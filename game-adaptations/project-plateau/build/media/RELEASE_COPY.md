*The Lost World* became more than dialogue and lore: this playable browser
prototype asks you to cross a connected plateau, read a living dinosaur family,
commit four physical glass plates while an aerial threat closes in, and return
with the exact views that survived the route.

The repository includes the public-domain source record, adaptation analysis,
concept trade-offs, game and art direction, runnable Three.js source, input-only
reference paths, and browser evidence.
