# 来源设定集：《金瓶梅》男性后宫改编基础

## 来源范围与证据规则

仓库来源为崇祯本百回足本的可复现删节洁本，版本与授权见 `source/SOURCE.md`。策划以回目定位事实；不从影视、漫画或其他游戏借造型与剧情。洁本移除露骨性描写，但保留人物关系、钱财、官场、家宅、节令与结局因果，足以建立本切片的状态和路线。亲密内容使用原创改编，不搬运未删节原文。

《金瓶梅》的可玩价值不只是“某个男人有许多女人”，而是同一所宅子里注意力、名分、钱、秘密和身体成本反复流动。西门庆能用钱与人情暂时把许多东西都占住，却不能让每个人失去自己的算盘。重制以这个结构解释后宫反馈，不把人物做成被收集的皮肤。

## 玩家身份：西门庆

- 第1回：清河县生药铺商人，有家资、铺面、帮闲与官面关系，能以钱推动婚姻、诉讼和消息。
- 第18回：通过贿赂从参本中除名，证明“钱／关系／秘密”可以解决外部压力，但会留下经手人与暴露风险。
- 第20、30、69回前后：铺面与官势扩张，生意、宅院和官场成为同一张资源网。
- 第30回：买得金吾卫副千户官身，与官哥儿出生同月，权力与家宅同时到达高点。
- 第47–49回：苗青案从行贿平事到被参再转圜，提供一条“秘密来自关系，秘密反过来解决经营”的完整原作因果。
- 第71–79回：权势、应酬与欲望同涨，身体同时透支；第79回三十三岁暴亡。

### 玩家资源、欲望、债与边界

| 维度 | 原作基础 | 切片表达 |
|---|---|---|
| 银钱 | 多处铺面、放债、行贿、嫁妆与梯己往来 | `silver`；买货、救急、设宴、保护关系 |
| 官势 | 结交官吏、买官、受贿说事 | `power`；办差、压风险、公开撑人 |
| 家声 | 宴席、节令、亲家与官场观感 | `repute`；影响吴月娘的合作与宴席结果 |
| 秘密 | 下人、媒婆、帮闲与女人之间的传话 | 有来源的可用旗标；能开夜间选项或化解白天压力 |
| 色心 | 对亲密与占有的持续追求 | 由玩家主动选择兑现，不被系统统一视为错误 |
| 关系债 | 给过谁钱、名分、承诺、保护，别人都可能看见 | 每名女主 `qing/yu/du` 与可见事件史 |
| 身体耗损 | 连日应酬与纵欲在第79回集中清算 | `strain`；是代价之一，不把所有亲密直接判坏 |

西门庆不是无代价的万能中心：他能选择今晚去谁那里，却不能决定对方一定答应，也不能抹掉其他人的记忆。第79回死亡是原著边界；玩家结果是“留下怎样的关系、局势与遗产”，不是把前面的追求归零。

## 三名切片女主

### 吴月娘：正堂与共治

- 原作身份：继室、清河左卫吴千户之女，掌家法、礼数、分派与最终收缩家业（第1、80–100回）。
- 她要什么：公开尊重、家宅稳定、重要决定在正堂说清。
- 她能给什么：中馈调度、家声、宴席裁决、把银钱和人手用在最要紧处。
- 她何时拒绝：玩家在公开场合反复羞辱她、拿公中当私房、或让家宅失稳还要她收尾。
- 她的主动性：会召玩家到正堂、设条件、限制偏宠，也会在被尊重时主动共担压力。
- 与他人冲突：不是简单吃醋，而是“偏宠是否破坏秩序”；她能把私人行为变成公开问题。

### 潘金莲：争夺与危险

- 原作身份：第9回入门第五房；没有可依靠的嫁妆、娘家或子嗣，主要靠观察、嘴、结盟与争夺注意力行动。
- 她要什么：被看见、被优先选择、能参与玩家的局势，而不是被安置后遗忘。
- 她能给什么：快速亲密、对宅内动静的敏锐、敢替玩家冒险的锋利行动。
- 她何时拒绝：长期冷落；给出独占承诺又当面食言；只拿她制造冲突却不承担后果。
- 她的主动性：会登门挑逗、公开拆台、逼玩家当场站边，不等玩家送对礼物才启动。
- 与他人冲突：挑战月娘的秩序，刺李瓶儿的软弱与财富；妒意必须来自她看见或听见的具体证据。

### 李瓶儿：财富、安全与私人依靠

- 原作身份：第13–19回的财产与婚姻变动后入门为第六房；带来三千两及沉香、白蜡、水银、胡椒等资产；官哥出生后母子成为宅内焦点。
- 她要什么：安全、保护、私事不被当筹码，以及情感上的确定。
- 她能给什么：解外部压力的银钱、柔和的私人空间、愿意托付的秘密。
- 她何时拒绝：玩家只取她的钱；答应保护却把秘密交给第三人；公开场合放任她受辱。
- 她的主动性：遇到风险会主动带账来找玩家，既能给也能收回，不是被动财库。
- 与他人冲突：她的钱能解急，也会让月娘质疑公私边界、让金莲认为玩家偏心。

## 三人关系不是平行轨道

- 吴月娘看重“公开怎么做”，潘金莲看重“你先选谁”，李瓶儿看重“你会不会护住托付”。同一选择必须在三条路线产生不同含义。
- 至少一个行为在两天后才兑现：例如公开替瓶儿挡下质询，第二天得到她的账本秘密；或对金莲许诺后又失约，宴席上被当众拆穿。
- 成人关系不是随机留宿：暧昧、前奏和明确 18+ 场景都必须由角色路线、当前意愿和玩家选择推进。
- 每次亲密至少留下两种后果，如 `qing/yu/du`、秘密、联盟、资源、家宅稳定或身体耗损。

## 可追溯的世界规则

| 规则 | 原作事实 | 游戏化边界 |
|---|---|---|
| 名分与恩宠不是一回事 | 入门礼、称呼、座次固定；注意力与礼物持续变化 | 吴月娘的正妻权不做可刷进度；玩家改变亲近、欲望与妒意 |
| 每名女性自带资本与目标 | 玉楼、瓶儿有财；月娘有家法；金莲以观察与争夺行动 | 女主不是奖品；每条线有可给、可拒绝、可退出的条件 |
| 钱能改事，不能消除经手人 | 多次行贿、说事、买官后仍可能被参 | 每个经营捷径留下秘密或关系债 |
| 信息沿人流动 | 玳安、媒婆、丫鬟反复传话、掩饰与抽成 | 秘密必须有来源，NPC 只对可见或被告知的行为反应 |
| 节令是公开结算 | 宴席、生日、元宵、清明贯穿全书 | 宴席把私人偏爱变成座次、承诺与当众冲突 |
| 生意依赖人 | 掌柜、伙计与家人掌货，西门庆死后卷款或自立 | 经营不是独立小游戏；关系决定谁肯提供钱、消息与背书 |
| 身体成本会累积 | 权势顶点伴随连日应酬，第79回死亡 | `strain` 制造张力，但亲密不是统一负收益 |
| 家宅会记账 | 礼物、梯己、债、口舌与人情反复被追索 | 次晨必须回响，关键旗标必须被后续消费 |

## 日程与可玩空间

```text
白日：正堂、铺面、衙门接口——理财、办差、探消息、备宴
黄昏：月娘正房、金莲花园角门、瓶儿私院——选择拜访与任务
夜间：近距离主观场景——调情、承诺、拒绝、亲密
次晨：宅院 Hub——谁来敲门、谁不肯见、谁拿昨夜说事
```

宅院不是开放世界。切片只需一个剖面 Hub 和三个人物近景场景：正堂的秩序、花园角门的危险、瓶儿院的私人安全感必须从构图和可用动作上区分。

## 改编边界

- 保留文化关键名称、宅院称谓、钱财与回目因果；第一次出现时用结果教，不开术语词典。
- 不把原作对女性的买卖与暴力变成收集或奖励系统。
- 官哥儿、孝哥儿与所有未成年人物仅可在非成人的历史背景中出现；切片成人数据完全不引用其名字、ID 或资产键。
- 不把“欲望皆空”做成唯一正确结论；先兑现玩家追求，再让关系债与身体成本形成后果。
- 不声称自动测试证明“性感”“好玩”或长期平衡；这些只能由目标成年玩家试玩报告支持。
