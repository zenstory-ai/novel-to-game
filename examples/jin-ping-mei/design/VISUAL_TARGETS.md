# VISUAL_TARGETS · 新国风叙事 CG 重塑

`targetFinish: playable-prototype`

## 目标

把《金瓶梅·风月总账》重塑为当代文字游戏玩家熟悉的“二维新国风叙事 CG”：世界、服饰、发式、器物与空间完整留在晚明，人物采用理想化但成熟的二维游戏审美，光色通透、情绪明确、关系动作可读。它既不复刻旧式工笔册页，也不做真人古装摄影、3D 电视剧截图或现代时尚广告。

首屏、白日、黄昏、夜谈、结果与场景册必须属于同一个古代游戏世界。白日以春庭日光、朱砂、石青、青绿、桃粉和克制金色建立吸引力；夜晚使用蓝紫月光与暖灯保持人物肤色、服色和器物可辨。压力由站位、视线、手势、证物归属与局部危险色承担，不再靠整体压黑。

- Case 206／242 式古画、长卷、书签不能成为人物与 UI 的主画风，会让成品像传统画册而不是当代叙事游戏。

- Case 207 式暗黑真人游戏封面不能作为成人感捷径，会同时压低人物辨识、关系想象与文字可读性。

## 样式基线

- **媒介**：二维数字手绘游戏 CG；轮廓精致，色彩柔和建模，丝绸与首饰有细节，但保留插画笔触与想象距离。
- **人物**：成年、成熟比例、理想化面孔与略放大的有神眼睛；不做幼态萌系，不做照片皮肤、3D 毛孔或演员剧照。
- **世界**：晚明宅院、家具、服装、发式和器物必须完整可信；不出现现代服饰、棚灯、几何摄影背景或品牌排版。
- **镜头**：角色不是并排证件照。用前后景、回看、交叉视线、递物、按账、留座和收钥形成关系张力。
- **亮度**：非特殊题材默认高明度。日景不得全局棕黄、灰黑或重暗角；夜景至少同时保留冷月填光与暖灯主光，脸、手、服色、边界动作和按钮保持可读。

## 目标画面

### 首屏

- 恰好五名成年女性同处春日院落与账房，脸型、成熟度、姿态、服色和器物可区分。
- 月娘石青持总账与钥匙；金莲朱砂持团扇；瓶儿象牙浅金自持匣钥；玉楼青绿藕荷持名帖与曲谱；雪娥琥珀深青持米账。
- 人物形成中右侧层叠群像，左侧约 30% 为春庭、花枝和空气透视留白，真实 HTML 标题落在留白上。
- 禁止黑底、重暗角、纸卷边框、现代时尚棚拍、真人照片、3D 皮肤、同脸换衣、可读伪文字和现代物件。

### 白日主循环

- 宅院背景使用完整二维游戏场景，决策页只覆盖局部；不使用全屏黑幕或黄褐纸纹统一压色。
- 选择签为暖白轻绢、石青细边与朱砂焦点；完成用青绿，危险用朱色局部边框，禁用整块红黑底。
- 顶栏保持轻薄，让日数和压力一眼可读，但不把人物 CG 切成后台管理面板。

### 黄昏与夜谈

- 五扇院门像同一套叙事角色卡：身份母版保持原始色彩，底部只留必要文字渐变。
- 夜晚允许比白日更深，但必须是蓝紫月光、暖灯和花影的彩色夜景；人物肤色、手势、器物与衣色仍可辨。
- 亲密、犹豫与拒绝由距离、朝向、目光、开掌、关窗、钥匙和出口表达，不把裸露或黑暗误当作关系深度。

### 结果与场景册

- 结果页沿用二维剧情卡面，不切回古画册页或系统成绩单。
- 公开群像让人物和证物占主画面，字幕不遮账簿、钥匙、封签、杯盏和关键手势。
- 失败与命数可以褪色、降饱和或转冷，但仍应看得见空间、物件和承担后果的人；悲剧不等于纯黑。

## 资产边界

- 参考库图片不进入运行目录；仓库只提交根据本项目人物、器物和剧情重新生成的原创资产。
- 四十一张运行图片全部由同一批准主视觉和六张身份母版派生；旧棕黑 CG、旧工笔重塑样张和未引用图片全部删除。
- 五张身份母版路径与哈希互不相同；后续个人、双人、群像、中局和终章图必须继承各自脸、发式、衣色和器物。
- 生成图内不得承担正文排版。若出现模型伪文字，必须编辑清除或由真实 HTML 完全替代。

## 验收

- 1280×800 首屏首先读作“古代二维叙事游戏”，不是古画、真人剧照、现代广告或暗黑封面；五人和五类器物可辨，标题不压脸。
- 390×844 首屏标题与按钮同屏可操作，裁切仍能读到至少三名人物和春庭光。
- 年龄门、白日选择、院门、夜谈、场景册和覆盖层共享暖白、石青、朱砂、青绿与藕荷语法。
- 所有四十一张运行图可解码、路径存在，旧图不再留在资产目录；关键身份图与终章图哈希唯一。
- 不以“好看”“现代玩家一定喜欢”作为机器结论；用截图、资源加载、无溢出、可操作路径和人工视觉巡检证明实现事实。
