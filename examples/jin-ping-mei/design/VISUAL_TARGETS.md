# VISUAL_TARGETS · 互动影游的六个画面

`targetFinish: playable-prototype`

对标主流恋爱 ADV 的完整外围配套与互动影游「选完就看后果」的画面节奏。细节见 `ART_DIRECTION.md`；下面每一条都要在带真实界面的实机画面里成立。

| 画面 | 一眼要看到的 | 不该出现的 |
|---|---|---|
| 标题 | 右侧五人春庭群像在微动，左侧墨色里竖着一枚「风月总账」朱印与六项菜单，落花 | 整屏文字、看不清的菜单、成人画面 |
| 阅读 | 全屏场景、站在场景里的人、画面下沿墨色渐隐里的名牌与正文；说话的人近一步，旁人暗下去 | 挡住脸的文本框、数值条 |
| 选择 | 选项贴着文本框上沿，脸露在上面；限时的那几处选项下面有一条烧短的灯芯 | 盖住人脸的选项、倒计时数字 |
| 过场 | 整屏影像，字幕居中压在下沿，人物名缩成一枚小签，底边一根细金线走进度 | 立绘叠在影像上、文本框 |
| 分岔夜 | 五扇院门并排，亮灯的暖、熄灯的只剩轮廓，门下是院名、人名与她的一句话 | 好感数值 |
| 结局 | 她的小像、结局名、盖下去的一枚印（良缘／寻常／错过），随后是暗底逐行浮现的原著命数 | 结算面板 |

竖屏（390×844）：上面六成是画，下面是文字与快捷栏；CG 与过场完整显示、四周垫同一张图的模糊底。

验收：验证脚本实机截取的 `screenshots/title.jpg`、`adv.jpg`、`cut.jpg`、`film.jpg` 与 `qa/evidence/` 里的院门、结局、命数、帘幕与窄屏截图；都不含成人画面。
