# GAME_DESIGN · 金瓶梅·风月总账

## 1. 体验定位

玩家是西门庆。那年春天，李瓶儿刚过门（第19回后），宅里五扇门各有心事。玩家读、选、等她们开口：
一条共通线把五个人放到同一张饭桌、同一场雨、同一席清明宴上，选择累积的心意决定那一夜哪扇门还亮着；
随后进入她一个人的路线，走到良缘、寻常或错过三种结局，再翻开一页不可更改的原著命数。

experienceProfile: `narrative-led` —— 成人古风互动影游（恋爱 ADV 结构）、阅读与观看主导、轻选择加少量限时与动作；桌面横屏优先，手机竖屏可完整游玩；指针、触屏与键盘输入。
单周目约 20–30 分钟；快进跳过已读后，五条线十六个结局全收约 1–1.5 小时。

首分钟目标：年龄门 → 动画标题 → 「开始游戏」→ 序章标题卡 → 第一句话下方提示「点击画面或按空格继续」。
玩家不需要读任何规则说明就知道：点一下读一句，遇到选项就选。

## 2. 核心循环

读（人物在场、立绘差分与名牌告诉你谁在说话）→ 选（在她们彼此冲突的时刻站边、在私下时刻说真话）→
看她当场的反应（表情、一句回嘴、下一幕的态度）→ 心意累积 → 院门开或闭 → 路线结局 → 原著命数。

选择不显示数值。好感只有三种出口：她的表情与台词；分岔夜院门是否「亮着灯」；系统菜单里可选的「心意」一瞥
（只有她的神色和「灯亮着／灯将熄」，不给档位与数字）。规则在第一章由月娘说出：清明席散那夜，还亮着灯的门才进得去。

结局判定：关键抉择做错 → 错过；做对且该人心意 ≥7 并在最后一问说真话 → 良缘；其余 → 寻常。
心意总数只用作 ADV 外围的开门与良缘门槛，结局分野仍由「关键抉择」这一条记录在案的具体言行决定，不由总分替代；路线内的台词与反应也只看具体选项，不看心意数。
良缘结局里有一次明确的同意选择：选项字面写「留下过夜」的进入亲密场景（成人 CG），写「不留宿……陪她坐到天明」的走非亲密版本，两者都是良缘；不用「拿开她的扇子」这类隐喻代替。

## 4. 原著命数（固定，不被结局改写）

每个结局之后翻开一页「原著命数」，按 SOURCE_BIBLE 人物名册写出她在书里的去处：月娘第79回守寡、第100回
孝哥儿出家；金莲第87回死于武松刀下；瓶儿第62回病故；玉楼第91回改嫁李衙内；雪娥第90、94回被拐、被卖；
西门庆第79回三十三岁而亡。结局只决定「这一春你们说成了什么」，页脚明写：改不了她在书里的去处。

## 5. 反馈、失败与重开

- 每个选择当场有人物反应（表情差分 + 一句台词），不弹数值结算。
- 「错过」作为正式结局，同样具备完整收束与命数页；玩家可随时读档或从任一章节节点重来。
- 读过的句子在名牌旁标「已读」，快进默认只跳已读、走到没读过的句子停下并提示；后续周目里走过的选项标「已选」。结局、CG、过场、回想、曲目跨周目保留，鉴赏页有结局流程图。
- 读档、回到上一选项或从剧情树重来时，如果直接落在一个选择上，文本框先把上一句摆回去，选择才有上文。

## 6. ADV 界面与外围功能（功能清单）

| 部分 | 内容 |
|---|---|
| 舞台 | 全屏背景 10 张（9 处场景，早市另有一张天亮前的街市；雨夜与寺院各一张），雨与落花两种天气；立绘左中右站位、进出场淡入、说话人近一步、旁人变暗；每位女主 6 种差分（平／笑／怒／哀／羞／惊），换到「惊」时轻跳一下 |
| 文本框 | 画面下沿的墨色渐隐，上面是她的小像（没有立绘的说话人只有名字前一道描金）、名字与一行身份（如「正头娘子」「贴身小厮」），下面是正文；打字机与翻页提示。CG 在场时底色让开；过场在场时换成居中的字幕 |
| 推进 | 点击／空格／回车读下一句；「自动」（A）；「快进」（F 或按住 Ctrl）；滚轮上翻、↑ 或「回看」打开带人名的历史，自己选过的那句（含「不作声」）也以「你选了」记在里面；「上一选项」（←）回到刚才的选择；右键或「隐藏」（H）收起界面 |
| 存读 | 快存（Q）／快读（W）；36 格存档（缩略图、章节名、当句预览、时间，可删除；一页摆排得下的几格，其余翻页）；每章开头与每个选择处自动存档；标题页「继续」读最近的一档，落回选择处或章节开头时浮一句说明 |
| 菜单 | 一本册页，左边签条：存档、读档、回看、剧情树、心意、设置、回到标题；标题页打开的是同一本，签条换成读档、剧情树、鉴赏、设置。Esc、右上角关闭、点册页外面都回到原处。册页里不出滚动条：存档、回看、剧情树、鉴赏的内容超出一页就分页，底下有翻页条，滚轮与 PageUp／PageDown 也是翻页；设置分成阅读、声音、影像与辅助、其他四签 |
| 设置 | 文字速度（带预览）、自动翻页、文字框浓淡、快进未读、配乐、音效、过场人声、动态影像、减弱动效、限时抉择、动作辅助、一键辅助、成人画面、全屏、恢复默认 |
| 鉴赏 | CG（未解锁显示锁格）、看过的剧情过场、回想（五场良缘之夜，按最近一次走到这一夜时的状态分台词，例如清明金簪给了谁）、音乐（8 首民乐曲目）、结局流程图（见过的结局点开重看结局名与原著命数） |
| 标题 | 五人群像的待机影像、落花、指针视差；开始游戏／继续／读取存档／剧情树／鉴赏／设置；页脚写已见结局数。只有打开页面后第一次来到标题时「开始游戏」带焦点；玩过一局回到标题时不给任何按钮焦点，连按空格不会开新局，上下键从第一项选起 |

竖屏：上面六成是画，下面是文本框与快捷栏（回看、自动、快进、上一选项、快存、菜单）；选项叠在画面下半；CG 与过场完整显示。

## 7. 语言、文化与成人边界

运行时简体中文，人物声口见本文附录「五条主线声口」。台词写动作与物件，不写账目术语。
成人白名单仅五名成年女主；年龄门在游戏的任何画面之前（门面只有一张不含人物的宅门夜景）；成人 CG 不预加载、只在亲密场景内并经玩家选择「留下过夜」后出现，
设置中可关闭（以帘幕替代）。存档缩略图不截取成人 CG。春梅、玳安、应伯爵、李娇儿只作宅中配角，不进入恋爱线。

## 8. 互动影游层

文游到影游，换的是「选择之后发生什么」。文游里，选完是几句旁白；影游里，选完是一段演出后果的剧情动画，
像短剧的一场戏：谁转身走了、谁把碗磕出缺口、谁先开口圆场，演完停在最后一个人的脸上，接下来的话就在这一帧上读。
本作的循环因此是：**读一段 → 当众或私下做选择 → 看这个选择的过场 → 在末帧上接着读 → 下一处选择**。

本作借鉴了主流互动影游的六种交互手法：

| 交互 | 先例 | 本作放在哪里 | 为什么是这里 |
|---|---|---|---|
| 选择之后的剧情过场 | 完蛋！我被美女包围了、隐形守护者、Late Shift：选完切进一段剧情影像 | 共通线每个有后续回响的选择点（每个选项各一段）、各路线的转折抉择、全部结局 | 玩家要亲眼看到自己那句话落在谁身上；当场演出来，才像在一场戏里做了决定 |
| 限时抉择，沉默是默认答案 | Late Shift、Bandersnatch：画面不停，倒计时走完替你选 | 共通线四场公开冲突：凉汤、荷花饼、箱子之问、应伯爵当席轻薄 | 当众的场面不等人。别人都看着你，迟疑本身就是表态 |
| 察言观色（画面热区） | 隐形守护者的线索搜集、Her Story 的「先看再判断」 | 第三章花园箱子、第四章门前旧契 | 两处都有一件物证决定你能说什么：瓶儿攥着的钥匙、契尾那行小字 |
| 按住动作 | 隐形守护者的长按、完蛋的 QTE | 第五章夜雨，护住手里那盏灯 | 本作的母题就是「留灯」，护灯由此化为玩家亲手完成的动作 |
| 「她记下了」 | Telltale、隐形守护者「这个人物会记住你的选择」 | 关键选项之后，带着她的小像浮出一枚签 | 不显示数值的前提下，让玩家知道这句话被谁收下了 |
| 剧情树回溯 | Detroit 流程图、隐形守护者的章节回溯 | 菜单「剧情树」：到过的章节可直接重来 | 十六个结局要多周目收集；跳回章节比反复快进更尊重时间 |

### 8.1 限时抉择

- 只用在公开、当众、有人在等你开口的场面。私下的夜话、院门选择、金簪、个人线关键抉择与良缘夜的同意选择都**不限时**；
  同意选择永远要玩家亲手点，不设默认值。
- 倒计时按选项的字数给：至少「2 秒 + 可见选项总字数 ÷ 7」，够读完再想一想（凉汤 11 秒、荷花饼 13 秒、花园箱子 12 秒，应伯爵那一下最短，9 秒）。选项下方一条灯芯在烧短，火苗跟着烧到头，最后三秒变色；灯芯下写一句「灯芯烧尽之前不开口，就是不作声」。
- 烧尽时先停一下：选项灰下去，灯芯下改写「灯芯烧尽了——你没有开口」，约一秒后再演沉默的后果；这时再按数字键只提示「灯芯已经烧尽」，不算选择。按数字键与点同一个选项，结果完全一样。
- 时间到即「沉默」：一条写好的独立分支，有人替你接话，在场的人各自记下你的不作声。它不是惩罚，有时也是对的。
- 设置「限时抉择」可关：关闭后不计时，「（不作声）」作为一个普通选项列出。快进、自动模式遇到限时选项一律停下；快进停在任何选择前都提示一句，按钮同时熄掉。菜单开着、界面隐藏、切到后台或弹着确认框时，灯芯不烧。

### 8.2 察言观色

- 画面停在这场戏的 CG/影像上，出现可点的细节（人物的手、器物、字），每处是四角一对金色折角加一个光点，一次最多看三处，右上角三盏小灯数着还能看几处，随时可以「不看了」。
- 每处细节写一句你看见的东西。看见关键物证会多出一个选项；没看见也有完整的选择，只是少一句话可说。
  - 第三章：看见瓶儿攥紧的那把小铜钥匙，才能说「钥匙你自己收着」。
  - 第四章：看见契尾「胡椒一宗，花子虚生前已折」，才能自己指出来，不必等月娘请中人。
  - 解锁的选项在文字下面带一行小字「看见了「那一处细节」才说得出口」，一眼看得出是哪一项、因为看见了什么；没解锁的选项不带。
- 热区按图像坐标的百分比登记，放在 CG 的画框里，任何宽高比下都对得上；键盘可用 Tab 依次选中，回车查看。看过一处后那句话压在画面下沿，整块文本区让点击穿过去，被字盖住的细节框照样点得中，只有快捷栏的按钮仍可点。竖屏时画面下沿另排一行细节的名字，点名字等于点那一处。

### 8.3 雨夜护灯

第五章开场，风把廊下的灯吹得要灭。按住（鼠标、触屏或空格）约两秒护住火苗。先留出两秒半读提示，之后不按的话火苗在七秒里矮到灭；松手早了火苗矮一截，可以再按。
两种结果都继续：灯在，清明席散那夜的旁白记着「你那盏灯一路没灭」；灯灭，记着你摸黑走过的那段回廊。
设置「动作辅助」打开时自动护住；没开时灯灭了，提示一句「要按住才护得住」与这个开关在哪。
提示行是一枚醒目的胶囊；松手早了，它亮一下改写成「别松手，一直按住」。开头读提示的两秒半里，从对话带过来的连点不扣火苗。

### 8.4 「她记下了」

选项效果里写 `r:人物` 才盖印：她心意上升时盖「某某会记得这句话」，下降时盖「某某心里冷了几分」。
不出现数字，不在每个选项都盖，只盖会在后文呼应的那几处。选项后面接着过场的，印等这段过场演完再盖，不压在影像上。

### 8.5 剧情树

每章开场自动记下一个节点（跨周目保留最近一次到达时的状态）。菜单与标题页的「剧情树」按共通线与五条路线排列章节，
到过的可点击重来（先确认），没到过的显示锁；每条线尽头列着它的三个结局，见过的写出名字。与鉴赏里的结局流程图互相补充：一个看过程，一个看结果。

### 8.6 剧情过场

- **配在哪里**：按选择点配，不按场景配。凡是后文会重提或决定走向的选择（带 `r:` 印、改路线、改结局），每个选项各有一段过场；
  限时选项的「不作声」、察言观色解锁的选项、护灯的成与败也各有一段。结局各一段。只换一句语气的小选择不配过场。
  逐段清单与分镜见 `build/art/cutscenes.json`。
- **选完立刻开演**：过场是选项去向的第一拍，前面不垫旁白或台词；玩家点下选项，画面就切进这一段后果，不先回到立绘加文字。
- **一段一个转折**：6～12 秒、2～4 个镜头：第一反应 → 动作 → 落点。末帧落在人脸或关键物件上，因为之后的几句就读在这一帧上。
- **第一人称**：镜头是你的视线，人看向镜头就是看向你；可以切她们的近景与彼此的反应，西门庆不出镜。
- **台词是字幕**：过场之后紧跟的几句台词是它的字幕，自动换句，规则是「读得完、不抢画面」：
  每句最早在画面演到它所写的那一刻出现（对白取说话人那一镜），每句至少停「0.8 秒 + 字数 ÷ 7」（1.8～10 秒）；
  画面演过了这句的内容还没停够，影像就停在镜头交界处、画面极慢地推近一点，并亮出继续记号，读够了再接着演。
  点击可以先走一步，画面跟着跳到下一句所属的镜头；菜单打开时影像暂停。
  最后一句上影像还在演的时候，点第一下只提示「再点一次跳过」，免得手快把一段戏点没了。画面底边一根细金线走着进度。
  过场有自己的人声、环境声与动作音效（音量在设置里单独调），播放时配乐压到三成。
- **降级显示**：读档、回退、快进、关闭「动态影像」、系统减弱动态或文件缺失时，直接显示末帧定格，字幕改为点击推进；
  任何选择、文字与结果不因此缺失。
- **鉴赏**：看过的过场收进「鉴赏 · 过场」，可以重看；没选过的那条要回剧情树重走才能看到。
- **成人边界**：过场一律不含成人画面；良缘结局的过场演的是次日清晨，成人场景仍按第 7 节处理。

### 8.7 待机影像

CG 与背景上的循环微动（花瓣、纱帘、烛火）只是氛围层，首尾帧即那张静帧，无声循环，可在设置里随「动态影像」一起关闭。
它不承担剧情，不能代替过场；热区所在的两张 CG 的细节物件在待机影像里不移动，保证热区对得上。

## 附录：文案声口参考

### 目标

本作不仿写《金瓶梅》原著句式。原著只继续约束人物关系和世界身份；运行时文案面向一宅五人的成年恋爱 ADV，重点是争宠、边界、暧昧、多人互动和次日回声。

### 落笔规则

1. **一个选择，一个当场回应**：让人物当场开口或做出动作，把玩家的选择带向下一个问题，不靠旁白总结情绪。
2. **多人场景至少有两次互相接话**：不把五个人写成轮流对西门庆表态的五张卡片。她们要互相拆台、圆场、试探、作证或主动照顾。
3. **暧昧靠距离和物件推进**：杯沿、扇柄、袖带、簪冠、钥匙、门闩、灯芯和纱帐都必须发生动作，不只做古风背景名词。
4. **欲望与利益并存**：账目、银钱、座次与安全感直接决定人物能否放下防备。
5. **嫉妒不共用模板**：月娘问“话能不能见日头”，金莲从衣领上闻到别处的香，瓶儿怕的是最后一个才听说。
6. **香艳不等于直白报告**：先写谁没有躲、谁替谁拆了簪、谁把钥匙留在自己掌心，再让灯变暗。不用“关系升级”或“她更爱你了”代替场景。
7. **偏爱必须有回声**：共通线里偏向谁、冷落谁，要在下一幕她或旁人的称呼、座次、物件和态度上留下后果。
8. **不写格言**：旁白只交代动作和场面，不替玩家抒情；对仗凑出来的狠话、故意只说半句的留白、「有些灯一辈子只亮一次」式的金句都会读成中二。界面提示同样用直白的说法：标题页只写作品类型，不写「先看清脸色再开口」；也不写界面做不到的操作提示。

### 验收检查

- 所有选择的结果文案实际可见，不被下一阶段立即覆盖。
- 每条个人线的良缘夜都有一次明确的同意选择（留下过夜／不留宿、陪她坐到天明），措辞字面明确，不能点一下直接进入亲密画面。
- 个人线开场引用共通线的事实（例：荷亭头彩的金簪给了谁）时，按实际状态分台词，不能默认最常见的那条路。
- 五人共场时，至少有两名人物直接对话、作证或照顾另一名女性，不只各自面向玩家。
- 五条个人线的吃醋、偏爱后的回声和良缘夜“陪她坐到天明”的文案不共用同一模板。
