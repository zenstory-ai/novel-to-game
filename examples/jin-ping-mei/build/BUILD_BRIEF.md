# BUILD_BRIEF · 金瓶梅·风月总账

# 目标

`targetFinish: playable-prototype`

- 平台与交付物：浏览器里直接打开的静态站，零构建、零运行依赖（原生 ES Module + DOM/CSS，`<video>` 播放预渲染过场）；`build/app` 整个目录即部署物。
- 范围：共通线六章 → 分岔夜 → 五条个人线各四章 → 十六个结局与原著命数页；58 段有声剧情过场、36 段待机影像原样沿用（晚饭 CG 换成暮色版后，它那段白天的影像停用）。
- 视口与输入：桌面横屏为主（1440×900 起），手机竖屏上画下字、横屏收紧排版；鼠标、触屏与键盘都能从头玩到结局。
- 分级：18+。年龄门在游戏的一切画面与声音之前（门面只有一张不含人物的宅门夜景），确认只记在本次浏览器会话里。
- 联网：无账号、无后端；存档、设置与鉴赏记录只写本机 `localStorage`。

# 核心还原要求

experienceProfile: `narrative-led`

- 循环：读一段 → 当众或私下做选择 → 看这个选择的剧情过场 → 在末帧上接着读。每个配过场的选项都有自己的那一段，且过场是选完后的第一拍，前面不垫旁白；过场缺失、关闭、读档或系统要求减弱动态时显示末帧定格，字幕改为点击推进，文字与结果一句不少。
- 过场里的台词是影片里人物已经开口念出的：句数与文字锁定，改动要重新生成影片。字幕时间点（`js/story/registry.js` 的 `CUT[id].cues`、`ends`，与 `build/art/cutscenes.json` 一致）按成片逐镜抽帧核对：`cues` 是画面演到这句所写内容的秒数（对白取说话人那一镜），`ends` 是画面还在演它的最后秒数；分镜表的镜头起止只是生成时的提示词，与成片常差 0.5～2 秒。
- 过场字幕读得完、不抢画面（`js/engine/subs.js`）：每句至少停 0.8 秒 + 字数 ÷ 7（1.8～10 秒）；演到 `ends` 还没停够，影像停在镜头交界处慢推、亮出继续记号，读够再演。点击先走一步时画面跟着跳到下一句的镜头。
- 心意不显示数值：只有她的神色、分岔夜门上的灯，和关键选择后盖的「她记下了」。分岔夜心意不足三的门熄灯；五扇全灭走「无人留灯」。
- 结局：关键抉择做错即错过；做对且心意够七、最后一问说真话是良缘；其余寻常。每个结局之后翻原著命数页，命数固定。
- 限时只用在四场当众的冲突，秒数至少「2 + 可见选项总字数 ÷ 7」；烧尽时先停约一秒写明「你没有开口」，再走写好的「不作声」分支，这期间按数字键不算选择；私下夜话、院门、金簪、关键抉择与良缘夜的同意选择不限时、不代选。限时在菜单开着、界面隐藏、切到后台时暂停。
- 成人边界：良缘夜的同意选择字面写明「留下过夜」与「不留宿……陪她坐到天明」；成人 CG 只在玩家选「留下过夜」之后请求，画面里只有明确成年、着装完整的女主；设置关掉「成人画面」时挂帘幕。存档缩略图、公开截图、过场与待机影像都不含成人画面。
- 图文昼夜与姿态一致：背景按「地点 × 时段」选，夜里的场次用正堂、灶房、花园的夜景，旁白写过入夜之后直到写天亮或换章都不配白天的背景；文字写她背对你、背过身、卸簪散发、披衣未梳时不留正面整妆立绘，同一场里之后出场的 CG 也必须是卸了簪的画面（`CG[id].undressed`）。立绘都是站姿、手里只有各自的器物（金莲团扇、瓶儿钥匙、玉楼名帖）：写她坐着、蹲着、伏案写账、做针线、抱琴、靠着睡着或「满桌」酒菜的旁白不压在立绘上，先写她起身再让立绘登场，重新坐下干活前先撤立绘。`npm run verify:model` 穷举时逐句核对；CG 画面内容本身靠台账与人工逐张对照，模型检查只认登记。
- 察言观色的细节框两两不相交，横屏下框底不越过文本框上沿（画面 77% 高处，右侧 60% 以外不限）。
- 关键画面：动画标题（五人群像）、立绘站位的晚饭戏、过场里压在画面下沿的字幕、察言观色的细节框、分岔夜的五扇院门、结局卡的印与命数页。视觉约束见 `design/ART_DIRECTION.md`。
- 回想按最近一次走到那一夜时的标记分台词（例如清明金簪给了谁）；鉴赏里见过的结局可点开重看结局名与原著命数。玩过一局回到标题时不给任何按钮焦点，连按空格不会开新局。
- 存档：36 格 + 快存 + 自动（每章开头与每个选择处）；存的是「这一拍之前」的完整状态（连同最近 120 句回看），读回来画面与文字一字不差，落在过场中间时显示末帧定格。旧版（2026-11 之前）的存档不读取。

复现: 全新浏览器会话 → 年龄门「我已成年，推门进去」→ 开始游戏 → 立刻回家 → 看向月娘 → 正院 → （灶上那一问等到时间到）→ 花园看「瓶儿手里的钥匙」、选「箱子我替你守着」→ 门前看「旧契」、选「听月娘的」→ 按住空格护灯 → 正院 → 沉下脸 → 给月娘 → 进正院 → 「那件事，是我不对」→ 糖兔子 → 「家里的账，大姐管」→ 推门进去 → 留下或陪她坐到天明 → 结局「月下焚香」（`yue_good`）→ 命数页 → 标题。无随机数。

# 运行

targetRuntime: 现代桌面与手机浏览器（Chromium、Safari、Firefox 的当前版本）
testedRuntime: Chromium（Playwright 自带的无头版本），1440×900 完整一局，390×844 走到第一章的限时抉择
engine: 无引擎、无框架；原生 ES Module + DOM/CSS。版本 NOT_AVAILABLE: 没有第三方运行库
commands:
  install: NONE
  start: `cd examples/jin-ping-mei/build/app && python3 -m http.server 5173`，然后打开 `http://127.0.0.1:5173/`
  test: `cd examples/jin-ping-mei/build/app && npm run verify:model`
  verify: `cd examples/jin-ping-mei/build/app && python3 test/verify.py --write-evidence`

操作：点画面、空格或回车读下一句；点选项或按数字键选择。其余按键与设置见 `build/app/RUN.md`。

# 限制

- 完整一局只在无头 Chromium 的 1440×900 下走过一条路线；窄屏只走到第一章，没有在真机、Safari 或 Firefox 上运行。
- 58 段过场与 36 段待机影像是沿用的成片，没有重新生成，也没有逐段复核演技、口型与人声的一致；字幕时间点是看画面核对的，对白没有逐句听音校准。护灯成功那段（`r_lamp_ok`）原片是描边线稿画风，已换成三张厚涂关键帧的摇镜剪辑，原音轨不变、没有动作表演。凉汤「汤凉了再热」那段（`d_xuee`）原片窗外与门外是白天，已逐帧调成入夜掌灯（窗景换成夜空，人物不动、原音轨与字幕时间点不变），没有重新生成；台账给夜里场次的 12 段过场登记了 `period: night`。其中 8 段（k_fair、k_pan、k_silent、k_xuee、x2_mud、x2_trust、x2_hurt、meng_normal_end）因配角被画成幼童，在本机用裁切、定格或关键帧静帧重封装了相应镜头，原音轨与字幕时间点不变；静帧段落没有口型。
- 只有过场里的人物开口，没有全程配音；静音或关掉动态影像都能读完全部内容。
- 旧版存档不兼容：换了存储命名，旧档不会出现在读档页里。
- 未覆盖项的完整清单在 `qa/verification.json` 的 `limitations`。
