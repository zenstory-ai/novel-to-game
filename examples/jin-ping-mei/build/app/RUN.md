# 《金瓶梅·风月总账》— 运行与验证

18+ 古风互动影游。你是西门庆；每个要紧的选择做完，都有一段剧情过场演出后果，台词以字幕压在画面上，演完在那一帧上接着读。那年春天，五扇门都为你留过灯。共通线六章之后，心意决定哪扇门还亮着，
进入吴月娘、潘金莲、李瓶儿、孟玉楼、孙雪娥之一的个人线，走到良缘／寻常／错过，再翻开不可更改的原著命数。
五名可攻略角色均为成年虚构人物。

## 启动

```bash
cd examples/jin-ping-mei/build/app
python3 -m http.server 5173
```

打开 `http://127.0.0.1:5173/`。零构建、零运行依赖。

## 怎么玩

| 操作 | 鼠标 | 键盘 |
|---|---|---|
| 读下一句 | 左键点画面 | 空格／回车／↓ |
| 选择 | 点选项 | 数字 1–5；或 ↑↓／Tab 选中再按回车（回车不会替你点第一项） |
| 回看 | 滚轮上翻、「回看」 | ↑ 或 B（选择处 ↑ 用来挑选项） |
| 回到上一个选择处 | 「上一选项」 | ← |
| 隐藏文字 | 右键、「隐藏」 | H |
| 快进 | 「快进」 | 按住 Ctrl |
| 自动 | 「自动」 | A |
| 存档／读档／快存 | 文本框下的按钮 | S／L／Q |
| 菜单（心意、剧情树、设置、回标题） | 「菜单」 | Esc |
| 限时选项 | 灯芯烧完之前点选项；不点就是「不作声」 | 数字键 |
| 察言观色 | 点画面上的细节框，最多三处；「不看了」继续 | Tab 选中细节、回车查看 |
| 护灯 | 按住鼠标或触屏 | 按住空格 |

单周目约 20–30 分钟；快进跳过已读后，五条线十六个结局全收约 1–1.5 小时。

## 一局的结构

序章 春深西门宅 → 五扇门 → 晨省 → 花园里的箱子 → 门前来人 → 夜雨 → 清明荷亭 → 今夜往哪扇门去 →
个人线四章（心事 · 出门 · 风波 · 夜里的真话）→ 结局卡 → 原著命数 → 标题。心意不足三的院门熄灯；全部熄灯则进入「无人留灯」。

设置里可以关掉「限时抉择」（不计时，「不作声」列为一个选项）、打开「动作辅助」（护灯自动完成），
或关掉「动态影像」（过场换成末帧定格、点击推进字幕，CG 用原图缓缓推近）；系统要求减弱动态时同样回落。
看过的过场收进「鉴赏 · 过场」，可以重看。

## 验证

```bash
python3 test/verify_visual.py --write-evidence   # 权威：真实浏览器走完整一局并重开，写 qa/ 与截图

```
