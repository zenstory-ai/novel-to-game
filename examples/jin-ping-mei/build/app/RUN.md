# 《金瓶梅·风月总账》— 运行与验证

这是一个 18+、男性第一人称的成人后宫关系模拟垂直切片。你是西门庆，在
20 日四幕中处理银钱、家声、外债与五处院门。白日的账与证据会改变当夜选择，夜里的
偏爱、边界与亲密又会在次晨变成口径、妒意、权限或合作。

五名可攻略角色均明确设定为成年虚构人物：吴月娘、潘金莲、李瓶儿、孟玉楼、孙雪娥。
李娇儿是贯穿四幕的交易中介支线。确认成年前，成人 CG 不会进入 DOM。

## 启动

```bash
cd examples/jin-ping-mei/build/app
python3 -m http.server 5173
```

打开 `http://127.0.0.1:5173/?seed=42`。仅做快速调试时可加 `&fast=1`；权威 QA 路径不加该参数。

应用为原生 ES Module + DOM，零构建、零运行依赖，目标桌面视口为 `1280×800` 与
`1920×1080`。

## 一局的结构

```text
次晨回声 → 白日选择／双人合办 → 娇儿支线／公开问责 → 黄昏拜访 → 夜间决定 → 结转
```

- **四幕**：1–5 日立账与入局，6–10 日偏宠有价，11–15 日同盟与裂账，16–20 日总账见日。
- **20 条日压力**：每日有唯一 ID、标题、情报与不可替换的结构任务，不用重复素材充回合。
- **五条深线**：每人 8 拍个人弧线，分别掌管正堂裁决、追问口供、私财商路、礼法人脉和灶仓证据。
- **五份边界条款**：定账、真话、私钥、退路、灶权；立约占一夜，不偷走个人路线拍。
- **五桩合办事**：三组旧搭档加月娘／玉楼、金莲／雪娥；每组只做一次，五人都必须实际出过力。
- **三场公开检验**：第 5、10、15 日分别检查功劳、债务口径与证词；空话会被之前的选择拆穿。
- **第 20 日**：只有五份边界、五桩合办事、三场公开口径与五人关系都到位，
  才能进入共同办事、三拍余夜、成人群像与次晨结算。任何 1–19 日的伪造状态都不能返回后宫结局。
- **同意门禁**：“今夜就到这里”始终可选；孟玉楼的财产／人脉、孙雪娥的职位／免罚不能交换亲密。

## 场景册、存档与声音

- 15 个唯一场景：五人各 1 页前奏、1 页关系终段，3 页公开问责，2 页第 20 日共同场景。
- 亲密美术只允许肩背、腿部或松开外袍等轻度裸露；不表现乳头、生殖器或性行为。
- 场景册只展示已解锁页面；重开清周目，不清场景册。
- 周目存档键为 `jpm_fengyue_save_v7`，schema 为 `v12`。旧 schema、缺少五人状态块或阶段矛盾的存档都拒读。
- 声音由 Web Audio 程序化生成，不依赖外部音频文件。

## 验证

```bash
cd examples/jin-ping-mei/build/app
node test/ledger.mjs
python3 test/verify.py
```

`verify.py` 走一条不含 `fast=1` 的正常速度、全键盘 20 日路径，记录每日压力、五条路线、
中盘存读、1–19 日未提前结束、第 20 日结局、重开和浏览器错误数组。结果写入
`qa/verification.json` 和 `qa/evidence/browser/evidence-normal.json`。

仓库级验证：

```bash
python3 scripts/validate_repo.py
python3 -m unittest discover -s tests -v
```

## 边界

- 自动化可以证明流程、状态、资源、素材和画面按当前合同运行，不能证明“好玩”“性感”或长期平衡。
- 内网小说库只用于归纳结构和声口；运行文案不复制未授权原句。
