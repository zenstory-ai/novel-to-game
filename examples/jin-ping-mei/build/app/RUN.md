# 《金瓶梅·风月总账》— 运行与验证

这是一个 18+、男性第一人称的成人后宫关系模拟垂直切片。你是西门庆，在 6 天内处理
铺子、官面和一宅人情；白日挣来的钱、势与消息会改变当夜选择，亲密结果又会在次晨变成
嫉妒、索取、秘密或新的经营办法。

本切片只包含明确设定为成年人的吴月娘、潘金莲、李瓶儿。页面先显示年龄与内容提示，
确认成年前不会把成人 CG 放进 DOM。

## 一局怎么玩

每日顺序固定：

```text
次晨来人 → 白天选择 → 第2–4日宅中插曲 → 黄昏拜访 → 人物回应 → 夜间决定 → 结转
```

- **白天**：`翻账`、`走官面`、`问口风`、`整席面`。没有一项能通吃三条路线。
- **宅中插曲**：第2–4日依次遇到孟玉楼、孙雪娥、李娇儿；名帖、后仓和催账三件事都会进结算。
- **黄昏**：去月娘、金莲或瓶儿屋里。人物近景、说话方式、想要的东西与拒绝条件不同。
- **夜间**：可到这里就走、留下说话、等她靠近，或在关系与意愿前置满足后留宿；
  `今夜就到这里` 始终可选。
- **次晨**：别人只根据公开选择、被看见的痕迹或已听说的消息吃醋或上门，不偷读隐藏值。
- **第五天**：三人同场的中秋宴，玩家必须公开站队、平衡或借题布局。
- **第六天**：按整局关系史得到 `专一`、`平衡` 或 `权谋` 收束。

常驻人物账只显示：

- `情`：信任与感情；
- `欲`：亲密意愿；
- `妒`：被忽视与争夺压力。

外账为银钱、官势、声望；总账为曝光、损耗与家宅。追求亲密不会被系统统一判成坏玩法，
但公开偏爱会留下能被别人看见的后果。

## 场景册、存档与声音

- 7 个唯一场景：三名女主各 1 页前奏、1 页关系终段，以及 1 页中秋群像。
- 场景册只展示已经解锁的页面；可全屏重看，重看不重复改状态；重开清周目，不清场景册。
- 周目存档键为 `jpm_fengyue_save_v4`（键名固定，迁移由存档内的 `version` 字段驱动）；
  存档格式当前为 `v5`。`v3` 档先补齐宅中人字段迁入 `v4`，再按已置位的失信旗标反推
  公开越过计数迁入 `v5`；旧孟玉楼版 `jpm_save_v1` 仍不会读入。
- `音／默` 状态独立持久化。声音由 Web Audio 程序化生成，不依赖外部音频文件。

## 自动验证

```bash
cd examples/jin-ping-mei/build/app
node test/ledger.mjs
python3 test/qa_browser.py            # 加速路径（默认）
QA_SLOW=1 python3 test/qa_browser.py  # 正常速度完整路径，时序证据只在这一轮有效
```

当前证据基线：

- 纯引擎：52 项通过，0 项失败；
- 真实 Chromium：167 项通过，0 项失败（加速与正常速度两轮各一次）；
- 控制台错误 0，关键资源失败 0，外部请求域 0；
- 最重转场（群体冲突场景册关闭）点击→绘制 12.3 ms（加速）/ 38.2 ms（正常速度）；
- 主线程长任务：按观察器记录的 `phase` 归因，仅年龄门/首屏一次 171 ms（加速）/ 181 ms（正常速度），玩家进入游戏后 0 次；
- 浏览器证据：只保留 `qa/evidence/browser/evidence-normal.json`（正常速度）；
- 逐步安全截图：测试时按需生成，提交时只保留 `screenshots/` 精选图；
- 18+ 内部验收截图：`qa/evidence/browser/adult/`（已 gitignore，不随仓库发布），不得用于 README 或公开商店页。

本作是纯 DOM/CSS，无 `requestAnimationFrame` 渲染循环，**帧率数字对它不构成性能结论**
（采 rAF 间隔只会量到浏览器空闲垂直同步节拍）；因此这里测的是转场延迟与主线程长任务。

浏览器验证覆盖年龄门、男性身份、三条深线、三条宅中短线、拒绝、延迟后果、可追溯嫉妒、宴席冲突、
场景册跨重开、旧档隔离、关键 CG 加载、两个目标视口、键盘聚焦和
`prefers-reduced-motion`。

## 当前边界

- 这是 3 条成人深线 + 3 条宅中短线／6 回合、约 20–30 分钟的可运行切片，不是旧版
  24 节令的内容迁移。
- 自动化可以证明流程、状态、资源和画面按设计运行，不能证明“好玩”“性感”或长期平衡。
- 把三条短线升级成完整夜访路线或扩到 18–24 回合之前，必须完成 6–8 名目标成年中文玩家的无讲解试玩，
  并达到 `qa/QA_REPORT.md` 记录的阶段 4 硬门。
