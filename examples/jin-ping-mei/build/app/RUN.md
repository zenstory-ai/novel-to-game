# 《金瓶梅·风月总账》— 运行与验证

这是一个 18+、男性第一人称的成人后宫关系模拟垂直切片。你是西门庆，在 6 天内处理
铺子、官面和一宅人情；白日挣来的钱、势与消息会改变当夜选择，亲密结果又会在次晨变成
嫉妒、索取、秘密或新的经营办法。

本切片只包含明确设定为成年人的吴月娘、潘金莲、李瓶儿。页面先显示年龄与内容提示，
确认成年前不会把成人 CG 放进 DOM。

## 启动

```bash
cd examples/jin-ping-mei/build/app
python3 -m http.server 5173
```

打开：

```text
http://127.0.0.1:5173/
```

可复现快速验证：

```text
http://127.0.0.1:5173/?seed=42&fast=1
```

原生 ES Module + DOM，零构建、零运行依赖。目标为桌面横屏
`1280×800` 与 `1920×1080`。

## 一局怎么玩

每日顺序固定：

```text
次晨来人 → 白天选择 → 第2–4日宅中插曲 → 黄昏拜访 → 人物回应 → 夜间决定 → 结转
```

- **白天**：`翻账`、`走官面`、`问口风`、`整席面`。没有一项能通吃三条路线。
- **宅中插曲**：第2–4日依次遇到孟玉楼、孙雪娥、李娇儿；名帖、后仓和催账三件事都会进结算。
- **黄昏**：去月娘、金莲或瓶儿屋里。人物近景、说话方式、想要的东西与拒绝条件不同。
- **夜间**：可到这里就走、留下说话、等她靠近，或在关系与意愿前置满足后留宿；
  `今夜就到这里` 始终可选。
- **次晨**：别人只根据公开选择、被看见的痕迹或已听说的消息吃醋或上门，不偷读隐藏值。
- **第五天**：三人同场的中秋宴，玩家必须公开站队、平衡或借题布局。
- **三院共约**：分别进三处院门，听清月娘的“正堂定账”、金莲的“去处说真”、瓶儿的
  “私钥在手”。立约占用当夜，但不推进她的个人路线拍。
- **联院差事**：两条相关院约谈成后，白日可让月娘／金莲对账问供、月娘／瓶儿合账调货，或
  金莲／瓶儿顺话验货。每组只做一次；至少完成两组，第六夜才算有共同办事的前史。
- **第六天**：若中秋三杯同斟、三条约齐备且联院差事达到 2/2，可请三人都别走。正确选择会先让月娘对账、金莲拆谎、瓶儿接货，然后进入两段可互动余夜、一页三人成人群像和一次次晨选择，不会点一下直接结束。花钱买静或再许空话仍只结算各自代价。

常驻人物账只显示：

- `情`：信任与感情；
- `欲`：亲密意愿；
- `妒`：被忽视与争夺压力。

外账为银钱、官势、声望；总账为曝光、损耗与家宅。追求亲密不会被系统统一判成坏玩法，
但公开偏爱会留下能被别人看见的后果。

## 场景册、存档与声音

- 9 个唯一场景：三名女主各 1 页前奏、1 页关系终段、1 页中秋群像、1 页安全着装的三院共同办事群像，以及 1 页仅对成年玩家展示的灯下余夜群像。
- 场景册只展示已经解锁的页面；可全屏重看，重看不重复改状态；重开清周目，不清场景册。
- 周目存档键为 `jpm_fengyue_save_v6`，格式为 `v11`。本原型不承担旧周目兼容：旧键、旧 schema 或缺少当前过程字段的状态均不读入，玩家从第一日开始新局；场景册使用独立键，重开周目不会清空已解锁页面。
- `音／默` 状态独立持久化。声音由 Web Audio 程序化生成，不依赖外部音频文件。

## 自动验证

```bash
cd examples/jin-ping-mei/build/app
python3 test/verify.py
```

该命令只走一条正常速度、全键盘完整路径：启动、渲染、三条院约、两张双人协力事件图、中秋同斟、第六夜共同办事、两段余夜、成人群像、次晨选择、`三院同灯` 结局与重开；同时检查 `1280×800` 和 `1920×1080` 两个目标视口。成人路径证据与公开安全截图分目录保存。
结果写入 `qa/verification.json` 和 `qa/evidence/browser/evidence-normal.json`。

仓库级验证：

```bash
python3 scripts/validate_repo.py
python3 -m unittest discover -s tests -v
```

## 当前边界

- 这是 3 条成人深线 + 1 条可实际游玩的三人共线 + 3 条宅中短线／6 回合、约 20–30 分钟的可运行切片，不是旧版
  24 节令的内容迁移。
- 自动化可以证明流程、状态、资源和画面按设计运行，不能证明“好玩”“性感”或长期平衡。
- 三条宅中短线升级成完整夜访路线，或将总流程扩到 18–24 回合，属于新的产品范围，必须先修订 PRODUCT_BRIEF，
  当前机器 QA 不对此作结论。
