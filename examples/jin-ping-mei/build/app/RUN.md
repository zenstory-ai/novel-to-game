# 《金瓶梅·风月总账》运行与验证

18+ 古风恋爱互动影游。你是西门庆。每个要紧的选择做完，都有一段剧情过场把后果演给你看，台词以字幕压在画面下沿，演完在那一帧上接着读。
共通线六章之后，心意够的院门亮着灯；进吴月娘、潘金莲、李瓶儿、孟玉楼、孙雪娥之一的个人线，走到良缘、寻常或错过，再翻开改不了的原著命数。
五名可攻略角色都是成年的虚构人物。

## 启动

```bash
cd examples/jin-ping-mei/build/app
python3 -m http.server 5173
```

打开 `http://127.0.0.1:5173/`。零构建、零运行依赖。

## 怎么玩

| 操作 | 鼠标／触屏 | 键盘 |
|---|---|---|
| 读下一句 | 点画面 | 空格／回车／↓ |
| 选择 | 点选项 | 数字 1–5；或 ↑↓ 移到选项上再按回车 |
| 回看 | 滚轮上翻、「回看」 | ↑（选择处用来挑选项）或 B |
| 回到上一个选择 | 「上一选项」 | ← |
| 自动／快进 | 「自动」「快进」 | A／F，或按住 Ctrl 快进 |
| 快存／快读 | 「快存」「快读」 | Q／W |
| 存档／读档／剧情树 | 「菜单」里的签条 | S／L／T |
| 隐藏界面 | 右键、「隐藏」 | H |
| 菜单 | 「菜单」 | Esc |
| 限时抉择 | 灯芯烧完之前点选项；不点就是「不作声」 | 数字键 |
| 察言观色 | 点画面上的细节框，至多三处；「看好了」继续 | Tab 选中细节、回车查看 |
| 护灯 | 按住画面 | 按住空格 |

过场最后一句上，影像还在演的时候点一下只会提示，再点一下才跳过。单周目约 20–30 分钟；快进跳过已读后，五条线十六个结局全收约 1–1.5 小时。

## 一局的结构

序章 春深西门宅 → 五扇门 → 晨省 → 花园里的箱子 → 门前来人 → 夜雨 → 清明荷亭 → 今夜往哪扇门去 →
个人线四章 → 结局卡 → 原著命数 → 标题。心意不足三的院门熄灯；五扇全灭进「无人留灯」。

## 设置

- 「动态影像」关掉：过场换成末帧定格、字幕点击推进，画面的待机微动换成慢推镜。
- 「减弱动效」打开：推镜、视差、落花与立绘弹跳都停掉，过场同样改显定格画面；系统要求减弱动态时自动如此。
- 「限时抉择」关掉：不计时，「不作声」列为一个普通选项。「动作辅助」打开：护灯自动完成。「一键辅助」一次打开这三项。
- 「成人画面」关掉：亲密场景的画面以帘幕代替，文字照常。
- 标题页的「鉴赏」收着看过的 CG、过场、回想、曲目与结局流程图；「剧情树」可从到过的任一章重来。

## 验证

```bash
python3 test/verify.py --write-evidence
npm run verify:model
```

- `test/verify.py`：浏览器完整通关验证。真实浏览器从年龄门走到吴月娘良缘、命数页、回标题并重开，途中核对过场播放与字幕换句、限时沉默、两场察言观色、护灯、
  快存快读、刷新后读档、成人画面开关与年龄拦截，另开 390×844 走到第一章的限时抉择；写 `qa/verification.json`、`qa/evidence/` 与 `screenshots/`。约两分半钟。
- `npm run verify:model`：无浏览器。核对剧本连通、资源登记与文件、过场成对与字幕句数，并穷举全部选择证明十六个结局都能走到。约十五秒。

## 目录

| 位置 | 内容 |
|---|---|
| `js/story/` | 剧本正文（九个文件）与登记表 `registry.js`（人物、场景、CG、过场与字幕时间点、曲目、结局、命数、剧情树） |
| `js/engine/` | 剧本编译器与运行时：纯逻辑，浏览器与 node 共用；剧本语法写在 `script.js` 开头 |
| `js/game.js` `js/stage.js` | 导演（走拍点、输入、存读档）与舞台（背景、立绘、CG、过场、待机影像） |
| `js/ui/` | 选项与院门、察言观色、护灯、印、整屏卡、菜单册页 |
| `css/` | 样式：`base` 色与字、`stage` 舞台、`play` 读与选、`screens` 年龄门与标题与卡、`book` 菜单 |
| `assets/` | 立绘、背景、CG、界面图、过场（`cut/`）、待机影像（`film/`）、配乐与音效 |

加一场戏只改 `js/story/`；过场里的台词与字幕时间点同影片绑定，不能单独改。
