# 西游记 · 三借芭蕉扇(回合制指令 RPG)

《梦幻西游》式回合制 RPG:可走的 2.5D 场景、NPC 头顶「!」、任务追踪自动寻路、日常封妖(明雷)、
商店与装备槽;战斗为指令回合制、敌我各占一条斜列车道(敌在左、我在右,召唤来的妖兵顶替倒下者的位置)、
速度行动顺序条、五行相克、法术/法力、愤怒特技、保护、携宠协战、阵型、悟空七十二变(换形态立绘),种子随机可复现。零构建,原生 ES Module + Canvas/DOM。

## 启动

```bash
python3 -m http.server 5173
# 浏览器打开 http://127.0.0.1:5173/
```

目标视口 ≥1280×800,鼠标优先;场景里方向键行走、Enter/空格与身边的人对话,战斗中 Esc 可取消选目标。

URL 参数(可选):`?seed=42` 固定全局种子;`&fast=1` 加速动画(自测用)。

## 玩法

- **场景(梦幻式外层)**:四张可走场景——火焰山庄(枢纽)、翠云山·芭蕉洞外、火焰山·火口、积雷山·摩云洞前,
  由传送阵相连,随主线开放。点地行走(寻路绕开山石),点人对话;头顶金色「!」是主线要找的人,青色「令」是可领的日常封妖令,「?」是待回报。传送阵点光圈或点阵名都能走过去。
  右侧【任务追踪】点一下自动寻路,可跨图。左上小地图可点击直达,显示地名与坐标;右上是人物/召唤兽气血;
  左下聊天频道(综合/当前/队伍/系统)收 NPC 闲话、队伍拌嘴与系统消息;右下图标栏(道具/角色/召唤兽/任务/阵型/设置);
  底边历练条。入战有墨色旋屏。
- **日常·封妖令**:一借之后,村里土地头顶亮青色「令」时领取。火妖在场上明处游走,追踪条写明场景与坐标,点追踪即走过去开打
  (炉砖火妖/火炎小校各带两只砖缝火苗,两三回合可清,敌方等级随队伍);得历练、银两与掉落(金疮药/法力丹/二阶兵甲),
  向土地回报领下一环(人在火口时火口土地也收),十环一轮另赏二阶装备。
  **等级上限 = 剧情设计等级 + 1**,刷满只得银两与掉落。
- **商店与研习**:卖糕少年(药铺:金疮药/法力丹/捕妖绳/九转回魂丹)、庄上老者(铁匠铺:一阶兵器/护甲);
  「角色」面板可换装(兵器/护身两槽,三阶),也可花银两把法术研习一重。
- **流程(第59-61回全战役)**:标题 → 火焰山庄问土地 → 翠云山一战罗刹女(+侍婢,第3回合被吹飞·剧情)
  → 灵吉授定风丹 → 再战取假扇 → 火焰山火兵战(假扇反火;校尉召唤;捕妖绳收服赤焰火骝)
  → 火脉残图寻宝(探路者/五行明牌/收手或深入)→ 摩云洞·玉面公主对峙(+妖将×2)
  → 初战牛魔王(赴宴而走·剧情)→ 碧波潭·变螃蟹偷金睛兽
  (三节点:变化/潜入/偷兽,错一次即由悟空纠正)→ 辟水金睛兽入队 → 变牛魔王骗真扇
  → 假八戒反骗(可识破) → 积雷山决战(牛魔王+玉面公主+妖将 多人;八戒土地接力回血;
  白牛真身;哪吒率众神门控助战;真扇三段)→ 四十九扇断火根(结局演出)→ 还扇西行。
- **回合**:每回合先为每位伙伴依次下指令(攻击/法术/防御/道具/特技/自动/逃跑/沿用/保护/挂机),
  下完后双方按**速度从高到低**依次行动(顶部行动顺序条,带速度值与「抢」位标记),逐个演出:扑击、飘字、
  血条与「第N回合」都跟着演出一格一格走,底栏「战况」逐行记下谁打谁、掉多少、相克/暴击/受克。
- **五行相克**:金→木→土→水→火→金(指令面板左格常驻相克环)。相克 ×1.5:数字加大并盖「金克木」式印;
  受克 ×0.66:数字旁标小字「受克」;悬停目标可预览 相克/受克/寻常。悟空(金)克罗刹女(木);
  火兵战由悟空变玄甲龟将(水)克火;碧波潭后入队的辟水金睛兽(水)克牛魔王人形(火),八戒(木)克白牛真身(土)。
- **法力经济**:法力金贵——一场 BOSS 战每人只够放 4–5 次技能;普攻穿插防御(回 10% 蓝),
  「何时开大」是核心决策。
- **敌方 AI**:敌方也读五行——单体技优先打**会克它的**目标,其次拆**正在给全队上增益**的
  支援位,再次打它能克的,同档内取血量最低者。所以把悟空变成克敌形态、或让水系携宠上场,
  代价是自己成为集火目标;沙僧开罗汉金身,代价是他先被拆。BOSS 每 3 回合蓄力预警、
  下回合重击(约 60% 最大血,这一击固定锁血量最低者)——让血量最低者防御,或提前开罗汉金身。
  BOSS 战「自动」只普攻。
- **指令**:攻击不耗法力;法术耗法力(单体/群体/增益减益,按钮标注 目标·类型·五行·法力);
  防御减伤一半并回法力;道具(金疮药/法力丹/回魂丹/捕妖绳/芭蕉扇,带彩绘图标);特技=愤怒特技(挨打攒愤怒,人人可用:
  破血狂攻/罗汉金钟/四海升平)与悟空「七十二变」;保护=替一位伙伴挡这一回合的单体物理攻击与 BOSS 重击(自受七成);
  自动=AI 代打这一回合;挂机=寻常战斗里全队此后每回合自动,点场上「挂机中·点此接手」收回(BOSS/剧情战里不摆这颗钮);
  沿用=复用上一回合的招式与目标,目标已倒则改打最前面的活敌;非 BOSS 战可逃跑(70%)。选目标时右键或「取消」退回菜单。
- **变化**:无消耗,三回合内改变五行/属性/技能:金甲神将(金·群体)、赤焰灵猿(火·火法)、
  玄甲龟将(水·硬克火敌、受克伤害减半)、蟭蟟虫(金·抢速);形态按钮会标注能克到场上谁。
  二借罗刹女一战中她气血≤55%时挂出「疲态·可智取」,此时变化(菜单里蟭蟟虫高亮)可触发「化虫入腹」直接取胜。
- **阵型**:天罡阵(攻+20% 速+5% 但受伤+15%)/ 六丁阵(防+18% 受伤×0.8 速-5%)。
  战斗内点右上「阵型」按钮**免费切换,每回合一次**(战斗中顶栏只留「设置」);战斗外用右下图标栏「阵型」。
- **败北**:败北卡给出这一战的锦囊;有未分配潜力时可「先去加点」再战;寻常战斗可「回城整顿」(封妖的火妖还在原地)。
  战斗里用掉的丹药与绳子,胜利或脱身后真正扣除;败北重来按开战前的数目。
- **火脉寻宝**:火兵战后选悟空/八戒/沙僧探路。金木水火土明示遗珍/连脉/丹药/妖气/稳藏倾向；
  外层三掘后可见好就收,或先封存所得再深入两掘。悟空标出深层妖穴、八戒每层首掘连开邻格、
  沙僧挡一次妖气。深层妖气满格只丢深层所得；成功必得大还丹与一重修炼心得。
- **连击**:暴击时 25% 概率追加一次减伤普攻,盖「连击！」印;暴击盖「暴击」印。
- **定风丹**:持有时扇风与妖丝的减速根本不落身,只飘「定风」;状态签一律写作「名·N回合」。
- **芭蕉扇**:假扇使火敌攻击提升(反噬);真扇三段**无视敌方属性**:一息火(清敌增益+全体减攻30%)、
  二生风(全队提速)、三落雨(持续回血+敌方破防25%+破绽:受伤+60%)。白牛真身每回合独立狂暴叠攻12%,
  一息火可清狂暴层;三段不可倒退,须自行判断使用时机。
- **成长**:决战前的三场完整胜利与两场剧情退出均全员升一级 + 每人 5 潜力点、1 修炼点(右下「角色」图标朱印提示未分配点数);
  法术按等级解锁,修炼点可手动提升熟练(威力+6%/级、法力消耗-2,上限3),决战前达 Lv6;最终战不再发下一等级成长。
- **装备/法宝**:兵器/护身两槽三阶,小幅 flat 属性(一阶铁匠铺买、二阶封妖掉落、三阶摩云洞剧情三选一);法宝只做规则型(定风丹:速+6 免疫减速;避火锦:火伤减免25%),不加攻。
- **召唤兽**:辟水金睛兽(碧波潭三节点偷得)+ 火焰山用「捕妖绳」收服血气≤40% 的火妖(赤焰火骝);
  右下「召唤兽」面板选 1 只上阵(占正式行动位),宠同样吃成长/加点/熟练。
- **剧情演出**:一扇吹飞/赴宴而走(剧情退出,非失败);假八戒反骗(识破与否影响开局);众神围剿
  (白牛≤50%哪吒一次性助战,门控);四十九扇断火根(结局演出,非刷怪);还扇西行(不杀罗刹女/牛魔王)。
- **存读**:「设置」里存档/读档(localStorage),战斗与寻宝进行中不可用(战后对白里可以，但剧情战升了级、阶段还没落定的那段——一借后见灵吉、初战老牛后碧波潭——只能读完再存);过传送阵、进残图前、
  寻宝结算后和每场胜利后自动存档,读档回到所在场景并取消读档前的自动寻路。偷得金睛兽即落定「携扇下山」阶段;
  通关后标题显示「重温结局」。新开一局重新取种子(`?seed=` 固定时除外)。
- **音频**:Web Audio 程序化合成(零素材):五声音阶 BGM 分场景(标题/场景/战斗/BOSS/结局;碧波潭潜入用慢曲),
  首次点击或按键后解锁播放;切曲时整轨淡出不叠音,胜利后战斗曲淡出;入战一声铜锣;全套战斗音效(命中/暴击/相克/变化/真扇三段/蓄力/胜负)。
  「设置」里有静音、音乐/音效五档音量与战斗加速/跳过演出/震屏开关,均持久化。
- **界面**：彩绘人物与明亮山水舞台，大人物对白、浅色指令台、朱色当前指令；五行字徽、气血/法力与状态条始终保留(气血条写数字,法力条只看长短)。窄屏采用敌我分层和底部导航，不是桌面缩略图。

## 扩展点

- **新角色/敌人/技能/阵型/道具**:只改 `js/data.js` 数据表,引擎与界面零改动。
- **新战斗**:在 `data.js` 的 `BATTLES` 加一项(敌人列表、背景、是否 BOSS、彩蛋),
  在 `main.js` 战役流里接一个 `runBattle(...)`。
- **新形态**:`data.js` 的 `FORMS` 加一项(五行/属性修正/附带技能)即可进「七十二变」菜单。
- **BOSS 多阶段**:敌人数据 `nextPhase` 指向下一个形态定义。
- **缺美术**:`assets.js` 按键名加载,缺失自动回退色块头像与渐变背景,不影响运行。

## 已知边界

- 存档记录战役阶段与养成,不记录战斗或寻宝中途状态;战斗与寻宝中不可存读。寻宝中断后从残图开头重来,不会重复结算奖励。
- 存档格式升版后旧档不迁移:标题页提示一句「旧版存档与这一版不相通」并从头开局。
- 封妖挂机多数两三回合收场;自动指令偶尔把头两回合花在减益与落空上,会拖到第四回合(Lv.2 约一成)。
- 非 Boss 战可逃跑或败北后回城整顿(回场景重试);败北后也可换种子重试当前战斗。
- 场景外的气血/法力不保留伤势(每战满状态开打);日常封妖会让杂兵战更好打,决战全程自动仍不胜(引擎自测)。
- 全战役验收覆盖桌面 1440×900；窄屏、常速过场、低动效及其他浏览器未测。

补充回归：`npm test` 运行文案合同、战斗规则与寻宝规则；数值以 `js/data.js` 为唯一事实源。完整战役证据仍由上面的权威入口产生。
