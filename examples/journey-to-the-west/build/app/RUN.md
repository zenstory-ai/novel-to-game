# 西游记 · 三借芭蕉扇

回合制指令 RPG：带着师徒走过火焰山庄、翠云山、火口与积雷山，把芭蕉扇借来三回，降伏牛魔王，扇灭八百里火。零构建，原生 ES Module。

## 启动

```bash
python3 -m http.server 5273
# 浏览器打开 http://127.0.0.1:5273/
```

桌面横屏 1280×800 起最合适，手机竖屏也能玩。可选网址参数：`?seed=42` 固定随机种子，`&fast=1` 缩短演出与行走（自测用，规则不变）。

## 操作

| 场合 | 鼠标或触屏 | 键盘 |
|---|---|---|
| 场景 | 点地面行走，点人对话，点右侧任务追踪自动寻路，点小地图直达 | 方向键行走 |
| 对话与章节卡 | 点画面 | 空格、回车 |
| 战斗 | 点指令，再点格子或场上的目标 | 数字键选当前这一页的第几格，←／→ 翻页，Esc 返回上一步 |
| 面板 | 右下图标栏：背囊、角色、召唤兽、任务、阵型、设置 | Esc 关闭 |

头顶金色「!」是主线要找的人，青色卷轴是可领的封妖令，「?」是待回报。

## 结构

| 位置 | 内容 |
|---|---|
| `index.html` · `css/` | 入口与样式：`base` 色与字、`world` 场景界面与结局、`battle` 战场与指令台、`panels` 功能面板 |
| `js/main.js` | 启动、标题与整局的进出 |
| `js/data/` | 战斗数据表、四张场景的道路与地点、对白与抉择、美术路径 |
| `js/rules/` | 纯规则，浏览器与 node 共用：`battle` 回合结算、`campaign` 成长与封妖、`nav` 寻路、`treasure` 火脉残图 |
| `js/game/` | 主线编排、场景外层、残图界面、结局 |
| `js/world/` · `js/battle/` · `js/ui/` | 场景绘制与 HUD、战场演出与指令台、对话与功能面板 |
| `js/core/` | DOM 小工具、图片与声音、种子随机、本机存档 |
| `assets/` | 立绘、行走图集、四张场景的整幅绘景、战斗背景、图标与声音 |
| `test/` | `*.test.mjs` 规则回归（`npm test`）；`verify.py` 权威完整运行 |

加角色、敌人、招式、战斗或抉择只改 `js/data/`，不动规则与界面。

## 验证

```bash
npm test                 # 纯 node：战斗、成长与封妖、寻宝、寻路、对白与资源登记、上屏文案
python3 test/verify.py   # 真实浏览器从标题打到结局再重开，整份重写 ../../qa/verification.json
```

`verify.py` 只点界面、按键，并读取 `window.xiyou.snapshot()` 这份只读快照留证；不注入存档，不调内部接口。

## 部署

`build/app` 是纯静态目录，由 Vercel 的 Git 集成直接发布；`vercel.json` 只设缓存头，`.vercelignore` 排除测试与本说明。
