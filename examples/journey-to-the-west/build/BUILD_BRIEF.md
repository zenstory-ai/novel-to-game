# BUILD_BRIEF · 西游记·三借芭蕉扇

# 目标

`targetFinish: playable-prototype`

- 平台与交付物：浏览器里直接打开的静态站，零构建、零运行依赖（原生 ES Module，场景用 Canvas、界面用 DOM/CSS）；`build/app` 整个目录即部署物。
- 范围：原著第五十九至六十一回的完整战役——四张可走场景、主线 NPC 与任务追踪、封妖日常、六场战斗、火脉残图、碧波潭盗兽、成长与装备、结局与重开。
- 视口与输入：桌面横屏为主（1280×800 起），手机竖屏关键路径可用；鼠标、触屏与键盘都能从头玩到结局。
- 分级与联网：全年龄；无账号、无后端，存档与设置只写本机 `localStorage`。

# 必须保真

experienceProfile: `system-led`

- 循环：在场景里找头顶有记号的人推进主线 → 进指令回合战斗（逐个下令，双方按速度依次出手）→ 得历练与银两、加点修炼换装 → 回到场景。主线之间可接封妖令。
- 五行相克是胜负手：金克木、木克土、土克水、水克火、火克金，克制 ×1.5、受克 ×0.66；选目标时预览相克与伤害。五行在界面上是彩绘图标配字，不拿单字当图标。
- 原著因果不改：一借第 3 回合被一扇吹飞；二借把罗刹女打到气喘后变蟭蟟虫可化虫入腹；假扇越扇火越旺；真扇须依次扇出息火、生风、落雨；牛魔王打空后现白牛真身，五行由火转土；结局还扇西行。
- 选择有回响：借扇前稳阵或强攻、带定风丹或避火锦、假扇先试小火或直扇火口、收服的火妖留用或放归、摩云洞三件兵甲拣一件、碧波潭怎么潜入、是否识破假八戒，都在后续战斗、寻宝或结局的「这一路」里读得到。
- 尚未验明的扇子在背包里只叫「芭蕉扇」，用过才改名；头衔与章节卡不提前点破假八戒。
- 界面不出滚动条：战斗子菜单一页八格（窄屏六格），超出翻页，说明在侧栏；面板内容超出就分页。
- 关键画面：标题（火焰山前的悟空）、火焰山庄场景与任务追踪、敌左我右的战场与底部指令台、白牛真身现形、真扇三扇的全屏演出、雨后还扇的结局。视觉约束见 `design/ART_DIRECTION.md`。
- 存档：每场胜利、每次剧情抉择与进入残图前自动存档；战斗与寻宝进行中不可存读。
- 决战引导：真扇一扇未出时，每次下令都由土地传音点明「真扇在【道具】、三扇依次扇出、自动不会替你扇」，【道具】描金；有人领扇或扇出第一扇才收起，重打同样出现。不改数值，「自动」仍只普攻。
- 剧情抉择不带默认焦点：弹出后空格、回车不确认任何一项；键盘须先用方向键（或 Tab）挑中，弹出满约半秒后回车才算选定；点击不受影响。决战白牛真身伏地即胜，余众溃散，白牛在场时「此战」写明伏地即胜。灵吉授宝用小须弥山专属底景。
- 结局字幕一句一屏，只在点击、空格或回车时翻页，不自动跳；按住不放的连发不算翻页。右下常驻「点击或按空格继续 · 第几句/共几句」。标题上的「重温结局」走同一套。
- 预警与结算一致：老牛蓄力预警亮起时就锁定当时气血最少的伙伴，横幅、头顶「被盯上」与下令处都点他的名，下一回合重击仍砸向他（补血不换人，他先倒下才改落当时气血最少者）。白牛现形时土地立绘真的入场，横幅写「在场伙伴各回 30% 气血」并逐人飘数字。
- 图文一致：结局每句换对应地景（积雷山 → 烈火 → 火灭灰烬 → 风散灰雾 → 雨后 → 还扇西行）；碧波潭只写画面里看得见或听得见的东西；悟空变牛魔王骗扇时对白名牌与立绘用牛魔王模样；伙伴倒下侧倒留在原位。
- 可点即可用：游走的封妖火妖点身子、名牌或身旁一身位内都算点中，点中或悟空走近它就站定，走到跟前即开打。横幅、提示条与章节卡按字数给足停留，不随「演出加速」缩短；新一段对白弹出后约 0.35 秒内不认点击与按键，连点的余波不会跳过头一句；剧情抉择方向键到头即停，不回绕。新亮起的可点层——战斗指令台（每场头一回合约 0.6 秒、之后每回合约 0.35 秒）、战后结算卡、剧情抉择、确认框、章节卡——刚出现时都不认点击与回车，指针点击还要求按下发生在它亮起之后；未亮起时鼠标停在某个指令上也不描红，首战指点要点的那一格描金。
- 二借化虫窗口：下令时罗刹女还没露疲态，这一回合怎么打都只到三成气血的护身线（飘「护身退开」），保证玩家至少有一次看得见「疲态·可智取」再下令；疲态时「此战」改写为点【特技】变蟭蟟虫。硬打到她认输即当场判胜，侍婢随之收兵，横幅写明化虫的机会错过了，不留一个灰着站着选不中的她。
- 「沿用」按钮第二行写明要沿用的那条指令（如「金疮药 → 猪八戒 · 剩2」），沿用道具时描红；药没了或回血回蓝的对象已满，就改为防御并照实写出。
- 返工记录：2026-11-14 盲玩发现两处引导缺陷后修正——决战真扇提示原先只出一次（还被重打吞掉）；结局字幕原先约每 3 秒自动翻页、与提示语不符。两处都由 `npm test` 与 `test/verify.py` 的浏览器断言回归。第 2 轮（新独立盲玩后）：白牛真身打空后战斗仍要清残敌且目标不变，改为白牛伏地即胜并在白牛现形后换写「此战」；剧情抉择原先首项带默认焦点、空格即确认，改为不预选、键盘须先挑再确认；灵吉授宝原先借用芭蕉洞外战斗背景，改用新生成的小须弥山底景。回归：`npm test` 的白牛判胜与底景测试，`test/verify.py` 的抉择连按、灵吉底景、白牛目标与伏地即终断言。第 3 轮：二借不变身把罗刹女打到认输时，原先仍播化虫入腹分支的「出来！扇子给你」，改为按取扇方式分台词（`fanHandover`），打倒分支说「扇子拿去」。回归：`npm test` 的交扇分支台词测试。第 4 轮：蓄力预警点名后出手改打当时气血最少者，改为预警时锁定；白牛现形旁白写「八戒与土地从侧翼杀到」而画面无人，改为土地立绘入场并写明回血；直接点游走火妖不开战，放宽点选并让火妖被点中或走近时站定；结局第 3、4 句写火退而画面仍是烈火，新生成火灭灰烬地景 `bg/huoyan-ash.jpg` 并逐句换图。同轮按类别通查修了：设置面板裸文本「falsefalse」、残图「手中：无、残简 N」、同名敌人名牌截断（改用短名加甲乙）、碧波潭「碰杯」与悟空变牛魔王的图文、伙伴倒下即消失、道具用尽后格子前移、对白被连点余波跳过、抉择方向键回绕、横幅与提示条停留不足、本命兵器栏写「空着」。回归：`npm test` 的蓄力锁定、土地接力事件、结局逐句地景与文案测试；`test/verify.py` 的直接点火妖开战、蓄力点名与锁定一致、土地上场、结局字幕与地景一致断言。第 5 轮：二借化虫窗口一回合即过、罗刹女打倒后灰站不可选且「此战」仍叫变化，改为窗口护身线、疲态时改写「此战」、认输即判胜；进战前连点对白落到指令台上误下令，改为指令台亮起后短暂不认点击；「沿用」重复吃药且不显示内容，改为按钮写明将沿用的指令与余量、对满血对象不再吃药。同轮按类别通查修了：结算卡、抉择、确认框、章节卡同样防连点余波；首战指点与默认描红不一致；技能说明框截断并压住「已下令」；战斗指点气泡压住伙伴名牌；场景镜头让右侧卡片遮住前方 NPC；消息栏展开后仍写「展开」；已打退的把门妖将仍站在洞口；场景抉择卡挡住画面中央说话的人、结算卡挡住伙伴；「第三借」与「二调」回目对不上；修炼页上屏系数；触屏上的键盘提示。回归：`npm test` 的护身线与认输即胜测试；`test/verify.py` 的指令台防连点、「沿用」写明内容、疲态时「此战」改写断言。

# 运行

targetRuntime: 现代桌面与手机浏览器（Chromium、Safari、Firefox 的当前版本）
testedRuntime: Chromium（Playwright 自带的无头版本），1280×800 完整一局
engine: 无引擎、无框架；原生 ES Module + Canvas 2D + DOM/CSS。版本 NOT_AVAILABLE: 没有第三方运行库
commands:
  install: NONE
  start: `cd examples/journey-to-the-west/build/app && python3 -m http.server 5273`，然后打开 `http://127.0.0.1:5273/`
  test: `cd examples/journey-to-the-west/build/app && npm test`
  verify: `cd examples/journey-to-the-west/build/app && python3 test/verify.py`（`--out DIR` 把记录与截图写到 qa/ 之外，自测用）

操作：场景里点地行走或用方向键，点人对话，点右侧任务追踪自动寻路；战斗里点指令与目标，Esc 返回上一步。可选网址参数 `?seed=数字` 固定随机种子，`&fast=1` 缩短演出。其余见 `build/app/RUN.md`。

# 限制

- 完整一局只在无头 Chromium 的 1280×800 下由脚本走过一条路线；手机竖屏只做过关键画面与全流程的滚动条检查，没有在真机、Safari 或 Firefox 上运行。
- 路线覆盖：脚本走的是稳阵、定风丹、小试假扇、留用火妖、深入残图、识破假八戒这一条；强攻、避火锦、直扇、放归、收手、受骗失扇等分支只由 `npm test` 的规则回归覆盖。
- 设计估计的 45–90 分钟未经真人计时；数值是否有趣、是否平衡不由自动化判断。
- 声音：自动化只确认曲目与音效文件能加载。
- 未覆盖项的完整清单在 `qa/verification.json` 的 `limitations`。
