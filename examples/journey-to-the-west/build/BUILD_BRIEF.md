# 成品目标

`targetFinish: playable-prototype`

构建《西游记 · 三借芭蕉扇》：一段约 45–90 分钟、桌面浏览器可玩的单人**回合制指令 RPG 完整战役**，
《梦幻西游》《问道》那样一眼就认出的回合制西游——指令出招、速度行动顺序、五行相克、
法术与法力、携宠协战、阵型、七十二变——跟着原著第五十九至六十一回从火焰山脚走到
牛魔王两阶段决战与还扇西行。

第一版的质量标志是：中文玩家一眼认出的回合制西游玩法、忠于原著的战役、随手截图就像
一款回合制西游网游的彩绘画面，以及每回合有真决策（技能/相克/变化/携宠/真扇 明显强于无脑普攻）。

首发界面只实现简体中文。所有玩家可见文案集中管理，不把文字烙进图片；字体覆盖人物、
地名和法宝字形并允许商业发布。保留语言资源边界，为后续本地化留出替换能力。

# 必须保真

## 战斗契约

- 指令回合制：每回合先为每位伙伴下指令（攻击/法术/防御/道具/特技/自动/逃跑/沿用/保护；寻常战斗另有挂机），
  下完后双方按**速度从高到低**依次行动、逐个结算、飘出伤害数字。
- 五行相克成体系：金→木→土→水→火→金，相克 ×1.5（盖「金克木」式印）、受克 ×0.66（标「受克」）。
- 命中、暴击、伤害浮动为概率，但**全程走可设种子的 RNG**，保证自测同种子同操作可复现。
- 法术耗法力、物理不耗；防御减伤并回法力；携宠（辟水金睛兽，水克火）作为第四参战单位。
- 悟空「七十二变」临时改五行/属性/技能；阵型（天罡/六丁）改攻防速；都要有实际战术价值。
- 成长系统：升级发潜力点自由加点（体/攻/防/速/灵）、法术按等级解锁且用修炼点进阶、兵器/护身两槽三阶装备（商店、封妖掉落、剧情三选一）、
  规则型法宝（定风丹/避火锦，不加攻）、召唤兽剧情门控捕捉与上阵、物品背包；不做抽卡、门派数值墙、
  装备打造与交易、PVP 和 MMO 长线。

## 原作因果

- 火焰山八百里阻断西路，需借翠云山芭蕉洞铁扇仙（罗刹女，牛魔王之妻）的芭蕉扇。
- 罗刹女因红孩儿旧怨拒借；二借时她露出疲态，悟空变化「化虫入腹」可直接取胜（第59回）。
- 先得假扇，假扇使火更旺、火中生出火兵；火兵战由悟空变玄甲龟将或避火锦应对，辟水金睛兽严格在碧波潭桥段后入队（第60回素材）。
- 真扇在牛魔王处；悟空骗扇、牛魔王化八戒反骗，最终积雷山决战（第61回）。
- 牛魔王现白牛真身（多阶段）；真扇三段一息火、二生风、三落雨，还扇后师徒西行。

## 视觉风格

- 彩绘动画西游：明亮青碧山水配朱红、奶油白与金；人物有体积、成年比例，衣着依公版原著。
  详见 `design/ART_DIRECTION.md`。
- 彩绘战斗背景（翠云山/火口/积雷山/摩云洞/碧波潭）+ 敌左我右两排相向；底部满宽指令面板。
- 四种变化与白牛真身各有独立立绘；白牛体量放大一档；宠辟水金睛兽。
- 暖白宣纸底界面：行动顺序条、HP/MP/愤怒条、文字状态签、飘字（暴击红大、相克印、受克灰小字、
  治疗绿字，颜色之外都有字冗余）。真扇三段各有一段全屏着色与粒子，结局换成雨后火焰山地景。
- 声音：Web Audio 程序化五声 BGM 与战斗 SFX，首次输入后解锁；无语音，字幕承载全部信息。

# 范围

必须包含（共十段桥段，其中六段为战斗，其余为场景与剧情演出）：

- 场景外层：四张可走 2.5D 场景（火焰山庄/翠云山/火口/积雷山）与传送阵、主线 NPC 头顶「!」、
  任务追踪自动寻路、梦幻式 HUD（小地图坐标/头像气血/聊天频道/图标栏/历练条）、日常封妖（明雷）、商店与装备槽；
- 战斗1·翠云山初战罗刹女：教学（指令/速度序/相克/暴击），第 3 回合一扇吹飞（剧情退出）；
- 战斗2·翠云山再战：取假扇 + 化虫入腹智取（罗刹女挂「疲态」时窗口开启）；
- 战斗3·火焰山火兵：玄甲龟将水克火、地火逼迫换形、假扇反噬、捕妖绳收服赤焰火骝；
- 火脉残图：火兵战后一次 2–4 分钟短探索；三位探路者改写规则、五行明牌只报倾向而不精确泄露陷阱、
  悟空提供明牌外的妖穴情报、连脉揭格、收手凝成独占避火符或深入两掘换大还丹与修炼、深层软失败、道具与成长写回下一战；
- 战斗4·积雷山摩云洞前：玉面公主 + 妖将；
- 战斗5·摩云洞激战牛魔王：第 3 回合赴宴而走（剧情退出），引出碧波潭偷金睛兽；
- 战斗6·积雷山决战：多人对阵、八戒/土地接力、白牛真身两阶段、众神门控助战 +
  真扇三段翻盘 + 还扇西行结局；
- 标题/开场引导、五行相克可读性、阵型/七十二变/携宠、升级养成、存读、失败重试。

明确排除：抽卡、门派数值、PVP、MMO 长线养成、交易与打造、开放大世界、可杀死并改写原著
存活角色的分支、多人和后端。银两只在单人战役内流转；日常封妖受「剧情等级 +1」上限约束。

# 实现自由

根据环境自行选择框架、渲染、数据结构、状态管理、输入映射、原创程序化资产和测试入口。
优先做完灰盒战斗核心与可复现结算，再补彩绘立绘、背景与反馈；不要为了展示技术静默改成
实时动作或卡牌构筑。数据表驱动：新增角色/敌人/技能/阵型/战斗只加数据不改引擎。

范围压力出现时，依次压缩过渡演出、额外战斗和养成深度；不得删除指令回合、速度结算、
五行相克、携宠、变化、多阶段 Boss、真扇三段和 seedRNG 可复现。
