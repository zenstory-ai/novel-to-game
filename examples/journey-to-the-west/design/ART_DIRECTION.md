# 美术方向：《西游记：三借芭蕉扇》

`targetFinish: playable-prototype`

## 品类成色

**随手一张实机截图，应像《梦幻西游》《问道》这类回合制西游网游里的一张游戏画面**：3/4 俯视的
彩绘行走场景、四角压着 HUD 小卡、头顶名字与任务标记；战斗是敌左我右两排立绘、上缘行动顺序条、
底部指令面板。借的是品类的形制与可读性，不借它们的 Q 版大头、描边和具体角色设计。

## 视觉身份 · 彩绘动画西游

- **色系**：明亮的青碧群山配珊瑚朱红、奶油白与金色；行走场景与战斗背景同一矿物色系，人物和
  场景不出现媒介断层。界面是暖白宣纸底、朱色强调、金线细框（`--paper #fff8ec`、`--zhu #b8453d`、
  `--gold #bd8b43`、`--qing #357d77`）。
- **人物**：有体积的彩绘动画造型，成年正常比例，表情与肢体先于衣纹。悟空保留猴相、金箍和金箍棒，
  八戒猪相与钉耙，沙僧降妖宝杖与稳重轮廓；罗刹女依第 59 回的团花手帕、锦云袍与双青锋，牛魔王依
  第 60 回的铁盔金甲与混铁棍。不取任何现代影视或游戏角色设计，不画成泛仙侠美人。
- **字**：标题与名牌用宋体系衬线；文字不烙进立绘或背景，全部由界面层排字。图标负责识别操作，短名称负责确认，不把同一名称再放大写成徽章。

## 行走场景

- 四张宽幅 3/4 俯视彩绘场景（火焰山庄、翠云山、火口八卦炉砖、积雷山摩云洞），主路、支路、建筑与地貌在一幅连续绘景中组织成多个相连分区，不以中央大空场或零散贴图承担全部活动。行走人物另制约 40° 俯视的站姿图，头顶、肩背与脚面服从地面的机位；身份服饰与战斗立绘连续。脚底锚点对齐地面，接触影贴脚并有柔和方向投影，远近体量随地面深度温和变化，按朝向镜像；步态不让整个身体摇摆或跳离地面。
- **名字与标记**：主角名绿、NPC 名黄、妖怪名红、传送阵青，称谓小字在名上。主线 NPC 头顶金色「!」，
  日常（封妖令）可领时为较小的青色「令」，待回报为「?」——主线与日常不共用一个记号。
- **传送阵**：青色光圈加「→ 去处」字签；点字签与点光圈等效。未开的阵灰色并写「（未开）」。
- **HUD**：左上小地图与坐标，右上头像气血法力银两、任务追踪卡（点一下自动寻路），左下四频聊天/
  系统日志，右下彩绘功能图标（锦囊、悟空、水兽、卷轴、阵列、青铜齿轮）配短名称。消息默认只露最新一条，展开后再看频道与历史。HUD 压在四角，不挡画面中央。
- 入战墨色旋屏；升级与任务更新用居中金字，两秒自消。

## 功能面板

角色、背囊、召唤兽、任务、阵型、设置共用暖绢底、细金边、朱红选中态、相同标题与关闭按钮。标题、内容和底部操作各有自己的空间，正文内部滚动；桌面与窄屏都能看到关闭和主要操作。

角色与召唤兽一次查看一名成员，肖像选择与详情分开；概览、修炼、装备按任务分层。属性使用心形生命宝石、兵器、盾、云靴和法珠图标配完整短名称；五行使用金锭、竹叶、水滴、火焰、山石图标，不重复写大字徽章。空装备槽用淡化器物图与一句状态说明。

背囊是实图格子与选中详情，法宝单独成卡；任务突出当前目标和追踪入口；阵型突出当前方案与代价；设置把音频、战斗偏好和存读分组。默认只展示当前需要的说明，不把养成规则与全部操作堆在总览。

窄屏左上保留小地图与地点坐标，右侧为紧凑队伍状态；小地图按真实地图与标记缩放，点击仍可移动，不能为了省空间直接隐藏。

面板主体统一为不透底的暖绢色，世界只通过一层轻遮罩压暗；嵌套弹窗不叠加暗度。标题与44px关闭按钮常驻，正文独立滚动，窄屏短面板按内容取高，保持外部返回区域。角色/召唤兽沿用宽布局，背囊和任务按内容收窄。

## 战斗画面

- **对阵**：彩绘背景远景山门留在上半部，人物是下半部主体。敌方一组居左，我方一组居右，各自前后错落
  斜排，在同一水平带上相向而立（我方立绘水平翻转朝左）。固定单屏，不做旋转相机。
- **顺序与焦点**：上缘一条行动顺序条按速度排列小头像；当前单位头顶金色箭头、立绘外光；可选目标
  描金。选中目标即在顶部预览「招式 → 目标 · 约伤害区间 · 相克/受克 ×倍率 · 命中」。
- **指令面板**：满宽底部面板。左格是当前伙伴的半身近景、五行徽与常驻的五行相克环；右格两行指令
  （攻击/法术/防御/道具/特技，自动/逃跑/沿用/保护）；主要操作用金箍棒、法珠、盾、锦囊与变化云图标，次要操作只留名称。子菜单
  在同一面板内展开。寻常战斗另有「挂机」开关。窄屏重排为底部紧凑网格。
- **名牌与条**：立绘下名牌、朱红气血条叠数字、水蓝法力条、橙色愤怒条；其下一行文字状态签
  （增减益「名·N 回合」、形态签、防御）。不靠纯图标。
- **文字层级**：地点名用于入场报幕，首道号令后收成小地名签；技能规则在选中预览与详情中读。保留五行字、气血、消耗与必要状态，不常驻重复标题或大段操作说明。

### 五行与反馈（颜色之外都有字或字号冗余）

| 功能 | 表现 |
|---|---|
| 五行徽 | 立绘左上圆徽，金 `#b8912a`、木 `#3e7d3a`、水 `#2a6b8a`、火 `#b03a24`、土 `#7d5a34`，徽内写字 |
| 相克命中 | 更大的伤害数字，目标身上盖「金克木」式三字印，并加重一次震屏；战况行写「相克」 |
| 受克命中 | 数字旁一枚小号灰字「受克」；预览与战况行同用「受克」一词 |
| 暴击 / 连击 | 更大的红色数字加「暴击」印；「连击！」印 |
| 落空、治疗、回蓝 | 灰字「落空」、绿字「+n」、蓝字「法力+n」 |
| 疲态（二借） | 罗刹女气血跌破阈值时，状态签多一枚金边脉动的「疲态·可智取」，特技菜单里蟭蟟虫同时高亮 |

震屏短促即收（普通 2px，暴击/相克 4px），设置里可关震动、跳过演出、战斗加速；低动效下保留当前行动标记。

## 识别规则（玩法即画面）

1. **变化先换形态轮廓**：金甲神将、赤焰灵猿、玄甲龟将、蟭蟟虫各有独立立绘与五行徽，变化时一团
   烟雾换形；形态签写「形态名·五行」。不同形态不共用一套立绘。
2. **体量即信息**：牛魔王人形倒下后撑起白牛真身——立绘放大一档、五行由火转土，阶段横幅点明。
   辟水金睛兽是矮伏的兽形宠，不与主将抢轮廓。
3. **化虫入腹**（第 59 回）：二借中罗刹女露出疲态时悟空变化，一只小虫飞入、全屏压暗，旁白结算
   取胜。智取胜于蛮打，不做血腥表现。
4. **假扇反噬**：火势从左侧倒卷、朱红压屏，用世界的反应否定预期，而不是弹错误提示。
5. **真扇三段**：每段一条青绿描边横幅，接一段两三秒的全屏着色与粒子——息火落灰、生风风痕、
   落雨雨线。持久的世界改变放在结局：火焰山换成雨后无明火的新地景（`huoyan-rain`），重开按钮常驻。
6. **火脉残图**：九宫地块未掘只露五行实图，掘开才写藏物；悟空识破的妖穴以朱边与短名称提示。上方同时
   写妖气四段条、掘数分数与「已护住 / 手中」两行，风险不依赖颜色。

## 对话与标题

- **对话**：半身立绘入前景，姓名、正文、推进提示分层；旁白时撤下人物。空格、回车和点击都可推进。
- **标题**：满幅山火与行旅人物，书名与「踏上火焰山 / 接着西行」组成前景。
- **文案声口**：悟空干脆、自负，被识破时也会噎住；八戒先顾吃喝与吃亏；沙僧说眼前要做的事；
  罗刹女念孩子、记仇，不替玩家总结主题。旁白只交代看得见的动作，规则在教学卡与帮助里说清。

## 首次借扇的反馈节奏

借扇准备与试扇选项沿用现有对白和选择卡，先写人物行动，再写本次战斗的具体后果。首战以紧凑提示条
指出当前伙伴、攻击入口和木行目标，不先用模态长文压住战场；玩家可以展开完整指令。
首次真实克制命中把金行、木行、实际伤害和 ×1.5 连在一起，配合现有命中音与印章，随后保留短说明供读完。
后续命中恢复原有节奏，低动效时仍以文字与五行字徽表达；防御知识在下一回合介绍。

## 声音

- **已实现**：Web Audio 程序化合成，零音频素材。五声音阶分场景 BGM（标题、行走、战斗、首领战、
  结局）；战斗 SFX 覆盖命中、暴击、相克、治疗、变化、蓄力预警、重击、真扇三段、假扇、升级、胜负，
  行走有脚步、银两、任务铃、传送与入战锣声。首次点击或按键后解锁播放；设置里可静音并分调音乐/音效。
- **语音**：`none`。字幕承担全部信息，关掉声音不丢任何玩法信息。
- **未实现**：以戏台锣鼓、寺观法器为骨的配器（金箍棒木铁撞、钉耙宽短土声、变化木鱼三拍等）只是
  方向，现版仍是合成音色。

## 实机验收

实机要看：敌左我右两排在满屏立绘下始终可辨；五行徽、气血条与「相克 / 受克」反馈不靠颜色也能分清；
四种变化各有独立轮廓；白牛真身的体量升级一眼可读；结局火焰山确实换了地景；寻宝界面同时看清五行
倾向、妖气、掘数与两层所得。

## 2026-11 地图扩展方向

四图使用3:2的高处俯视构图，以可探索的多个街区、林道、冷石台和山门支路代替中央大空场。建筑与人物保持既有体量，扩的是可走空间与地标关系；路面、台阶、桥面、岩壁与水火危险边界一眼可分。地图无烙字、无预画角色与界面。

村庄以干旱土黄、暖红屋墙和青石压住酷热；翠云山以冷绿芭蕉竹林与溪桥表现凉意；火口以可走暗红冷石对比明亮熔岩；积雷山以紫灰岩、红枫、金色兽首洞门和临潭高台表现妖王排场。每图保留入口到主目标的清楚视线线索，并用实物、颜色与轮廓区分两处支路地点。

探索点对应底图中的井车、田渠、芭蕉林、药篓、炉砖、石龛、辎重与望台；只补轻微地面光环或闪光和靠近时短名称。已完成点收成青玉色，不用大字徽章或一屏常驻地点清单。

## 地图可读性修订（2026-11-02）

最终生产画面采用完整绘景地图。房屋院墙、树石、水火、桥面和生活陈设直接融入连续地貌，疏密与色彩共同区分主路、支路和危险边界；试制的独立物件与材质不再随运行包加载。角色、交互路线和小地图标记继续动态绘制。

每张地图根据共同构图与布局引导分别生成 2×2 重叠分块。单块原图约 1536×1024 像素，对应 1320×880 逻辑单位；四块位置依次为 `[0,0]`、`[1080,0]`、`[0,720]`、`[1080,720]`，横向重叠 240、纵向重叠 160 逻辑单位。相邻分块分别应用互补的横、纵原生 Alpha 蒙版，以加法合成各块的预乘颜色，保证四块交会处权重之和仍为一。世界缩放后单块显示为 1518×1012 CSS 像素，约为源图的 0.988 倍，不再放大旧低分辨率整图。

当前场景的静态绘景按实际设备像素比缓存；DPR 2 时缓存为 5520×3680，每帧只按相机窗口做物理像素一比一拷贝。道路中心线、物件占地与角色脚点 18 逻辑单位净空继续服务导航和碰撞，并指导绘景布局；屋檐、树冠的视觉范围参与阻挡，避免人物脚点进入背景中的建筑或树冠。几何规则能证明角色按设计路径移动，不能自动证明生成画面中的路岸、门洞和建筑与数据吻合，仍需用实际画面和移动轨迹逐处校准。

## 街巷与地貌的完整构图（2026-11-02）

用户两次指出低对比地面加独立摆件仍然单调，否决把降低噪声等同于留大片空白。村庄先以 `visual-targets/village-street.webp` 校准整段街巷的成色：房屋院墙连成聚落、井台接生活区、旱田形成边界，道路用真实土石材质与疏密区分主支路。该图是美术目标，不是实机验证。

以实际布局引导图约束共同绘景，固定路口、建筑基底、出口与分块重叠区，再以共同构图为参考分别生成四个重叠窗口。绘景中已有的静态景物不重复叠独立贴图。四图已逐一通过画面与移动检查：村庄街巷、翠云木桥、火口石道和积雷湖岸均有实机证据；定向浏览器测试与完整战役证据分别保存在 `qa/evidence/maps/` 和 `qa/verification.json`。

## 战斗与对白的阅读层级（2026-11-03）

沿用功能面板的暖绢底、细金边、朱红当前态与现有彩绘图标。战斗中选令、目标预览、报招、命中各有主次，取消角色头顶的重复技能名飘字，以统一出手提示作为报招焦点；伤害与金克木等关系跟随目标反馈，用图形、短标签和实际扣血共同表达。默认战报只显示最近结果，历史可展开完整阅读。窄屏将敌我分成上下两排，教学与目标预览按当前步骤复用底部信息区，给角色和点击目标留出空间。预览保留当前决定所需的目标、区间与五行关系，教学只随当前步骤露出，不能把说明铺满舞台。

对白保留原正文与人物身份，姓名、正文、进度和继续按钮分区；不以缩小字号装进过多文本。桌面人物与对白留出彼此空间，窄屏正文独立滚动且继续操作常驻。选中文字、滚动与拖动不推进剧情；静音、低动效与跳过演出仍能辨认出手者、招式、命中结果和相克关系。
