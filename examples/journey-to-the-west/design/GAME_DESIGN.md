# 游戏设计：《西游记：三借芭蕉扇》

> 文中数值是设计意图，精确值以成品数据为准；调参若改变下文的策略关系，再回写对应段落。

首发面向中文玩家，界面使用简体中文；玩家不需要读过原著，但原作术语、人物关系和
佛道民间信仰的区别不能被通用奇幻词替换。首次出现的生僻名物用战斗后果和一句短提示
解释，不用知识问答考玩家。简繁对应与角色/地名/物件/规则四类专名术语表维护于
`analysis/SOURCE_BIBLE.md`「统一术语表」，为后续英文等本地化提供依据；第一版不实现
语言切换。

海外本地化必须重新验证名称、宗教概念、幽默和角色关系，不能只替换字符串。回合制指令、
五行相克、法术法力和携宠阵型的心智可以跨文化复用，《梦幻西游》《问道》一代玩家熟悉的
回合制西游只作为这套语法的证据，不作为西游文化和视觉风格的来源。

## 玩家承诺

你是孙悟空，带着一支五行互补的取经队伍走进火焰山这一段连续劫难。每回合你为每位伙伴
下达指令，看着双方按速度快慢逐个出手、飘出伤害数字与「金克木」式相克印、「受克」小字，再用五行、变化、
法宝和携宠把一场看似只能硬拼的对阵扭成可解的棋局。最终奖励不是通关动画，而是罗刹女的
真扇一息火、二生风、三落雨，师徒在雨后穿过八百里火焰山。

## 类型与体验支柱

experienceProfile: `system-led`。

这是《梦幻西游》《问道》风格的**回合制指令 RPG**：敌左我右两组错落斜排、相向而立的对阵，顶部速度
行动顺序条，底部指令面板出招，五行相克与法力法术构成战斗骨架。战斗之外是梦幻式的**场景外层**
（见下文「品类外壳」），加一次火脉寻宝短循环，串起第五十九至六十一回的可玩桥段与结局，是
「三调芭蕉扇」约 45-90 分钟的完整战役。

三个支柱按优先级排序，每条配可观察运行证据与会否决它的失败现象：

| 支柱（按优先级） | 可观察运行证据 | 否决现象 |
|---|---|---|
| **五行相克成体系**：金克木、木克土、土克水、水克火、火克金；克制 ×1.5、受克 ×0.66。选对属性、用对携宠与变化，是比堆伤害更重要的胜负手 | 选中目标时预览相克/受克，指令面板左格常驻相克环，相克命中盖「金克木」式三字印；牛魔王由火转土后，原有最优解法失效，须换八戒（木）或变化应对 | 无视相克全程无脑普攻，也能以相近回合数打通战役 |
| **指令回合的经典手感**：速度序、法力经济与防御取舍构成每回合的真选择 | 顶部行动顺序条可读；法力有限时攻击、法术、防御、道具各有当选局面 | 每回合存在一条无脑最优指令 |
| **胜利写回世界**：战斗结果改变世界状态，而非只弹「敌人已击败」 | 假扇一用火敌变强；真扇三段各有专属演出（息火灰烬、生风风痕、落雨甘霖）；牛魔王现白牛真身换立绘换五行；结局雨落、还扇西行 | 打赢只弹结算框，场景、后续对阵与结局与打之前毫无差别 |

发生范围冲突时，先删过渡演出、敌人招式和养成深度，不能删五行相克、真假扇三段因果和
牛魔王多阶段变身。

## 核心循环

```text
为每位伙伴下指令（攻击/法术/防御/道具/特技/自动/逃跑/沿用/保护）
  -> 生成含敌方的行动队列，按速度从高到低排序
  -> 逐个结算：命中→暴击→五行系数→伤害浮动，屏幕飘字
  -> 每次行动后判定死亡与胜负
  -> 一方全灭则本场结束，否则进入下一回合
  -> 胜利后得历练与升级、按等级解锁新法术，回到场景
```

玩家的乐趣来自：读懂对阵里的五行关系，为当前敌人挑选克制它的角色、携宠、变化或法宝；
在法力有限时权衡攻击、法术、防御回蓝与道具；在真假扇、多阶段 Boss 这类剧情节点上做出
正确决策。

### 外层循环：品类外壳与第一分钟

```text
在场景里点地行走 / 点任务追踪自动寻路(可跨传送阵)
  -> 找头顶「!」的 NPC 推进主线(对话 → 剧情战 → 回到场景)
  -> 主线之间:找头顶青色「令」的土地领封妖令,点明处游走的火妖开打(明雷)
  -> 得历练/银两/掉落 → 升级、买药换甲、银两研习法术
  -> 回村回报土地(头顶「?」)领下一环(十环一轮另赏二阶甲兵),或继续主线
```

| 品类外壳 | 状态 | 做法 / 理由 |
|---|---|---|
| 进入世界与移动 | 实现 | 四张可走 3/4 场景（火焰山庄、翠云山、火口、积雷山），点地行走、方向键行走，青色传送阵（点阵或点阵名） |
| 目标指引 / 追踪 | 实现 | 主线 NPC 头顶「!」，右侧任务追踪点一下自动寻路、可跨图；左上小地图 |
| 明雷与日常环 | 实现 | 借扇后开放封妖令，十环一轮；火妖明处游走，点击即战；等级上限 = 剧情等级 + 1，刷不穿决战 |
| 成长与回访 | 实现 | 历练升级、潜力点、修炼点、银两研习、愤怒特技（见「升级养成」） |
| 商店与装备 | 实现 | 卖糕少年卖丹药与捕妖绳，铁匠铺卖一阶兵甲；兵器 / 护身两槽三阶，二阶来自封妖，三阶剧情三选一 |
| 召唤兽 | 降级 | 两只固定宠（辟水金睛兽、可捕的火妖）选一上阵；无收集池、繁殖、洗练——一段 45-90 分钟战役用不上 |
| 聊天 / 社交 | 降级 | 左下四频（综合/当前/队伍/系统）只承载系统消息与 NPC 闲话；没有其他玩家 |
| 组队 / 交易 / PVP | 不做 | 单机离线作品，没有第二位玩家；师徒四人就是固定队伍 |

- **第一分钟**：开局落在火焰山庄，土地头顶「!」、顶部一句提示、右侧追踪闪动；点土地或点追踪都能走过去。
  问完土地，系统栏记一行「获得 金疮药×2、法力丹×1、捕妖绳×2」。
- **主线由人触发**：每段剧情战都由场景里的 NPC 开启（罗刹女、火口的土地、玉面公主、牛魔王、下山路上的「八戒」）；
  打完回到场景，玩家有空隙整顿加点、换装。「八戒」出现时真八戒正跟在队尾——识破的线索就在画面上。
- **日常封妖**的由头是第 60 回土地原为兜率宫守炉道人：火妖从八卦炉砖里钻出。银两只来自剧情战与封妖。

### 支持循环：火脉残图

火兵战后，火炎校尉遗下一张炉砖残图。它不是新的长线养成，而是一段约 2–4 分钟的主动短局，
把战斗外的“观察 → 取舍 → 带回可用物”补进战役节奏：

```text
选择探路者（悟空识破 / 八戒连掘 / 沙僧护物）
  → 读五行明牌：金、木、水、火、土只报倾向，同行可同时有藏物与妖穴
  → 外层付费三掘，连脉可免费揭开相邻地块
  → 见好就收，保全所得；或把外层所得封存后再探深层两掘
  → 深层成功必得大还丹与一重修炼心得；妖气满格只损失深层所得
  → 道具、潜力与修炼点立即写回队伍，在下一场摩云洞战斗中可读
```

地图顺序由战役种子独立生成，不占战斗随机序列；同一种子、同样选择得到同一地脉。五行是概率倾向而不是
藏物类型：每处妖穴都与至少一处非陷阱共用同一明牌，玩家不能凭五行精确逆推。三位探路者改变的是规则而非掉率
数字：悟空在深层标出两处真妖穴，提供公开五行无法推出的新情报；八戒每层第一掘连开相邻格，可能连宝也可能惊妖；
沙僧抵消全局第一次妖气反扑。外层所得在深入前已经护住，软失败不会回退战役。此刻收手固定把封炉余火凝成一张避火符，
且深层不会再掉落该符；深入则放弃这份独占稳收，换取大还丹与修炼心得。两条路线因此交换不同的下一战资源，而不是让无风险深入同时拿走收手收益。

## 回合结构

一个回合严格按以下顺序推进，界面与结算共用同一套规则：

1. **我方逐个下指令**：界面让每位在场伙伴依次选择指令；玩家未指定的伙伴按「防御」补齐，
   敌方一律由 AI 补齐指令。
2. **生成行动队列**：把所有存活单位（含敌方）按**有效速度降序**排成一条队列。
   速度已计入阵型、变化形态与增减益修正；同速时我方优先，再按固定入场顺序，完全确定。
3. **逐个结算**：沿队列取出每个单位——先清除其上回合的防御姿态、结算「落雨」持续回血、
   判定眩晕（被晕则跳过），再执行它这回合的指令并即时飘字。
4. **死亡与胜负判定**：每次行动后立即检查；有单位体力降到 0 则死亡（Boss 若有下一阶段则
   换阶段而非死亡）。敌方全灭 → 我方胜；我方全灭 → 战斗失败；胜负一旦判定立即结束本回合。
5. **回合末计时**：所有增减益回合数减一，到期移除；变化形态计时减一，到期还原五行。
6. **下一回合**：回合数加一，回到第 1 步。

没有站位格、没有移动步数、没有潜入与身份怀疑；一切在这条速度队列上以指令和数值结算。
命中、暴击和伤害浮动共用一个种子随机数序列：固定种子后，同一串指令得到同一结果，问题可以原样复现。

## 战斗系统

### 属性

每个单位有六项数值属性和一个五行属性。属性 = 1 级基础 + 每级成长 ×（等级 − 1），我方再加潜力点；
敌方等级随战役逐幕上调，使中后期仍有挑战：

| 属性 | 作用 |
|---|---|
| 体力 | 归零即倒下（Boss 触发换阶段除外） |
| 法力 | 施放法术与七十二变的消耗，防御可回蓝 |
| 攻击 | 物理招式的伤害基数 |
| 防御 | 减免所受伤害；公式里按半值抵扣 |
| 速度 | 决定行动队列先后 |
| 灵力 | 法术招式的伤害基数 |
| 五行 | 金/木/水/火/土之一，决定相克关系；变化会临时改写 |

### 五行相克

相克链为**金克木、木克土、土克水、水克火、火克金**。
攻方克防方，伤害 **×1.5**，数字加大并盖「金克木」式三字印；攻方被防方克，**×0.66** 并标小字「受克」；无关系 ×1.0。
预览条、战况行与飘字统一用「相克 / 受克」两词。
典型关系：悟空（金）克罗刹女（木）；辟水金睛兽（水）克一切火妖；八戒（木）克白牛真身（土）。

### 伤害公式

伤害按固定顺序计算，每一步的随机都取自同一个种子随机数序列：

```text
攻击力  = 法术取灵力，物理取攻击               // 均为计入阵型/变化/增益后的有效值
base    = 攻击力 × 技能倍率 − 防御 × 0.5       // 下限 1
dmg     = base × 五行系数(1.5 / 0.66 / 1.0)
若暴击(概率 = 单位暴击率 + 技能暴击加成)：dmg × [1.5, 2.0) 随机
dmg × [0.9, 1.1) 随机浮动
若目标处于防御姿态：dmg × 0.5
dmg × (1 − 减伤增益)                            // 如沙僧罗汉金身
dmg × (1 + 破绽)                                // 真扇落雨的破绽，+60%
若攻方克目标且目标带受克护盾：dmg × 0.5         // 玄甲龟将变化期间
若目标有该五行抗性：dmg × (1 − 抗性)            // 法宝避火锦对火 −25%
若目标为我方且阵型有受伤修正：dmg × 受伤系数     // 天罡阵 1.15 / 六丁阵 0.8
最终伤害 = max(1, 四舍五入)
```

**连击**：任意一次暴击命中后，若目标未倒，有 **25%** 概率追加一次减伤基础攻击并盖「连击！」印。
它让暴击不只是一个更大的数字，而是会改变本回合结算长度的事件。

**命中**：命中率 = 技能命中（未设定时 0.95）+ 命中增益，限定在 5%–100%；未命中飘「落空」；暴击加盖「暴击」印。
基础攻击命中 0.95、倍率 1.0、不耗蓝。

### 指令

选中伙伴后从以下指令出招：

| 指令 | 效果 |
|---|---|
| 攻击 | 基础物理单体，命中 0.95、倍率 1.0、不耗蓝 |
| 法术 | 消耗 MP 施放已习得技能（单体/群体/增益/减益）；蓝不够或未习得则回退为普攻 |
| 防御 | 本回合受伤 ×0.5（持续到下次行动前），并回复 10% 最大法力（下限 1） |
| 道具 | 使用金疮药 / 法力丹 / 捕妖绳 / 芭蕉扇（假扇或真扇） |
| 特技 / 换阵 | 特技耗愤怒(破血狂攻/罗汉金钟/四海升平,人人可用)，悟空另有「七十二变」；换阵走战场独立按钮，每回合免费一次且不占行动 |
| 自动 | 交由 AI 为该单位代打一回合，与敌方 AI 同一套逻辑；BOSS 战中只代打普通攻击 |
| 沿用 | 复用该伙伴上一回合的指令与目标；目标已倒则改打最靠前的活敌，法力不足时改为普通攻击 |
| 保护 | 指定一位伙伴，本回合替他挡下打向他的单体物理攻击与 BOSS 蓄力重击，自己受七成伤害 |
| 逃跑 | 非 Boss 战 70% 成功、直接结束本场返回场景重试；Boss 战必定失败 |
| 挂机 | 寻常战斗（非 BOSS、非剧情退出战）可开：之后每回合全队自动出手，点「接手」收回 |

## 七十二变（悟空特技）

「特技 → 七十二变」**不耗法力**，代价是占掉悟空本回合的行动；变化让他在 **3 回合**内临时改写五行、属性并替换技能栏。
四种形态：

| 形态 | 五行 | 属性修正 | 变化技 | 定位 |
|---|---|---|---|---|
| 金甲神将 | 金 | 攻 ×1.4 | 神将横扫（物理群体，倍率 1.3） | 群攻输出 |
| 赤焰灵猿 | 火 | 灵力 ×1.45 | 烈焰拳（火系单体，倍率 1.7） | 高爆法术，克金 |
| 玄甲龟将 | 水 | 防 ×1.6、灵力 ×1.35、速 ×0.8；**受克伤害再减半** | 玄冰击（水系单体，倍率 2.0） | 抗压兼克火 |
| 蟭蟟虫 | 金 | 速 ×1.5、攻 ×0.8 | 无 | 抢速自保 |

变化不是伤害皮肤：改五行意味着改相克关系（如赤焰灵猿以火克敌方的金），玄甲龟将换来
防御却牺牲速度，蟭蟟虫抢到先手却几乎不输出。形态在回合末计时，到期自动还原本来五行。

**化虫入腹（智取）**：二借罗刹女一战中，当罗刹女体力 ≤ 55% 时悟空施展
七十二变，即触发「化虫入腹」直接取胜——对应原著第 59 回悟空钻进罗刹女腹中逼其交扇。开战前悟空
一句心声预告这条路；窗口一开，罗刹女状态签挂「疲态·可智取」、特技菜单的蟭蟟虫高亮，并弹一次提示。
一借（带新手教学）不设智取，第 3 回合必被一扇吹飞。

## 携宠协战

辟水金睛兽（水）严格在碧波潭盗兽桥段后入队，对应原著第 60 回，不提前穿越到火兵战。入队时强制成为
当前上阵宠并追平悟空等级，保证决战能实际使用金睛破浪与冰封；先前捕获的赤焰火骝保留在待命栏，可由
玩家换回。火兵战由悟空变玄甲龟将解题；决战中金睛兽克牛魔王人形（火），八戒（木）克白牛真身（土）。

## 阵型

两套阵型修正作用于全体我方：

- **天罡阵**：攻击 +20%、速度 +5%、**受伤 +15%**——抢先手、拼输出，代价是更脆。
- **六丁阵**：防御 +18%、受伤 −20%、速度 −5%——扛 Boss 高伤时保命，代价是让出先手。

战斗外在右下图标栏「阵型」切换；战斗内用右上「阵型」独立按钮，每回合免费一次且不占伙伴行动。
新阵会替换旧阵而非叠加；代价来自攻、防、速度的互斥取舍，而不是额外输入税。

## 芭蕉扇

芭蕉扇是道具，不是装备；它的分量在于改写整场对阵的状态，且真假两段完全对立：

### 假扇（芭蕉扇·伪）——反噬

二借胜利后拿到的假扇一经使用，场上所有**火敌攻击 +30%**（3 回合）——越扇火越旺。这照搬原著
第 59 回「一扇火更旺」的骗局：玩家若照百姓说法猛扇，反而助长火势。它教会玩家法宝要验真伪，
真正的翻盘要靠真扇。

### 真扇（芭蕉扇）——三段息火生风落雨

BOSS 战携带真扇 ×3，按使用次数依次递进，是牛魔王战的翻盘关键：

真扇三段**无视敌方五行**，对敌方全体生效——这一条是设计要求而非实现细节：决战末段的对手是
白牛真身（土），若三段只对火敌生效，真扇在最需要它的那一战会完全失效，「三借芭蕉扇」的
仪式也就落不到玩法上。

| 次序 | 效果（敌方全体，无视五行） | 原著对应 |
|---|---|---|
| 一扇·息火 | 清除敌方增益（保留我方所加的破防/眩晕/破绽），敌方攻击 −30%（3 回合） | 一扇息火 |
| 二扇·生风 | 全队速度 +30%（3 回合），抢下整条行动队列的先手 | 二扇生风 |
| 三扇·落雨 | 全队持续回血（每次行动回 8% 最大体力，3 回合）；敌方防御 −25% 且**露出破绽（受伤 +60%）**，均 3 回合 | 三扇下雨 |

三段既是战力曲线，也是「三借芭蕉扇」的仪式：先压制敌方攻势、再抢速、后开破绽窗口集火，
配合携宠与变化拿下白牛真身。落雨的破绽期是决战唯一的速决窗口——白牛真身每回合狂暴叠攻，
拖下去必被反杀，所以「三扇何时开」是决战的核心决策。

## 战场态势（杂兵战的具名规则）

一条战役里最先烂掉的是夹在中间的杂兵战：开头有教学、决战有机制，中间几场容易退化成
「再打一次，敌人血更多」。判据是**默认打法测试**——全程点「自动」跑完这一场，它照样轻松过去，
这一场就是过场而不是关卡。两场杂兵战各配一条**具名、常驻可见、指向已有系统**的战场规则：

| 战斗 | 规则 | 效果 | 它逼玩家用上什么 |
|---|---|---|---|
| 火焰山·火口 | **地火炙烤** | 每回合末，我方**非水系**单位受最大体力 **6%** 灼伤；水系免疫，避火锦再减 25% | 悟空变玄甲龟将，或早先选了避火锦 |
| 积雷山·摩云洞前 | **妖将结阵** | 两名妖将同时在场时，敌方全体**受伤 −12%**；折损其一立解 | 先拆结阵还是先打玉面公主——集火目标的选择 |

两条都作为战斗数据交给通用规则执行，名字与一句话效果常驻界面，触发时飘字，与五行相克印
同一套反馈语言。规则对双方的理由要说得通：地火只烧我方，是因为对面本就是火中妖，这一句写进提示。

**结阵为什么是减伤而不是加防**：伤害公式里防御是减项（`攻击×倍率 − 防御×0.5`），给防御加三成
只抵掉个位数伤害，玩家根本看不出结阵在起作用（实测中位回合数纹丝不动）。减伤是乘项，才撑得起
「先拆结阵」这个选择。数值取 12%：自动不再替玩家包办通关，但对症打法在固定样本仍 5/5 可胜；
败北会换种子重试，因此不会形成战役死锁。

五个固定种子的对照结果：

- 地火炙烤：全程自动 3/5、对症 5/5；合计 43 回合 vs 37 回合。
- 妖将结阵：全程自动 2/5、先拆结阵 5/5；合计 45 回合 vs 31 回合；集火主将为 50 回合。

## 敌人与多阶段 Boss

敌方 AI 统一按辅助优先、多目标用群攻、否则单体或普攻出招：


| 敌人 | 五行 | 1 级体力 | 招式 |
|---|---|---|---|
| 罗刹女 | 木 | 980 | 双剑击（物理单体 1.35）、芭蕉扇风（物理群体 0.85） |
| 火兵 | 火 | 430 | 火弹（火系单体 1.25） |
| 火炎校尉 | 火 | 640 | 火弹、烈焰喷吐（火系群体 1.0） |
| 牛魔王 | 火 | 1500 | 混铁棍（物理单体 1.55）、蛮牛冲锋（物理群体 1.15） |
| 白牛真身 | 土 | 1300 | 法天象地（物理单体 1.9）、地火燎原（火系群体 1.2）、蛮牛冲锋 |

**多阶段 Boss**：当牛魔王（火）体力被打空，不会死亡，
而是**现出白牛真身**（土）——满血重开、清空增益与变化，换立绘、换五行、换更强招式与属性。
这正是原著第 61 回牛魔王现出大白牛原形的一战：五行从
火转土后，克制关系随之改变（八戒木克白牛土成为破局点），迫使玩家重新组织真扇三段、携宠
和变化。

决战的三个数值门控，都是「难度阀 + 原著桥段」两用：

| 门控 | 触发条件 | 效果 | 原著对应 |
|---|---|---|---|
| 八戒·土地接力 | 白牛现形的那一刻（一次性） | 全队回复 30% 最大体力 | 第 61 回八戒与土地接力助战 |
| 白牛狂暴 | 白牛真身在场的每一回合 | 独立「狂暴」攻击 +12%，可无限叠加；一扇息火可清层 | 大白牛原形越战越凶 |
| 众神围剿 | 白牛真身体力 ≤50%（一次性） | 哪吒登场，直接削去白牛 15% 最大体力，并附加防御 −30%（3 回合） | 第 61 回哪吒率天兵合围 |

狂暴叠加是这一战的时间压力来源：拖得越久白牛越强，所以三扇落雨的破绽期必须用来速决，
而不是留到「更安全的时候」。众神围剿是**门控演出而非刷怪**，只在血线以下触发一次。

### 敌方也在用相克体系

敌方择敌读五行，不是只挑血量最低者，优先级为：**会克我的目标 > 正在提供全队增益的支援位 >
我能克的目标**，同档内取血量最低者。因此玩家的相克决策会被对手回应——把悟空变成克敌形态、
或让水系携宠上场，代价是自己成为集火目标；沙僧开罗汉金身，代价是他先被拆。择敌不消耗随机数，
同一种子仍可复现。BOSS 的蓄力重击另按一条规则：每 3 回合亮出预警，出手时锁定我方当前体力最低者，
造成约 60% 最大体力的伤害；被锁定者可防御，或由伙伴用「保护」代挡七成。

## 战役流程

场景外层 + 第五十九至六十一回的可玩桥段 + 结局（主线 NPC 头顶「!」指向下一段），约 45-90 分钟。完整顺序：
序幕·火焰山脚 → 罗刹女一战（罗刹女+芭蕉洞侍婢，一扇吹飞悟空）→ 灵吉菩萨授定风丹 → 再战·化虫入腹取假扇
→ 火焰山·假扇反火（火兵，校尉召唤波次）→ 火脉残图（探路、连掘、收手/深入）→ 摩云洞·玉面公主（+妖将）→ 初战牛魔王（赴宴而走）→ 碧波潭·变螃蟹
偷辟水金睛兽（获召唤兽）→ 骗真扇 → 牛魔王变假八戒反骗 → 积雷山决战（牛魔王+玉面公主+妖将，八戒/土地接力）
→ 白牛真身（多阶段+狂暴，真扇落雨破绽期集火）→ 众神围剿（哪吒/李天王剧情门控支援）→ 真扇三段+四十九扇
→ 还扇西行结局。下列列出其中几处关键战斗：

### 序幕·火焰山脚（火焰山庄场景）

点地行走，向土地问话得知火焰山与铁扇公主的来历，经村南山路上翠云山找罗刹女触发一借。开局队伍全 1 级，
持有金疮药 ×2、法力丹 ×1、捕妖绳 ×2、银两 100，天罡阵。一借之后回到翠云山场景，封妖令开放。

### 一、翠云山·芭蕉洞外（一借与二借）

一借：对阵罗刹女（木）与两名侍婢，悟空、八戒、沙僧三人上阵，带新手教学；第 3 回合罗刹女一扇把
悟空吹飞（演出，非失败），灵吉菩萨授宝。二借：同一对阵升一级，悟空（金）克罗刹女（木）；把她
压到 55% 体力以下再七十二变可触发化虫入腹速胜。非 Boss 战可 70% 逃跑回场景重试。
胜利后追加假扇 ×1 与金疮药 ×1，进入火焰山。

### 二、火焰山·火口（火兵战）

对阵火兵·甲、火兵·乙、火炎校尉（皆火），仍由悟空、八戒、沙僧三人上阵。悟空可变玄甲龟将
取得水系与地火免疫，也可依靠先前选择的避火锦；此处玩家会见识假扇反噬。真扇要到碧波潭盗兽、
骗扇之后才取得。

### 火脉残图（战斗外短探索）

火兵战后先选悟空、八戒或沙僧探路，再依只报倾向的五行明牌揭开炉砖旧藏。外层三掘后必须在“保全当前
所得，并凝一张深探拿不到的避火符”与“封存外层所得、深入两掘”之间选择；深层妖气满格只丢深层所得。所得丹药直接进入
背包，残简转成探路者潜力点；深探成功再给该角色一重修炼心得，下一场即可使用。

### 三、积雷山决战（BOSS 战）

对阵牛魔王，两阶段（牛魔王火 → 白牛真身土），携宠四人，携真扇 ×3，**不可逃跑**。用真扇
三段息火生风落雨、以八戒木克白牛土、配合携宠与变化降伏白牛真身。

### 结局·还扇西行

打赢后直接存档并进入结局，不再发放无处使用的下一等级成长：悟空依承诺归还芭蕉扇，师徒在雨后
穿过火焰山，当地重获生机（对应原著第 61 回结尾）。可从结局重新开始新战役。

## 升级养成

围绕战役展开、可复现的成长（不做门派、抽卡、装备打造/交易、技能树）。升级与捕捉的随机使用独立的
战役种子，不占用战斗的随机序列，所以同一种子的战斗结果不受养成影响。

以下养成系统分别说明会影响哪类玩家决策；纯数值成长不单独作为策略深度的证据：

- **升级加点（潜力点）**：决战前的三场完整胜利与两场剧情退出都给一次历练并发潜力点，使队伍达到 Lv6；
  玩家在「角色」面板自由投 体/攻/防/速/灵（含走独立种子的「推荐加点」）；设软台阶防线性爆炸。
  → 新增决策：五维分配的长线构建取舍，一键推荐是下限，手动分配拉开执行差异。
- **修炼点（法术熟练）**：每次历练升级发 **1 点修炼点**，玩家在「角色」面板投给**某一个**已习得法术，
  使其熟练 +1（威力 +6%/级、耗蓝 −2，上限 3 级）。熟练只靠投点提升，不投点则全程停在 1 级。
  面板显示投点后的具体变化（如「齐天棍影 威力 2.10→2.23，耗蓝 24→22」），并提供走同一套确定性
  权重的「推荐修炼」一键作为下限。→ 新增决策：全程只有 5 点，是把一门法术推满 3 级，还是铺开三门各 +1。
- **按等级解锁法术**：技能表以等级为键，解锁扩展到 Lv6；两场剧情退出也给历练，确保中后期法术在决战前解锁。
  胜利结算明示点数，右下图标栏「角色」以朱印提示未分配成长，决战不预告无处使用的新法术。→ 每个新法术都是新的目标 / 耗蓝 / 时机选项。
- **历练与等级上限**：剧情战胜利仍是全员 +1 级（剧情设计等级随之推进）；封妖得历练，满条升级，
  但不超过剧情等级 +1。→ 新增决策：花多少时间刷，换多少余量带进下一场剧情战。
- **银两、商店与研习**：银两买药与一阶兵甲，也可在「角色」面板花银两把法术研习一重（与修炼点同上限 3 重）。
- **愤怒特技**：我方挨打按失血比例攒愤怒（上限 150），任何伙伴都可放破血狂攻 / 罗汉金钟 / 四海升平，只耗愤怒。
  → 新增决策：蓄力重击由谁扛、扛完的愤怒用来翻盘还是保命。
- **装备槽（兵器/护身，三阶）**：一阶铁匠铺买、二阶封妖掉落与十环奖励、三阶为下述剧情缴获；在「角色」面板换装，旧件回背包。
- **三阶剧情装（悟空三选一）**：摩云洞授宝节点给悟空**三件定位不同**的原著本命装，选一件且
  **不可回收重选**——如意金箍棒·精（攻+12、暴击+5%，输出）、锁子黄金甲（防+12、体力+40，生存）、
  凤翅紫金冠（速+8、暴击+3%，节奏）。仍是 flat 属性，不做打造、词条与交易。→ 新增决策：下一场是
  抢先手、扛蓄力还是拼输出，选择当场兑现且不可反悔。
- **规则型法宝（1 件/全队，二选一，忠原著）**：只做规则效果不加攻。灵吉菩萨授宝节点由玩家在
  **定风丹**（速+6、免疫减速）与**避火锦**（全队火系受伤 −25%）之间挑一件，全队法宝位只有一个。
  两者的说明写**前路**而不只写数值（「她那把扇子能把人吹出千里」／「前路是八百里火焰山」），让玩家
  在选的当下就能预判。战斗外可免费改选，战斗中不可换；存档记录当前法宝。
  → 新增决策：押注接下来那一段以减速还是以火伤为主。守 SOURCE_BIBLE「不把法宝降格为伤害更高的装备」。
  芭蕉扇风附带减速 15%（2 回合），所以定风丹的「免疫减速」在一借、二借中就有作用对象。
- **召唤兽/宝宝**：辟水金睛兽（碧波潭变螃蟹偷得，水克火）与火妖赤焰火骝（火焰山用捕妖绳、血气≤40% 剧情门控
  捕捉，封妖火兵同样可捕）为固定协战单位；「召唤兽」面板显示由成长表派生的资质/成长与技能，选 1 只上阵；不做收集池、繁殖与交易。
  → 新增决策：捕捉时机（压血到门槛后用捕妖绳还是直接击杀）与上阵取舍（水克火 vs 火系输出）。
- **物品/背包**：丹药（回体/回蓝）、捕妖绳（捕召唤兽）、芭蕉扇（真/假，规则型）等；剧情节点、封妖掉落与商店获取。
  火脉残图额外产出一小批可复现物资，但不可重复刷取。→ 支撑「道具」指令：有限消耗品在战斗内的使用时机即其决策。
- **不做的养成**：无抽卡、无门派数值墙、无装备打造/交易、无 PVP、无 MMO 长线；封妖可重复，但等级上限让它刷不穿剧情。

## 失败与重试

- **败北**：我方全灭即战斗失败；败北后换一个种子重开当前战斗，
  凭养成进度与更优指令再战，不回退整局。
- **逃跑**：仅非 Boss 战可用，70% 成功后回到场景重试（明雷妖怪仍在原地）；Boss 战禁用逃跑。
- **无死局**：六场战斗均可凭现有队伍、道具与阵型打通；「自动」不保证替玩家通关，但对症打法在固定样本 5/5 可胜；真扇三段、化虫入腹、多阶段变身都是
  设计内的可用手段而非陷阱。
- **寻宝软失败**：深入后妖气满格，只丢掉深层未封存所得；外层物资、战役进度与角色状态保留，
  不回退火兵战。重开整段战役才会重新生成地脉。

改编第 59-61 回「三调芭蕉扇」，以一段连续事件证明全书「问因—侦查—用规则—恢复通路」的循环，

  是牛魔王之妻、红孩儿之母；双方都会七十二变；八戒接力、真扇三次天气变化、还扇后师徒西行。

  入队；众神围剿收束为白牛真身一战；打斗回合数与原文成人化社交细节按玩法需要裁剪。

  化虫入腹或真扇三段，以及升级与阵型带来的执行质量差异。火脉残图借用“八卦炉余砖落成火焰山”

## 实现预算与设计边界

切片包含六场战斗、一次火脉寻宝和一次完整西行结果。数值只服务几个设计关系：相克应改变优先目标与效率；
法力让技能时机有代价；阵型同时提供收益与反向代价；白牛阶段让上一阶段的最优解失效；
