# Agent Note: 西游记首次完整试玩后的信息与布局修正

Status: implemented

## Problem

在 1a0b94b 候选上，隔离新存档、不给源码或攻略的 Agent 实际从标题玩到结局，随后回访存读、重开与 390×844 窄屏。没有通关阻断，但出现窄屏结语挤窄、保护指令被遮挡、背包提前揭露假扇、真假八戒在场时序和战后真扇归属冲突。宠物潜力入口与人物不一致，蓄力提示未持续到下令阶段；后二者先作为观察，再用源码及定向回归核对。

## Decision

沿用[首战与故事选择](2026-11-01-xiyou-story-choices-and-first-battle.md)、[统一面板](2026-11-01-unified-game-panels.md)及[战斗对白反馈](2026-11-03-battle-dialogue-feedback.md)的既有设计，以定向回归先记录失败，再按边界修正：剧情显示与连续性、战斗指令与预警、结局响应式。保留物品内部键、成长数值、主线结果和固定剧情退出时点。宠物潜力统一放在概览，技能修炼仍在修炼页；剧情接管回合不再收集注定丢弃的玩家指令。使用当前真实状态显示持续预警，不预告尚未确定的目标。

首轮原始日志、36 张截图与报告保存在仓库外 audit-runs；仓库只保留精简发现、必要前后证据和回归结论。首次试玩与知情复测分别标注。技能只补充由本次实际问题支持的叙事展示及决策时机经验。

## Alternatives considered

- 只交诊断报告：保留真实发现，但不能满足用户要求继续改进。
- 扩展通用剧情知识图谱或重做战斗系统：可覆盖更多情况，但本次有限状态及已有渲染边界足以解决问题，额外抽象没有必要。
- 调整数值和整个教程节奏：首次玩家实际通关，尚无证据支持整体改动。

## Consequences

隐藏身份需覆盖背包、道具菜单和场景跟随者；修正结局不能让桌面主视觉和重开失效。回归使用测试状态不冒充首次盲玩。此角色为 AI Agent，评分不是人类用户研究，也不证明平衡或趣味。
