# Agent Note: 彩绘界面资产与文字密度

Status: implemented

## Problem

用户在西游 demo 中发现导航把“囊、角、兽、任、阵、设”作为大图标，下方又写完整名称，界面同时有大量常驻解释。已有角色与道具美术没有覆盖常用操作入口，技能也未明确区分图形识别与文字说明的职责。

## Decision

使用 Codex 内置 ImageGen 制作十枚透明彩绘图标，接入六个导航入口与主要战斗指令；保留简短名称、可访问名称和原有输入行为。次要操作用单层文本，不用重复大字章。复核常驻说明，将只在选中、查看详情或首次操作时才需要的信息按需露出，保留必要规则、数值与剧情。

沿用 [品类外壳与第一分钟](2026-10-02-genre-shell-and-first-minute.md) 的指令 RPG 方向。左下消息默认只显示所有频道最新一条，键盘或鼠标可展开频道与历史；战斗地点牌删除重复副标题，首道真实号令提交后收成小地名签，教学与当前规则保留。

在美术方向、构建与 QA 各自拥有的现有文件中补充对应决策：方向定义图形和文字职责；构建调用实际可用的图像工具并接入本地成品；QA 在运行中检查实际尺寸辨识、加载和信息可达。白盒与文字主导作品继续按自身目标判断，不以一律去字替代设计。

## Alternatives considered

- 只缩小汉字徽章或换 emoji：修改少，但无法建立符合本作画风的器物识别。
- 移除全部标签和解释：画面字少，却会牺牲新玩家对操作、技能与结果的理解。
- 只改 demo：能解决本次截图，但后续构建仍可能以汉字和说明段落填补美术缺口。

## Consequences

十枚运行图为 192×192 RGBA WebP，合计 186098 字节；只做尺寸转换与压缩，生成来源与提示组复用 `build/ASSET_NOTES.md` 记录。导航与战斗“道具”共享锦囊图，避免同一操作出现两套意象。保留五行字、气血、状态时长、消耗与剧情，不把少字当作删除玩法依据。

技能要求收窄到需要图形识别的入口与正式生产的新绘制位图；已有图标体系和适合代码表达的简单图形继续复用，不给每种状态强制新增美术。独立审查提出的过度泛化问题已据此修订。
