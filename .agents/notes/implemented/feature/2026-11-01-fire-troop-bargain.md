# Agent Note: 收服火兵后的退路交易

Status: implemented

## Problem

用户要求持续利用 novel 库丰富西游内容。已有火兵捕捉只进入召唤兽名单，紧接的火脉寻宝与火兵自身处境没有因果连接，原有故事主要靠悟空与大妖推进。

## Decision

只在火兵战实际收服火妖后增加一次选择：留下同战，保留现有宠物；或解绳放走，交换火脉退路线索并放弃该宠物。线索抵消火脉外层第一次妖气，不提供隐藏地图答案，也不增加战斗、货币或养成层。线索先于沙僧守护消耗，两者各一次；未收服时沿用原流程。

选择前保存待处理事实，读档后仍能处理；结果即时保存，不重复收宠、释放或获得线索。寻宝结束记录线索是否实际使用，结局回读留用或放归的事实。

捕获在取胜后落定。若成功逃跑，本战未带回的成功捕获撤销、退回对应捕妖绳；失败捕捉的消耗保留，逃跑失败则继续保留待结算捕获。反馈明确说明这一结果。

只读 DB 依据为《看着西游弹幕，小妖怪翻身啦》简介中小卒评估牺牲命令与退路的动机，以及《西游：夭寿啦！这个孙悟空稳的离谱！》前两章先验证再行动的取舍。角色反应和玩法均为本项目原创，第五十九至六十一回没有此火兵交易与火脉寻宝；不复制现代正文或将其写成原著。

## Alternatives considered

- 只加火兵求饶对白：能补人物感受，但玩家没有真正取舍。
- 增加新阵营或支线战斗：可以扩充内容，但现有捕捉与寻宝已有足够接点。
- 本轮只强化真假八戒线索：有第99章行为识人的素材依据，但现有分支已有后果，优先补齐尚未连接的火兵与寻宝。

## Consequences

释放必须明确失去宠物，读档与装备应不丢失财物；线索只抵消外层一次妖气，不默默替代沙僧能力或成为无限奖励。常驻界面仅保留线索剩余状态，说明放在选择与实际触发时。

新状态只保存实际捕获后的待处理选择、已选结果与线索使用事实；旧捕获档不补造本次捕捉。未使用的线索进入深层后不显示可避险，火兵对白使用现有真实人物图，不产生汉字头像占位。

## Verification

`test/qa_firetroop.py -v` 四项浏览器用例通过：留用、放归、返装、读档不重弹/不重复返装、旧捕获档不补弹、真实外层陷阱消费线索并落入 `hunts.fire`；另核对火兵对白实际加载人物图。最小证据为 `qa/evidence/firetroop/01_release-clue-consumed.jpg`。

寻宝 17 项规则回归通过，含默认无变化、外层一次、深层无效、沙僧独立守护和放归退款幂等。独立审查发现捕获后逃跑丢宠/耗绳的提交冲突，修复后战斗测试增至 277 项，覆盖成功捕获后逃跑退绳、未捕获/失败捕捉不额外退款、逃跑失败不丢捕获。
