# Agent Note: 四场景分区扩展与可探索地点

Status: implemented

## Problem

用户认为当前四个场景地图太小、内容单薄。旧图为 1672×941，主要是中央空地加边缘建筑，放大同一底图会同时放大道具和空地，并不能形成探索。地图尺寸、画面道路、寻路网格、NPC、传送与小地图必须一起校准。

## Decision

保留四场景、主线锁与战役顺序，将地图改成 2400×1600 的分区地图，逻辑面积约为旧版的 2.44 倍。每图有明确主路、两处支路地点、原有主线 NPC 与出口。用内置 ImageGen 重绘实际底图，再按成品校准可走边界与障碍，角色体量保持原尺度。

八处探索地点复用现有弹层、物品、银两和存档；以背景中的实物和少量光点提示交互，不新增汉字徽章。四处只提供原作世界线索与伙伴反应，四处提供一次性补给取舍；探索不是通关条件，也不增加经验或新战斗。每处状态使用稳定标识，旧档缺省未探索，重访不重复奖励，选择取消不提交。

寻路继续使用原网格与八向路径算法，补充岛内障碍与不可达目标的停止语义；通过实际移动检查所有出生、抵达、NPC、出口与探索点，不能靠把整图标成可走掩盖地形不符。

## Alternatives considered

- 只提高地图缩放：快速但同步放大建筑和空白，场景拓扑与互动不变。
- 无限拼接开放世界：空间可持续增长，但超出四图封闭战役，降低地点身份与叙事密度。
- 加随机遇敌与采集刷取：能填时间，但破坏现有明雷/等级上限与一次性故事节奏。

## Consequences

背景生成的实际道路可能偏离提示坐标，必须实图复核。扩图可能拉长主线跑图、让 NPC 被 HUD 遮住或让旧档位置与当前网格不符；需要完整战役、定向空间与视口验证。可选补给只使用既有少量资源，不能成为无限经济来源。

## Verification

导航规则8项、探索规则8项通过；浏览器地图回归6项通过，覆盖四图实图与8地点、小地图移动、取消/首取/重访/存读和390px布局。实景复核后继续校准支路脚点与标签避让。完整战役与仓库检查在整合最新主分支后执行并更新此记录。
