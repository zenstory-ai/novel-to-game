# Agent Note: 面板信息层级与窄屏小地图

Status: implemented

## Problem

用户在角色面板发现仍有大量汉字徽章，三人的属性、加点、法术与装备堆在同一页，各面板语言不一。此前图标替换只覆盖导航和战斗入口，没有覆盖养成面板。小地图在宽度小于 700px 时被 CSS 直接隐藏，嵌入浏览器的窄视口因而只剩地点名。

## Decision

沿用 [彩绘界面资产与文字密度](../../implemented/feature/2026-11-01-illustrated-ui-and-text-density.md) 的方向，把角色、背囊、召唤兽、任务、阵型和设置统一到暖绢、细金边、朱红当前态的共享面板外壳；标题、关闭、滚动、卡片、按钮和禁用态共用规则。

角色与宠物每次只展示一个成员，概览、修炼、装备分层，保持选择与页签在操作后不跳回。背囊使用实图网格与选中详情，任务突出当前目标，阵型展示已选方案与取舍，设置按用途分组。属性与五行使用实际彩绘图，空装备槽使用淡化器物图，不再把单字作为装饰图标。

寻宝探路者使用人物肖像，地块与图例复用同套五行图。共享弹层只由顶层处理键盘，方向选择同步实际焦点；成员面板重建后恢复当前控件，用尽则落到同属性或技能行的可用操作。

窄屏保留可点击寻路的紧凑小地图，与队伍状态分栏；坐标转换沿用原画布，不改变游戏世界或寻路规则。在 390px 与 1440px 逐个打开面板验证，另检查 320px 窄边界。面板内容按自然高度滚动，摘要卡在窄屏紧凑并列，资源条不得覆盖最后一项操作。

## Alternatives considered

- 只给旧长列表换图：能减少字章，但三人同屏堆叠和功能边界混乱仍存在。
- 只维护桌面界面：已有嵌入浏览器会直接触发窄屏布局，忽略它会继续隐藏核心导航信息。
- 引入前端框架重做菜单：能提供组件设施，但现有原生 DOM 足够表达所需结构。

## Consequences

重建面板不得丢失选中成员、页签、加点、研习、配装、宠物出战、任务追踪和存读功能。共享模态键盘处理不能破坏剧情选择与寻宝的原有路径；新资产需在真实尺寸验证。

## Verification

保留现有规则回归作为基线。`qa_panels.py` 的 14 项完整浏览器回归通过，覆盖正常/空/禁用/有资源状态、窄屏滚动、嵌套弹层和小地图点击；随后新增 1 项连续键盘加点焦点回归单独通过，结果分别记录在 `qa/evidence/panels/report.json`。规则回归通过文案合同、277 项战斗、17 项寻宝和 4 项场景几何。

完整战役初次运行停在旧脚本重复点击已出战宠物的禁用按钮；脚本改为在需要切换时真实点击，并同时断言按钮和实际出战状态。修订后 `python3 test/verify.py` 完整路径通过 launch/render/input/coreLoop/outcome/restart 六项，四张代表帧，实际运行包 12.98 MB。阵型删除重复数值说明后单独复测切换并更新截图通过。`python3 scripts/validate_repo.py` 通过 7 个 skill，`python3 -m unittest discover -s tests -v` 的 15 项测试通过，`git diff --check` 通过。独立只读复审在焦点修复后结论为 APPROVE。
