# Agent Note: 西游借扇选择与首战分步教学

Status: implemented

## Problem

用户要求先优化西游记 demo：查询其 MongoDB 的 novel 库寻找故事思路，增加故事趣味和机制，再调整首场教学、信息露出与首次五行命中反馈。现首场先弹整页教程，真假扇与罗刹女怨结主要通过对白传达，玩家的准备与试探缺少可读后果。

本轮沿用 [品类外壳与第一分钟](../../implemented/feature/2026-10-02-genre-shell-and-first-minute.md) 的场景与指令 RPG 方向，收紧首战的信息节奏，不重开类型选择。

## Decision

在既有第五十九至六十一回战役中加入两次有实际后果的选择：一借前稳阵或试刀，分别使前两回合全队减伤 15% 或悟空攻击提高 15%；取得假扇后试边火或直接扇火口，后者触发已有假扇助火规则。选择存入战役 flags，在对白、战斗状态与后续回读中使用，旧版同 schema 存档缺新字段时沿用未选择状态。

首战把教学放在真实指令与命中之间：先看悟空与木行敌人、选择攻击和目标，再观察实际克制命中；后续回合补充防御与其他指令，完整菜单随时可展开。首次克制说明只消费真实伤害事件，不保证命中或更改 RNG。三回合被吹飞、母子怨结、真假扇与还扇结局保持原作因果。

作者先修订设计与表现合同，再由独立实现者分别负责故事规则和战斗呈现；新增规则用确定性正反例验证，浏览器验证选择回读、教学顺序与真实命中反馈，并复跑完整战役。

## Alternatives considered

- 扩编其他章节或加入现代网文的穿越系统：变化大，但会重开原有三借芭蕉扇的产品范围。
- 只增加对白：成本低，却不能让玩家的判断改变实际局面。
- 强制正确攻击并保证命中：教学容易展示，但会破坏真实规则与种子随机的承诺。
- 用提速奖励试刀：悟空本已排在最前，提速通常不能改变行动顺序；改用短时攻击加成，让选项有可观察效果。

## Consequences

准备加成与助火后果复用已有状态规则，不引入另一套伤害计算；新伤害事件携带当次五行，反馈层不读取回合结束后可能已变化的属性。选择即时存档，重试沿用且不叠加。

只读调研记录见 `examples/journey-to-the-west/source/STORY_RESEARCH.md`。现代作品只提供人物主动追问、先观察再行动的叙事思路；新增对白与分支为本项目原创，原作依据仍为第五十九回。

保留自由选目标、取消与完整菜单入口，未命中不会显示克制成功。趣味需要实际试玩判断，自动化只证明覆盖的选择、规则与可玩路径；全战役仍以桌面加速呈现验收，常速录证限于首战前两回合。
