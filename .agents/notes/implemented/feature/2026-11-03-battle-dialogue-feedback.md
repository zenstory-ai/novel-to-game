# Agent Note: 战斗反馈与对白阅读层级

Status: implemented

## Problem

[面板行为统一](../../implemented/bug-fix/2026-11-03-consistent-panel-dismissal.md)后，战斗仍同时展示长预览、教学卡、报招飘字与多行战报，五行关系与实际伤害容易被重复文字淹没。对白的姓名、正文和继续提示缺少与共用面板一致的层级，点击式推进还需要区分阅读滚动与明确继续。

## Decision

沿用现有暖绢、细金边、朱红当前态与真实彩绘图标，战斗按玩家选令、目标判断、角色出手、命中结果分区。预览只说明当前决策，战况默认展示最近结果并允许展开历史；技能与五行反馈消费引擎事件，用实际角色/技能/五行图和目标局部反应强化可见因果，不追加整屏说明。

对白保留原正文与人物身份，姓名、正文、进度和继续操作分区，长文有独立滚动区；选择、拖动和模态覆盖不推进剧情。关键提示在静音、跳过演出及低动效下仍可读。

## Alternatives considered

- 再加更大的文字横幅：实现快，但继续争抢人物舞台和注意力。
- 删除教学与战报：画面清爽，却丢失首战判断依据和结果回查。
- 重画全部人物与背景：能改变风格，但不解决当前信息层级与输入问题。

## Consequences

事件演出必须与真实结算一致，尤其首个五行克制、治疗和无效结果；更换反馈不能篡改数值或提前泄露终态。共享对白推进影响完整战役，需验证正常速度输入、嵌套模态、长文与窄屏布局。
