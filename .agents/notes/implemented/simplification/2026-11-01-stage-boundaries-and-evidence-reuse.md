# Agent Note: 收窄白盒、补证与问题回流的触发条件

Status: implemented

## Problem

逐文件审查发现，白盒继承完整产品闭环、外部模型缺失触发文档降级、概念选定后无条件二次拆书、世界设计默认入口承诺完整原型，以及严重体验问题统一升级产品裁决，都会扩大当前阶段的责任。动态媒体与语音的固定台账还可能重复已有运行时数据。

## Decision

白盒只实现足以验证最大风险的交互，正式生产承担完整闭环；按当前可用实现能力决定能否构建；概念选定后只补实际证据缺口；世界设计的默认提示词与中英路由描述只承诺可实现的设计合同；问题先回对应负责人，改变产品或已批准概念才请求产品裁决；媒体交接复用已有登记表，仅补缺失信息。

补证只针对概念依赖却缺少定位证据、相互冲突或未覆盖的关键因果、必要外观与时空事实；既有充分证据直接引用。产品、设计、构建与 QA 的决策按各自职责归属处理，不写回原作事实层。媒体复用构建或运行时实际消费的登记表，保留两份合同各自的十一项信息语义，缺项才补；语音输出兼容已批准的运行时合成。

本次延续[阶段负责人分离](../architecture/2026-07-18-planning-owner-separation.md)与[构建声明设计出入](../process/2026-10-03-build-writes-back-design-drift.md)，收窄旧有无条件流程；保留来源覆盖、人物名册、语言、自包含与六项同次运行 QA。

## Alternatives considered

- 只改措辞、不改触发条件：差异最小，但无法消除白盒范围、重复取证和产品回流的实际冲突。
- 删除事实表、媒体字段或跨技能重复规则：能明显缩短文件，但会丢失事实、授权、连续性与独立安装所需的保护。
- 新增流程校验脚本：能检查固定字符串，却无法证明模型是否做了多余工作；沿用仓库检查，另做有限场景对照。

## Consequences

八份技能文件完成局部修订，技能 Markdown 由 1079 行减为 1077 行。白盒、补证、回流与媒体交接的触发条件更明确；补证仍依赖设计者发现缺口，媒体登记表复用仍须核对必要信息。独立精修还发现语音文件保存要求与运行时合成许可冲突，文件保存要求现仅适用于构建期生成的资产。

## Verification

修改前后 `python3 scripts/validate_repo.py` 与 `python3 -m unittest discover -s tests -v` 均通过，15 项测试保持通过；`git diff --check` 通过。作者与审查者分离，按 prose-gap-polish 的五步核对语言、冗余、歧义、信息和逻辑断点，并修正运行时语音的相邻冲突。

两个独立上下文分别读取修改前后的技能，对同一组 13 个场景各生成一次决策输出。旧版在已批准 NPC 与指引漏实现时请求产品裁决，新版直接回构建修复；白盒新版只交狭窄走道风险探针，不再承诺产品重开。其余场景保留了本会话实现、定向补证、只交设计、方向变更裁决、媒体复用与补缺、必需媒体失败处理、运行时语音和新候选六项 QA 的边界。此对照只观察决策文本，未构建游戏，也不证明总体生成质量或所有行为没有回退。

旧版技能、固定场景和决策输出保存在本次仓库外实验目录，未增加永久测试框架。输入与预期如下：

| 场景输入 | 预期决策 |
|---|---|
| 白盒只验证狭窄走道的相机与碰撞 | 实现真实交互与可复现观察，不先补主线、胜负或产品重开 |
| 本会话可编码，目标工具链就绪，无外部模型 | 继续实现，不降级为仅交说明 |
| 概念依赖的事实已充分覆盖 / 缺服饰证据 | 前者直接进入世界设计，后者定向回原文补证；原文未说明时标明空白 |
| 用户直接采用世界设计默认提示词 | 只交 GAME_DESIGN，包含可实现的切片合同 |
| 构建漏做已批准的 NPC 与指引 / 必须把 RPG 改成互动叙事 | 前者回构建修复，后者请求产品裁决 |
| 语音与媒体已有完整 / 缺项 / 没有生产登记表 | 分别复用、补缺、新建最小记录；保留授权、运行文件、降级与状态 |
| brief 批准运行时语音，已有对白登记表但没有逐句持久音频 | 保留运行时合成，不强制改为构建期文件或复制台账 |
| production 的新候选未跑完整 QA，旧候选有 PASS | 提供六项同次运行的验证入口，不沿用旧 PASS |
