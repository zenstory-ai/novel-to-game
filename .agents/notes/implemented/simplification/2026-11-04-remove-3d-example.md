# Agent Note: 删除未达到展示预期的 3D 示例

Status: implemented

## Problem

所有者试玩后认为《失落的世界》的制作成色不足，并明确要求彻底删除案例及 README、description 等现行引用。它已经完成可运行验证，但继续作为公开案例不符合当前展示取舍。

本决定改变[三个示例整体重做](../feature/2026-10-02-examples-rebuilt-on-benchmark-genres.md)中保留并提升该案例的选择，也改变[README 展示真实产物](../process/2026-09-18-readme-real-outputs-and-faq.md)中使用该案例节选的选择；旧笔记保留当时的事实。所有者随后明确保留网站，只在本机备份源码。

## Decision

1. 删除整个案例目录，包括原文、设计、源码、资产、截图、视频和 QA 记录。
2. 同步两份 README，删除试玩入口及设计、QA 节选，将仓库公开示例数量改为两个。插件清单、skill 描述和界面说明没有案例专属宣传，保持原样；GitHub About 的 description 改为两个可玩示例，主页改指现有项目介绍页。
3. 删除 CI 中专属安装、测试和构建步骤，部署观测只保留两个现存案例；同步相关文档、忽略规则及案例专属研究内容。
4. 保留历史 CHANGELOG 和决策笔记，不改写旧决定；新增删除记录。通用 3D 构建能力与多语言支持不随示例删除。
5. 在仓库外的本机目录保留完整案例备份，来源为删除前的提交 `6f899005be17997668e1af913361649ad7202652`。线上网站独立保留于原域名，不再连接本仓库的 Git 自动部署或部署观测。用户要求下线时 Vercel 项目已经删除；后续改口保留后，从同一提交恢复生产构建并重新绑定原域名。
6. 使用现有校验和回归测试，复核现行引用、README 中英结构及本地链接，不为这次目录删除新增常驻扫描器或依赖。

## Alternatives considered

- **撤出首页、保留归档**：可保留唯一的 3D 完整案例，但所有者已明确选择彻底删除，归档仍保留了不希望维护的内容。
- **继续提升成色**：能保住品类覆盖，但仍需投入制作和试玩，不符合此次删除决定。

## Consequences

仓库只保留两个中文素材的浏览器游戏示例，不收窄 skills 接受的原著语言、目标平台或游戏类型。备份路径与部署说明留在本机备份目录的 `BACKUP.md`，不作为仓库的跨目录依赖；网站后续从该备份独立维护。
