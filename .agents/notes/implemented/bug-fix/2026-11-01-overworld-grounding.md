# Agent Note: 行走人物与地面的机位匹配

Status: implemented

## Problem

用户在西游 demo 中指出人物与地板透视不协调。行走场景直接缩放接近平视、战斗姿态的人物立绘；人物高度固定，NPC 额外放大 10%，脚底按整张画布下沿对齐，所有人物共用硬椭圆投影，移动时整张图上下跳动和左右摇摆。地图则是较高机位俯视的彩绘地面，造成贴纸感与悬浮感。

## Decision

沿用现有四张场景地图、寻路与任务规则，为全部十三种行走人物生成独立的俯视站姿图。以原立绘锁定身份服饰，用首张悟空行走图校准机位；保持战斗与对白资产的用途。

按每张图的脚底中点、人体头顶和朝向记录绘制元数据，同一地面锚点驱动绘制、接触影、点击区域、头顶信息和 QA 坐标。景深大小从世界地面坐标推导，镜头平移不会改变体型。移除 NPC 额外放大与整张图跳动摇摆，补贴脚接触影和柔和方向投影。

美术方向补充机位与资产用途的交接，沿用现有资产记录与 QA 证据，不引入三维引擎或通用相机系统。

## Alternatives considered

- 只压扁或缩小原立绘：修改轻，但无法生成原图不存在的头顶、肩背和脚面，战斗姿态仍会悬浮。
- 重画所有地面或切换真三维：能统一相机，但会破坏已调好的路径、交互与场景范围。

## Consequences

生成图的透明边缘、身体比例、朝向与机位需要逐张目视，不由提示词宣告成功。脚底中点和人体高度必须按身体而非武器、披帛和留白校准；点击、自动寻路与主线目标应保持可达。

十三张运行图合计 752714 字节；八戒和罗刹女经实景审查后再次重绘，强化帽顶/发顶、肩面与脚面。站定队友间距略放宽，上左光对应右下柔影；统一地面锚点随朝向镜像，实际交互区域覆盖头顶任务标记。

## Verification

四项几何回归通过，包含身体留白归一化、温和景深与至少 70px 的头顶点击范围。真实浏览器在罗刹女头顶上方 58px 点击，成功自动接近并打开对白；修复了独立审查发现的可见标记上部点不到的问题。

十三张运行资产全部 HTTP 200，村庄、翠云山、火口、摩云洞玉面/牛魔两阶段五组场景验证通过，无页面或控制台错误。常速首战定向测试通过；完整战役至结局与重开六键 PASS。`qa/evidence/world-perspective/01_cuiyun.jpg` 与 `qa/evidence/ui-art/01_overworld.jpg` 保留实景前后对照，独立视觉复核确认落点、尺度与重点人物机位改善。

当前 `npm test` 为战斗 277、寻宝 17、场景几何 4 项通过；仓库校验、15 项仓库单元测试与 `git diff --check` 通过。仍是二维站姿双向镜像，不宣称已制作多方向逐帧走路动画。
