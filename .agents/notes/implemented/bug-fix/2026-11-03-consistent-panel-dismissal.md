# Agent Note: 面板遮罩与关闭行为一致性

Status: implemented

## Problem

[共享面板](../../implemented/feature/2026-11-01-unified-game-panels.md)已有共同视觉外壳，但普通面板和选择弹窗分别实现生命周期。阵型的内部关闭没有通知导航，外部点击在两类构造器中不同，法宝改选没有取消出口。窄屏的 stretch 还把短面板拉成长空页，透明背景与多层遮罩使明暗不一致。

## Decision

保留现有暖绢、金边和朱红控件，面板主体不透明，底层遮罩轻度压暗且嵌套不叠加。所有面板由共同外壳处理焦点、顶层键盘、遮罩与关闭；可取消操作显式声明取消按钮，X、Esc和外部完整点击调用同一取消动作。面板内起始的拖动不视作外部点击。主线必选和未结算步骤保留其明确操作，不因点击背景隐式提交。

法宝改选增加取消且不改存档，关闭后回到背囊原按钮；阵型的所有关闭路径清理导航当前态。标题和关闭固定在可视范围，正文独立滚动，短面板按内容取高，子面板只保留宽度与内容布局差异。

## Alternatives considered

- 分别补事件：改动小，但两套焦点、遮罩和关闭语义会再次漂移。
- 所有弹窗一律直接移除：看似统一，却会挂起等待玩家选择的流程，或误提交奖励。

## Consequences

共用键盘与取消处理会影响剧情、确认框、养成重建和寻宝流程，需要保留必选步骤并回归完整战役。外部关闭不得点击穿透到地图；嵌套只关闭顶层并恢复焦点。
