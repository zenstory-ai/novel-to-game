# 新玩家盲玩方法

只看源码与内部状态最多证明程序算得通，证明不了第一次点开游戏的玩家光看画面就能上手、玩顺并愿意玩下去。

## 操作纪律

- 用真实浏览器或原生窗口做真实点击与按键。在仓库外另建运行目录存截图与日志；每个玩家画像单开全新会话，防止串用存档。
- 按 `1×` 正常速度玩：过场、倒计时、逐字台词与战斗动画都等画面播完再点，不连点跳字，不拨快时钟。
- 边玩边记，不事后补写：每过关键节点存一张截图，同步抓取控制台报错与失败请求，用第一人称记下带时间戳的当场反应。
- 浏览器断连、会话回收或网络抖动不算游戏缺陷：能补测就补测，补不了的记入「未覆盖」。

## 盲玩旅程

设定 1–2 个贴合目标受众的玩家画像（如没读过原著、习惯单手点手机的剧情玩家，或懒得看长说明的同类老手）。每步给卡顿度打分：`0` 顺畅、`1` 小停顿、`2` 疑惑但自己摸清、`3` 卡住瞎猜、`4` 劝退关页；同时记下最抓人和最想关掉的瞬间。必须走完六步：

1. **首屏五秒与三秒扫视**：看标题页五秒，写下这是什么游戏、我扮演谁、第一下该点哪。进主玩法后不读长说明，三秒内扫视能否看清焦点与下一步，同时排查去字过猛致新机制操作不可发现。
2. **开局一分钟**：不翻帮助与暂停页，能否凭画面焦点、内联键帽与即时反馈看懂去哪、怎么操作；同一操作第二次是否更顺手。
3. **主线到结局**：选择后果、人物态度、克制关系、风险后果签与预警是否好懂；不同选项须有真回应；含连续行走须全程跑图。排查策划术语、内部字段、套话复述、说明墙、难懂单字缩写、现代热梗，以及常驻短目标条提前剧透或不在场角色串词。
4. **视听与容错**：自动翻页字幕能否读完，结算页有无防误触，过场与降级静画是否齐全；立绘与物件有无假透明棋盘格、白边锯齿、多指畸变、牌匾乱码、拉伸变形、画风割裂或违和毛玻璃面板；常驻面板、弹窗与气泡是否切碎主视野或遮挡主角、血条与交互点，全屏瞬态横幅（如蓄力、转阶段播报）与单位名牌有无动态层级穿插，对白与抉择期场景功能坞有无半露遮挡，同一信息有无多处复述，热区与按钮有无遮挡（含小游戏胶囊与安全区），弹窗能否统一退出，限时与长按在菜单和后台是否暂停；含激励广告或抖音侧边栏复访时，实测空广告位、半途关闭、拉起失败及冷/热进入领奖且无废按钮。
5. **退出重进**：刷新或重启后核对实际恢复的场景、持物与进度（只弹「已保存」不算）；通关点重开后旧状态是否清零。
6. **双视口与辅助**：覆盖桌面短屏（`1280×720`）与手机窄屏（`390×844`）重走标题、主界面、子菜单、长台词与结局页，检查三秒扫视、按钮压脸、气泡裁切、动态层级遮挡及触屏误显键盘提示；PC 小游戏或双端一并查等比缩放；按需测静音与减弱动效。

## 定级与报告

| 级别 | 判定标准 |
|---|---|
| `P0` 阻断 | 无法启动、崩溃白屏、主线死路、必点入口被挡死、存档损坏 |
| `P1` 严重 | 能通关但极易劝退：核心机制失灵、明显报错、严重剧透或串线、关键台词读不完、气泡或面板大面积遮挡主舞台/血条/关键目标、文字墙替代玩法致三秒抓不到重点、去字过猛致核心操作桌面端不可发现 |
| `P2` 一般 | 造成困惑、误触或绕路，摸索后能走通；面板过密、跨控件复述、非核心遮挡、瞬态横幅与名牌层级穿插、对白期功能坞半露、难懂单字缩写、触屏误显键盘提示或短目标剧透（不降格为 `P3`） |
| `P3` 轻微 | 局部措辞、排版与音画细节 |

每条问题写清标题、复现步骤、证据路径、预期与实际表现，以及对玩家的直接后果（写「以为卡死直接关页」，不写「体验欠佳」）。偶发问题标「偶现（n 次里 m 次）」；排查未重现的写「本轮未复现」，不断言「已修复」或「不存在」。设计如此但界面没讲清的，仍按引导缺陷记。客观事实与代入画像的主观感受分开写，注明出自首轮盲玩还是第二轮核对。

`qa/playtest-report.md` 含五节：

1. 结论与 `0–10` 续玩意愿，附具体时刻作证；
2. 环境、视口、玩家画像、走通的路线与未覆盖项；
3. 游玩时间线：关键节点、卡顿评分、最抓人与最劝退时刻；
4. 按严重度排列的问题清单；
5. 改进建议与归属（`product` / `design` / `art` / `build`），按收益高、改动小优先。

工作区只留报告与关键问题截图，过程连拍与原始日志留在仓库外；报告内不出现密码、令牌或 Cookie。
