# 对白与互动选择设计方法

对白承担主要体验时，用本方法把人物目标、信息权限和玩家选择写成可实现的场景。它不规定
台词长度、选项数量或固定节拍；逐字文案的声口见
[game-writing-craft.md](game-writing-craft.md)。

## 一、先写议程，不先写台词

先完成 [narrative-design-method.md](narrative-design-method.md) 的场景脊柱，再为会改变局面的
参与者记录：当前要求、害怕暴露的事、可用筹码、初始策略、受阻后会换的策略和底线。

先写行动链：

`A 用策略和筹码行动 → B 回应或拒绝 → 局面变化 → A 换招或退出`

每轮应改变信息、关系、权力、物件、站位或下一步可做的事。纯粹重复立场的往返应压缩；一方
每句都成功会把对话变成演讲。

## 二、让台词执行动作

关键台词应主要执行一种人物动作，例如试探、交换、划界、推责、威胁、保护、求证、拒绝、
承诺或撤回。同一句事实可以因目标不同而成为不同动作；先定动作，再写句子。

保留能推进局面、增加期待、显露人物或改变权力的台词。物件、站位和反应已经表达的意义不要
再解释。沉默、打断和长发言只有在改变策略或信息条件时才保留；设定信息随压力和行动进入，
不要让角色整段科普。

## 三、人物声音

核心人物只需一张紧凑声音卡：

- 他认定什么算证据，又怎样证明；
- 他如何使用称呼、公开范围和关系控制距离；
- 他如何隐藏、拒绝或转移；
- 压力下句式和策略怎样变形；
- 哪条底线被触碰时会出现可追溯变化。

人物辨识度来自目标、知识和关系策略，不靠口头禅。交换两名说话者后若关键台词仍完整成立，
检查缺少的是目标、证据观、知识边界还是关系位置；不要用固定对白长度推断权力。

## 四、信息、潜台词与选项

人物只能使用本场已经掌握的信息；推断说出口时要听得出仍是推断。潜台词同时包含字面内容、
想让对方做的事和不能直说的风险，并通过避词、物件、称呼、证据矛盾或公开范围变化让玩家看见。
没有秘密、风险或权力差时，直说通常比强造潜台词更真实。

互动选项写主角真正会说或会做的内容，不用“安抚她”“施压”“信任他”这类作者摘要。选择后
先给人物反应，再让后续行动承接；按钮、回应和代价提示各做一件事，不重复解释。

## 五、修订与交付

逐场检查：是否过度解释或收口；人物是否只会重复同一策略；证据、筹码和信息密度是否变化；
选择是否总套用同一模板；代价是否被当场结清；巧合或第三人是否反复替人物解决问题。

修订优先删解释、合并重复轮次、让反对方使用筹码，并让物件或空间承担意义。保留原作中的方言、
笨拙、急话、称呼和不整齐句式，不把所有人物润色成同一种标准范文。

交付前反向走读分支，确认未选事实没有串入；每场至少留下可见变化和退出压力；玩家作判断所需
的证据不能在删解释时一并删掉。
