# 对白与互动选择设计方法

对白承担主要体验时，用本方法把人物目标、信息权限和玩家选择写成可实现的场景。它不规定
台词长度、选项数量或固定节拍；这些由原作、人物、平台与当前场景决定。逐字文案的声口与
去AI味标准见 [game-writing-craft.md](game-writing-craft.md)。

**先读这条**：本文每种手法都有它不成立的场合。只学"该怎么做"而不学"什么时候不该"，
结果是手法被当成质量指标全场铺开——**对白最常见的坏味道不是手法用得少，是用得到处
都是**。

| 手法 | 什么时候不该用 |
|---|---|
| 写潜台词 | 人物没有理由隐瞒时；此时直说才是人物真实反应 |
| 打断 | 被打断的那句带着玩家此后再也拿不到的信息 |
| 先承认一部分 | 玩家还不知道存在更大的秘密，后面揭露时会觉得被耍 |
| 沉默与留白 | 玩家缺少作判断所需的证据，留白变成信息缺口 |

## 一、先填场景脊柱

写逐字台词前，先按 narrative-design-method.md 第二节填完场景脊柱，含存在理由、反制筹码、
离场状态，以及与相邻场景的因果连接。本文只追加两问：谁是焦点人物；哪项退出状态发动
下一场，而不只是宣布"谈话结束"。

## 二、建立对白议程

为会改变局面的参与者各写一张对白议程：

| 项目 | 要回答的问题 |
|---|---|
| 当前要求 | 此刻想让对方做、交出、承认、停止或相信什么 |
| 害怕暴露 | 最怕哪项事实、欲望、软弱或关系被看见 |
| 筹码 | 能提供、扣留、证明、破坏或公开什么 |
| 初始策略 | 先试探、交换、划界、推责、威胁、保护还是转移 |
| 策略受阻 | 对方怎样拒绝；随后换成什么策略，而不是把原话说得更响 |
| 底线 | 哪件事通常不会做；什么压力可能迫使其越线 |

两人可以表面谈同一件事、实际争不同结果。例如都在谈"交钥匙"：一人要结束控制，一人要
迫使对方承认责任。**双方议程一致就是复述**，这种对话应当压缩或删除。

先写行动链，再写台词：

`A 以策略和筹码行动 → B 回应或拒绝 → 权力、信息、关系、物件或站位变化 → A 换招/退出`

每轮应接住上一轮动作，并改变下一轮能做什么。可以维持僵局，但僵局必须增加代价、暴露
策略或改变理解。纯粹重复立场的往返应压缩。

**不要让一方每句都成功**，否则对话变成演讲。让另一方：看穿并点破策略；接受字面条件却
拒绝隐含关系；提供反证；改变公开范围；把对方的词反过来使用；拿走说话所依赖的时间、
物件或身份；不给预期反应。

## 三、让台词成为行动

给关键台词标一个主要动作：试探、交换、划界、推责、威胁、保护、转移、求证、拒绝、承诺、
诱导、撤回。同一句事实可以执行完全不同的动作——

> 事实：「门在九点锁。」
> 催促：「你还有三分钟。」
> 推责：「九点以后，钥匙不归我管。」
> 试探：「你是不是以为九点以后没人进得来？」
> 威胁：「九点一到，里面是谁都不重要了。」
> 保护：「九点前走，我就当没见过你。」

字面信息相近，关系动作完全不同。先定动作，再写句子。

**每句台词至少承载一项**，否则删：推进局面、增加期待、显露人物、改变权力。情绪场景里
每句还要回应上一句的情绪状态（承接／偏转／升级／退缩）——对白是两个人的情绪在碰，
不是轮流播报信息。

不要把已经由物件、站位或对方反应表达的意义再解释一遍。动作段只在它会完成至少一件事时
出现：操作筹码或证据；改变距离、出口、视线或空间权力；暴露言行不一；给对方一个必须
回应的新事实；记录后续必须继承的连续性变化。"看了看""笑了笑""沉默片刻"若不改变策略，
只是表演填充。沉默可以保留，但要说明人物用沉默拒绝、试探、拖延、保护还是迫使谁先行动。

**长发言只在议程内部有转折时**才用一条改变策略的动作行断开；内部没有转折的长发言应当
**缩短**，不是拆开。断不开说明这段话在替人物做说明，回到第五节重写信息的进入方式。

**禁科普嘴**：设定、原理、前因后果不能由任何角色整段讲解，信息型配角尤其。拆成人物在
压力下挤出的半句话 + 身体反应 + 留白，用到哪带哪点。

## 四、建立人物声音卡

人物声音不只是一组口头禅。为核心人物写声音卡，覆盖这几个维度：

- **认定什么算证据**：注意流程、体面、感受、风险、长期后果还是具体物件；
- **怎样证明**：举证、引用规则、讲关系、诉诸经验、逼对方表态；
- **怎样控制距离**：直呼名字、使用称谓、说"我们"、避免代词、公开说还是私下说；
- **关系策略**：面对亲友、上级、陌生人和需要保护的人分别怎么做；
- **怎样隐藏**：多解释、反问、开玩笑、沉默、改话题、过度精确；
- **压力下怎样变形**：更精确、更含糊、更礼貌、更短促、开始重复，还是改用行动；
- **哪条底线被触碰时**声口会发生可追溯的变化。

**对话长度往往等于权力位置**：掌控者话短且冷静，被动者话多且情绪化。权力反转时长度也
该反转。现场权力可能来自：谁能结束谈话或打开门、谁持有可验证证据、谁能让话语公开、
谁承担更少退出成本、谁能定义问题与可接受答案、谁愿意付更高代价、谁掌握第三人的信任。
台词改变权力时应有后续动作证明：对方交出物件、改称呼、停止解释、转向第三人、撤回条件
或离开原位置。

**交换说话者测试**：交换两人的名字后，若关键台词仍完整成立，检查缺少的是不同的目标、
证据观、关系策略还是知识边界。不要只靠生僻词和口癖制造差异；也不要仅凭常用词就判定
"同声"，要指出缺的是哪一项。

## 五、管理信息权限与证据边界

三层状态（世界事实／人物相信／玩家知道）与每项关键证据的三层拆分（可见载体／直接支持／
未决推断），定义见 narrative-design-method.md 第四节。写台词时落到两条：人物只能使用他在
本场已经掌握的信息，揭示要改变某人可以采取的行动；未决推断说出口时必须听得出是推断。

**潜台词的三层写法**：字面层（实际说了什么）、行动层（想让对方做什么）、风险层（为什么
不能直接说）。潜台词需要玩家可观察的线索：角色避开一个具体词、对方触碰或藏起相关物件、
称呼改变、先回答旁枝而拒绝核心问题、台词与可见证据矛盾、第三人进入后语言突然改变。
**潜台词不能完全依赖设计文档事后解释。** 若现场没有外人、秘密或权力差，这句就只是生活
指令，不自动具有潜台词。

## 六、把互动选择写成角色行动

选项表达主角此刻采用的说法、姿态或行动；关键选择的判据、节点记录项与汇流规则见
narrative-design-method.md 第五、六、七节。本文只管一条：**选项标签写玩家真正会说出口
的那句**，不写它的摘要——"安抚她""施压""信任他"这类作者标签与实际台词语气不符时，
玩家会觉得自己说了没打算说的话。

## 七、避免模板化对白

逐场并排检查，而不只逐句润色：

- **过度解释**：动作或证据已表达后，台词又翻译心理、主题或道德意义；
- **过度收口**：场景和结果都用总结句封死余波，下一场只能重新制造压力；
- **过度工整**：每轮都是同样长度、同样句式、同样的问答与微动作；
- **信息密度均匀**：每一拍都同样"有信息"，导致真正的证据与决定没有重量；
- **策略重复**：人物只会质问—否认—提高音量，筹码与行动条件从不变化；
- **因果重复**：每轮都靠陌生人带来答案、巧合救场、对手自曝；
- **代价即时结清**：本场造成的代价全部在本场还完，于是什么都不积累；
- **选择模板重复**：连续场景都按"说明 → 二选一 → 一句回应"运行。

其他失效信号：人物轮流复述彼此都知道的背景；所有角色用同一种证据观与句式；一方持续
发问、另一方持续完整回答；对方已经反制，角色却重复原要求；台词很"狠"但没让任何人改变
行动；沉默与打断只用于制造节奏、不留下后果；用对白长度或比例判断好坏。

修订时保留原作承诺与已批准选择，优先删解释、合并重复轮次、让反对方使用筹码、改变信息
密度，并让物件或空间动作承担一部分意义。不要用固定字数、对白比例或选择数量冒充质量。

**保护风格**：润色最容易顺手抹掉的，恰恰是人物身上不整齐的部分——方言、口吃、笨拙、
不合语法的急话、地方性的称呼、只有这个人会用的粗俗比喻。把所有人的句子都改得通顺、
匀称、得体，是把人物差异磨平，不是提高质量。修订只删**解释性**的句子，不删**不像范文**
的句子；拿不准时问：删掉它，还认得出这是谁在说话吗？

## 八、交付与审查

交付清单见 SKILL.md 输出 checklist 的「叙事承载附件」一项。交付前自查：

1. 交换说话者，检查人物是否仍可辨认；
2. 反向走读分支，确认未选事实没有串入；
3. 标出每场至少一项可见变化与退出压力；
4. 删除重复解释，但保留玩家作选择所需的证据。
