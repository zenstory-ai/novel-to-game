# 互动叙事设计方法

场景、对白、知识差、证词或关键选择承担主要体验时使用本文；写逐字文案时同读
[dialogue-design-method.md](dialogue-design-method.md) 与
[game-writing-craft.md](game-writing-craft.md)。

本文不放松任何完成标准，只把同一批判据换成叙事承载的说法。系统主导的项目照旧用
[world-design-method.md](world-design-method.md) 与 [numeric-design-method.md](numeric-design-method.md)；
混合型项目两边都要成立，各自对自己那一层负责。

## 一、玩家能动性合同：先过这道门

互动叙事最常见的失败不是文案差，是玩家其实没有能动性——他在**分诊已经写好的结果**，
而不是让事情因他而不同。判据是两项权利，两项都要成立：

- **因果权**：玩家的选择决定后续事件**为什么**发生、朝哪个方向转。事件只是被玩家的
  点击放行（不点也早晚发生、点什么都同一条因果）即不成立。
- **结算权**：结果**看得出是他的**——人物点名他做过的事、局面按他选的方向收束、代价
  落在他在乎的东西上。结算只出现在旁白总结或一个总分里即不成立。

这道门专治一个具体现象：把"给玩家能动性"廉价兑现成"给玩家一个花资源的界面"。资源面板
是最容易做出、也最容易被验收为"可交互"的东西，所以模型会默认滑向它。**卡牌、回合、
资源条本身不是缺陷，缺陷是它们替代了这两项权利。**

配套的三条硬判据：

1. **结果必须能追溯到玩家做过的选择。** 主角被动承受、随后由外部力量（突然赶到的人、
   一份恰好出现的文书、一次掷骰）解围，即使"阻碍产生了结果"也不成立——那一场玩家是
   观众不是主角。修法不是加动作，是把某次被动承受改写成主动选择，让外部事件成为该
   选择的**后果**而非救援。
2. **巧合有方向性。** 巧合可以制造麻烦，不可以解决麻烦。用随机数、掷骰或资源判定收束
   核心矛盾，就是"巧合解决问题"的一种；玩家投入的是人物怎么应对，不是世界怎么补偿他。
   四条判据缺一不可：**位置**（把人推进麻烦可以，把人从麻烦里捞出来不可以）；**代价**
   （巧合送来的必须是负担，不是礼物）；**已建立**（这类事此前在世界里出现过，不是临时
   发明的规则）；**只用一次**（第二次就成了模式，玩家不再相信世界，只相信作者会救场）。
3. **误会必须留下残余。** 四条判据：**人物有理由不解释**（说不出理由，就直接让他解释）；
   **玩家位置要选定**——玩家知道真相是悬念，玩家不知道是惊讶，**选一种并贯彻**，摇摆的
   结果是两种效果都没有；**必须产生行动**（不改变任何人做的事，就只是误读）；**解除时
   有残余**（澄清之后关系回不到原点）。澄清即复位的误会没有兑现。

## 二、场景脊柱

每场记录：

| 项目 | 内容 |
|---|---|
| 存在理由 | 删掉本场会损失哪项选择、证据、关系变化或不可逆行动 |
| 时间与地点 | 场景发生在哪里、距上一场多久 |
| 视角 | 玩家通过谁感知现场 |
| 在场人物 | 每个人为何来到这里 |
| 人物目标 | 此刻想得到、保护、隐瞒或确认什么 |
| 反制筹码 | 谁挡住焦点人物，用什么挡 |
| 已知信息 | 玩家、主角和各人物分别知道什么 |
| 方向性变化 | 哪句话、证词、物件或行动使原计划失效 |
| 玩家介入 | 观察、追问、表达或行动 |
| 离场状态 | 谁离开、带走什么、关系和信息怎样变化，下一场为何现在必须发生 |

在压力已经活跃时进入，在有意义的变化之后离开。开场先给正在继续的行动、已落地的后果
或与既有认知冲突的可见事实，不让人物先复述上一场。

相邻场景通过人物行动、未付代价、物件去向或时间压力连接。只有时间相邻而没有因果连接，
不算连续剧情。删掉后不损失选择、证据、关系变化或下一场因果的场景，合并或删除。

## 三、人物引擎

为核心人物建立一页人物引擎：当前欲望与长期目标、害怕失去的东西、对其他人的判断、
掌握与误解与隐瞒的信息、对玩家具体行为的记忆、会主动发起的请求或试探或威胁、
声口与称呼与行动习惯。同一选择对不同人物产生不同解释；人物通过后续行动表达态度。

**可跟随性四问**——玩家愿意为这个人往下走，靠的不是他讨喜：

1. 他正在承受什么不该由他承受的东西？不公要具体、要在第一场就看得见。
2. 他正在替谁扛？替一个具体的人扛比替自己扛更有牵引。
3. 他想要的那样东西，玩家自己是不是也想要？尊严、被认出来、把一件事做完、护住一个人，
   比"复仇"这类抽象目标更早生效。
4. 他有什么本事是玩家想借来用一次的？

四问不必全答，但**至少要答出一条，并且它要在第一场就能被玩家看见**——写在人物档案里
而玩家永远遇不到，等于没有。

反面提醒：这四问不是"把人物写讨喜"。让人物一直正确、一直被善待或一上来就赢，会同时
取消不公与欲望，玩家没有可替他争取的东西。**可跟随来自他想要而尚未得到。**

**人物变化要经得起追问。** 声称某人变了，必须指得出：压力测试 → 他的选择 → 得到的局部
结果 → 付出的代价 → 变化后可见的新策略。只有台词宣称"我变了"或情绪强度变化，不算弧线
移动。合法结果包括确认旧信念、出现裂缝、试探新做法、退回旧做法、作出不可逆选择、
明确拒绝改变——不是每次施压都必须转变。

## 四、知识、证词与证据边界

为关键事实建立知识表：

| 事实 | 真相 | 谁知道 | 谁误解 | 谁在说谎 | 可获得方式 | 后续用途 |
|---|---|---|---|---|---|---|

同时维护三层状态，任何一场都不许混：**世界事实**（实际发生了什么）、**人物相信**
（每人知道、误信、怀疑或隐瞒什么）、**玩家知道**（当前看见听见并能合理推断什么）。
人物只使用自己在当前场景已经掌握的信息。

每项关键证据再拆三层：**可见载体**（证词、文件、伤痕、钥匙、位置、可复核行为）、
**直接支持**（该载体足以确认的最小结论）、**未决推断**（仍可能成立但载体尚未证明的
解释、动机或责任）。证据只升级它直接支持的结论，未决推断保持未决。人物可以误判，
设计文件必须保留这三层区别。

新揭示可以改变旧证据的意义，不能凭空改写已经发生的事实。揭示应改变某人**可以采取的
行动**，而不只是补一条百科答案。

## 五、关键选择

关键选择服务人物关系和主题冲突。每个节点记录：玩家掌握的信息、各人物正在争取什么、
选项代表的立场或行动、当下反应、写入的隐藏事实、最近一次回响、延迟回响、对结局的影响。

选项数量跟随局面，不设机械下限。每个选项使用主角在当前语境中可能采取的说法或行动，
不用道德标签，也不预告后果。关键选择让价值、关系、信息或未来机会不可兼得；提交后先给
即时反应，再在后续场景留下延迟回响。

**每个非教学场景都要存在真选择**：不存在一个在多数局面下通吃的选项，且不同选项的后果
可区分。做不到就合并场景——把两个没有选择的场景压成一个有选择的。

## 六、隐藏因果

隐藏因果保存具体记忆：答应了谁、公开支持了谁、看过哪份证词、把物件交给谁、在哪件事上
沉默。每个事实按 `写入 → 第一次读取 → 延迟读取 → 玩家感知` 四段登记，**四段齐全才算数**。

- 只有写入没有读取点的事实，删掉或给它读取点；这条与
  [numeric-design-method.md](numeric-design-method.md) 的"只写不读"审计是同一条规则，
  换成旗标说法。
- **读取优先限制行动广度，不限制内容访问。** 玩家付的代价应该是"这一段做不了那么多事"
  或"这个人不再对你说实话"，不是"这条线你看不到了"。被数值挡在剧情外面比代价不结账更伤。
- 区分**身份型 flag**（她记得你做过什么，后文点名回响）与**匿名数值**（只汇进一个总分）。
  原型里至少 3 处玩家叙事选择写入持久状态并被后续玩家可见文本消费。
- 两名玩家若因不同的伦理选择走到**字字相同的结局**，说明命运感被抹成了钱，判回改。

玩家通过人物措辞、称呼、行动、场景顺序、可达内容和结局感知这些事实。**界面默认不展示
隐藏因果的数字**；确需展示时用语义档（疏／近／知心）加一条可见原因（"昨夜你去了她屋里"），
不给小数精算。界面只展示主角当前合理掌握的信息：随身物件、已知证词、公开承诺。

结果呈现当前代价和仍在运动的压力，不逐项解释内部事实，也不替玩家总结道德意义。

## 七、分支与汇流

先画关键节点和结果，再安排共享场景：

- 关键分支改变人物关系、信息或终局；
- 局部表达分支在短距离内汇流，并保留人物记忆；
- 共享场景根据历史替换人物、对白、物件和可用行动；
- 每条主要路径都能走到一个完整结果；
- 汇流时不得把未选行动当作已发生（反向走读时最容易串线）。

用"节点数 × 变体数 × 关键人物数"估算内容量。首个原型保留少量高重量选择，给人物反应和
延迟回响留下篇幅——**宁可少而被回收，不要多而无人记得**。

## 八、揭示与反转

揭示前检查：玩家是否见过足够的可解释迹象；谁在此前能接触该事实，谁不能；证据为何现在
出现；新事实排除了哪些旧解释；得知后谁必须改变行动。有效揭示常来自"旧事实的新关系"，
不是突然加入一个更大的秘密。

反转要能填满一句话：**因为〈已建立的事实或玩家的选择〉，原计划〈为何不再成立〉，人物
现在只能在〈新代价 A / B〉之间行动。** 填不满就不是反转。

- 回看至少 3 处铺垫指向它，且全部在此前文本中出现过；
- 由人物选择（含玩家的选择）推动，不由巧合推动；
- **延迟揭露不等于反转**：玩家早已知道真相、后面只等人物追上来，那是等待不是震惊。

## 九、节奏

场景在行动、对话、观察和安静时刻之间切换。对白承担人物动作：试探、遮掩、逼问、拉拢、
拒绝、求助、承诺。环境与物件承担背景信息，减少人物解释已经发生的事。

- **不断期待**：当前悬念兑现之前，下一个悬念的种子必须已经种下。
- **同一情绪母题不连超 2–3 场**：连续多场同一情绪高位运行，场景分类做得再细也救不了。
- **信息密度不要均匀**：每一拍都同样"有信息"，真正的证据与决定就没有重量。
- **代价不要当场结清**：本场造成的代价全部在本场还完，就什么都不积累。
- 高压之后需要恢复段；铺垫段每一节仍要有信息量和张力。

界面把人物、现场和当前话语放在视觉中心；历史、证词和关系信息按需展开。关键选择出现前
给足信息，提交后留出人物反应与结果落地的时间。

## 十、前提装置（系统流 / 重生 / 金手指 / 预知）

原作带"主角拥有系统、重生记忆或外挂能力"的前提时，先认清：**装置本身不提供冲突，它
取消冲突。** 全部工艺问题都是同一个——把取消掉的阻力用什么补回来。

先分清是哪一种，两种要的手艺不同：

- **先知型**（重生、预知、看过剧本）：主角比所有人多知道一段未来。工艺问题是**信息边界
  与起点选择**——他知道到哪一步为止、哪些事因他介入而不再照原样发生、从哪个时间点开始
  才既有优势又仍有未知。知道得越全，越要尽早让某件事偏离他记得的版本。
- **授权型**（系统、金手指、外挂能力）：主角获得一份能力契约。工艺问题是**宣告不等于
  新增条款**——装置说话时是在披露既有规则，不是当场发明规则。

共通的四条：

- **契约与披露分开**：装置的规则可以从一开始就完整（作者侧），玩家不必立刻知道全部。
  被禁止的只有事后扩权——契约里从来没有的能力，写到困境时凭空给出来。
- **四种失效**逐条自查：阻力被抽空（对手不再构成威胁）；对手不学习；装置替戏说话
  （该由人物挣扎出来的判断由装置直接播报）；规则通胀（写不下去就给装置加新条款，
  每加一次都追溯性地削弱此前所有段落的紧张感）。
- **无代价的能力等于没有装置**：代价要落在玩家看得见、且主角在意的东西上。
- **装置不替主角做决定**：它可以给能力、给信息、给限期任务，不能替他选。若每次装置宣告
  后主角只是照做，主角就退化成执行者，玩家没有可认同的对象。
- **对手要学习**：装置用过的手段，对手应逐步适应，否则重复使用越来越廉价。

## 十一、一个填好的样例（照这个密度写，不是照这个故事写）

抽象规则最容易被填成空话。下面是三张表各一行填好的样子，用一个通用处境（管家怀疑
少爷动了账，少爷需要他今晚别开口）说明**密度**——不是模板，也不要照抄这个情境。

场景脊柱一行：

| 项目 | 内容 |
|---|---|
| 存在理由 | 删掉它，玩家就拿不到"账房昨夜有人进过"这条证词，第三场的质证无从发起 |
| 视角 | 少爷 |
| 人物目标 | 管家：确认是不是他动的，但不想撕破脸；少爷：让管家今晚别向老爷开口 |
| 反制筹码 | 管家手里有当值簿，他可以明早交上去，也可以"忘了写" |
| 已知信息 | 世界：账是少爷动的。管家：只知有人进过。玩家：全知 |
| 方向性变化 | 管家把当值簿摊开在桌上却不说话——原本"矢口否认"这条路不再成立 |
| 离场状态 | 当值簿留在谁手里；管家是否得到一句承诺 |

关键选择因果一行：

| 项 | 内容 |
|---|---|
| 选项（玩家会说出口的那句） | 「簿子先放我这儿。」 |
| 即时反应 | 管家松手，但没有起身——他在等一句交换 |
| 写入的隐藏事实 | `管家握有你欠他一次` = 真；`当值簿在少爷手里` = 真 |
| 第一次读取 | 第三场管家当众替少爷圆一句话，然后看他一眼 |
| 延迟读取 | 第六场管家用这一次来换他儿子的差事，不容拒绝 |
| 玩家感知 | 称呼从「少爷」变成「你」；多出一个只有欠人情时才出现的选项 |
| 对结局的影响 | 通向"靠人情压住"的结局；关闭"清清白白翻案"那一条 |

反面对照——同一场写坏的样子：管家问「是不是你动的账？」，玩家选「否认／承认」，
系统提示「信任 −5」，下一场没人再提这件事。它的毛病不是文案差：**没有筹码、没有
方向性变化、写入的数值没有读取点、结算只出现在一个读数里**——因果权与结算权两项
都不成立。

## 十二、叙事试玩

试玩记录玩家原话和操作路径，重点观察：

- 玩家如何描述核心人物；
- 玩家相信了谁，依据是什么；
- 关键选择是否形成犹豫和讨论；
- 延迟回响出现时，玩家是否联系到自己先前的行为；
- 结局是否回收了玩家最在意的关系与问题；
- 玩家能否说出"是我做的哪件事导致了这个结果"——答不出即因果权或结算权没有到位。

观察结果回到场景、人物目标、信息披露和选择因果中调整。自然度、人物魅力、沉浸和选择
重量属于独立文案审查与目标玩家试玩，不写成自动化结论。
