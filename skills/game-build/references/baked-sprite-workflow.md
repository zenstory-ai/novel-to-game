# 2.5D 序列帧烘焙工作流（按需）

适用于 2.5D 游戏中需要多朝向、多动作且造型高度统一的角色或物件；若项目已有合用的序列帧或纯代码几何表现已足够，则无需走本流程。

## 流程

1. **生成并核验 3D 模型**：以 `ART_DIRECTION.md` 批准的角色目标图作为唯一参考输入生成 3D 模型，逐项对照目标图核对五官、发型、服饰与标志性道具及头身比；一旦关键造型特征走样立即重新生成，绝不放任走样的模型进入绑定环节。
2. **骨骼绑定与套动作**：自动完成骨骼绑定，按 `GAME_DESIGN.md` 实际用到的状态（待机、行走、攻击、受击等）套用动作库或制作关键帧动画，重点排查关节弯曲处有无穿模与贴图拉伸。
3. **固定机位逐帧烘焙**：在目标引擎无头模式或 3D 软件中，严格按游戏实际的镜头俯角、正交/透视投影、主光源方向和轮廓描边规则，逐朝向、逐动作渲染输出；同一批角色与物件必须统一朝向切分数、帧率、画布尺寸和脚底站立锚点。
4. **打包图集与实机联调**：打包为精灵图集（Sprite Atlas）接入工程（源模型、绑定文件、批量渲染脚本与最终图集一并保存在项目工作区内），放回真实游戏镜头下核查：转身是否生硬顿挫、移动时脚底是否打滑漂移、帧间锚点是否抖动、受光色调是否与底图融合；发现问题只针对性重渲该朝向或动作。
