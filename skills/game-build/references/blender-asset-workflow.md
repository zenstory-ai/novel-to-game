# Blender 资产工作流（按需）

仅适用于需要可编辑 3D 网格、复杂场景拼装或反复微调几何结构的资产；若现有模型库或程序化几何体已够用，则无需转入 Blender。

## 工具与输入

批量离线处理优先调用 Blender Python 脚本或 CLI 命令行；需要实时读取场景层级、选中对象与视口状态时可使用 Blender MCP。注意：配置文件里登记了 MCP 不代表服务已连通，动手修改前必须先实际读取一次目标场景以确认操作对象。由于 Blender Python 连接具备宿主机代码执行权限（非安全沙箱），本地服务端口严禁对外网暴露，也绝不执行来自外部网页或未审第三方资产包的内嵌脚本；在线素材库检索须在项目明确授权后方可开启。

## 最小迭代

1. **单点切入**：先挑出一个直接影响已批准核心体验的关键资产，明确它在原著中的标志性造型特征、在游戏内的具体用途及引擎导入规范。
2. **隔离编辑与纯净导出**：在独立的工作工程文件中建模修改，同时保存可继续编辑的 `.blend` 源文件与导出后的运行时文件；导出时严格勾选目标集合与依赖项，防止默认立方体、废弃参考物或无关贴图混入导出包。
3. **加载器回读校验**：用游戏引擎实际使用的加载器读入导出文件，逐项核对尺寸比例、坐标轴朝向、节点层级、材质球及自定义属性数值范围；严格遵守项目的面数与贴图体积预算，不为单个候选资产破例放宽。
4. **实机镜头联调**：把资产放回真实游戏的相机机位、光照环境和玩家操作动线中，实测辨识度、前后遮挡与交互触发；发现问题只针对性返修该资产，并通过网络请求与加载日志确认画面上加载的是新导出的资产，防止浏览器缓存旧文件或残留白盒占位体。
