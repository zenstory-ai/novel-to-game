# 三维资产、生成模型与空间工具协同（按需）

适用于 3D 或 2.5D 项目中需要立体角色、关键器物、可探索箱庭或复杂场景拼装的场景；动笔前先探测本机与当前会话实际具备的工具能力，自由组合最顺手的路线，不为三维项目强绑单一软件或强装插件。

## 能力探测与弹性路线

按宿主环境现有条件灵活选择组合，不必生硬走满所有环节：

- **图/文生 3D 模型直出（如混元 3D / Hunyuan3D 等服务）**：环境内可调用 3D 生成模型、CLI 或接口时，优先以 `ART_DIRECTION.md` 批准的角色立绘或器物单件设定图（干净底色、轮廓无遮挡）作为参考输入生成带贴图的 `.glb` 网格；生成后先核对比例、五官衣纹与标志性特征，无需二次改动的静态器物或地标可直接导入 Three.js / 目标引擎使用。
- **Blender 精修与场景拼装**：需要修整网格拓扑、压减面数、将原点校准到脚底接地点、拆合可动部件或批量搭建建筑地形时，调用本机 Blender Python 脚本或 CLI 命令行处理；需要实时查看场景层级、选中对象与视口状态时可配合 Blender MCP（配置了 MCP 不代表服务已连通，修改前先读取一次目标场景确认连接；因 Blender Python 具备宿主机执行权限，本地端口严禁暴露公网，也不运行来源不明资产包内的嵌入脚本，在线素材检索须经项目明确授权）。
- **轻量引擎原生构建（无外部 3D 工具时）**：本机既无 3D 生成服务也未装 Blender 时，可直接在 Three.js 或目标引擎中用程序化几何体、挤压路径、受光材质贴图或分层景深立绘（2.5D 纸片剧场）搭建清晰可读的立体空间。

## 最小联调闭环

1. **单点打样定标**：先挑一个直接影响核心体验的主角、核心法宝或主场景地标走通“生成/建模 → 导出 → 入引擎受光”全流程，确认风格、面数与贴图体积合乎预算后再铺开其余资产。
2. **纯净导出留档**：涉及 Blender 编辑时，同步保留工作工程 `.blend` 与导出的运行时 `.glb`/`.gltf` 文件；导出时只勾选目标集合与必要贴图，剔除默认立方体、参考底板或废弃实验物（之前可用的模型在新候选导出失败时保留回退，但核心必需资产缺失时直接报错，不用空壳蒙混）。
3. **实机相机与光影核验**：在 Three.js 或目标引擎的真实相机机位、视口尺寸与玩家移动动线下加载资产，核对单位尺度、坐标轴朝向、脚底接触阴影、主光/天光/雾效层次及前后遮挡与点击拾取，并通过网络面板或加载日志确认画面已读入最新导出的文件而非旧缓存。
