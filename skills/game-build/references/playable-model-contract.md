# 可执行改编模型合同

仅在生成式自由输入、知识权限、事件回放、存档迁移或专属命令需要时读相关部分。
复用已有状态机、对话引擎或场景图，不为了合同再造平行 JSON/YAML；
独立数据只有被运行时消费或被测试逐项对照时才存在。

## 生成模型与规则的边界

模型可解释输入、提出动作候选、写对白或表达已确认结果；规则器唯一提交时间、资源、位置、
物件、知识、承诺、胜负与事件。候选按适用的 schema、前置、数值范围、知识权限和原作边界验证。

表现层只读取已提交状态。换文字、镜头、动画或三维表现不能改变因果、观察者、归属或后续回读。
秘密、证词与误判区分世界事实、玩家知道、人物知道或相信；普通事实不维护多层知识模型。

## 身份专属命令

仅实现 GAME_DESIGN 已选的 `signature_command`，继承
`id / label / intents / slots / validators / commit`，不扩展成通用聊天。

解析器输出有限候选；schema、前置、资源、执行人可用性、空间权限、人物知识、
冲突承诺或原作边界失败时，返回澄清/拒绝且不提交。
否定、条件和互斥表达不能按关键词猜成相反行动。

规则器输出执行轨迹与实际结果，再提交资源、物件、知识、关系、证物、见证和到期事项；
叙述器只表达已确认事实。在线解析记录解析版本、规范化候选与验证结果，
确定性回放从候选开始，不再次请求模型。

私人谈话若能改变主线，只提出事实、承诺、权限、拒绝或见证候选，经同一规则验证；
自由效果字段、聊天摘要或忠诚估值不能直接成为状态权威。

## 延期后果

记录来源行动、到期条件、携带事实、当前状态、重新进入决策面的方式与结清事件。
载入或回放不得提前触发、重复触发或让已结事项复活。

## 回放与兼容性

需要载入时用快照，需要重演时保留事件和规范化输入；不要求每个游戏同时维护两套存储。
同一内容/规则版本、初态、seed 与规范化动作序列应复现规则终态和事件顺序；
在线生成表达不参与权威状态比较。

回滚遵循已批准设计。节点标识、变量语义、行动效果或知识权限变化时迁移或明确拒绝旧存档/日志，
不能静默重解释。局部修改声明基础版本、目标、预期差异与兼容性，重放失败路径及相邻反例，
检查修改范围外的不变量。

这些检查只证明被覆盖的因果与回放，不证明角色魅力、选择重量或复玩意愿。
