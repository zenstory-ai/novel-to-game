# 构建说明契约

构建说明只约束产品和证明方式：

```text
# 成品目标
[目标平台、受众、时长和完整体验；逐字抄入 brief 声明的目标视口 / 朝向 / 最小分辨率，
以及首屏加载 / 总包体上限 / 目标帧率的性能预算]

# 必读设计
[GAME_DESIGN.md, ART_DIRECTION.md]

# 必须保真
[核心循环、世界规则、视觉风格和招牌画面]

# 范围
[必须包含；明确排除]

# 实现自由
根据当前环境自行选择最能实现已批准设计的技术方案。

# 完成证据
[如何运行；必须走通的动作、结果、重开；在目标视口 / 朝向 / 最小分辨率下实测；核对性能预算
（首屏 / 包体 / 帧率）未超]
```

不要粘贴完整小说，也不要规定模型可以从环境正确决定的框架、类、着色器或资产
管线。构建完成后在同一文件记录真实运行命令、已执行验证和当前限制。
