# 剧情过场的生产与接入

当游戏需要在玩家做出选择后播放剧情过场短片时，按本说明将 `GAME_DESIGN.md` 与 `ART_DIRECTION.md` 锁定的分镜制成视频成片并接入运行时。

## 台账、提示词与审片

每段过场在资产台账中登记：所属选项与剧本节点、参考图、分镜表（镜头起止秒数、动作、对应字幕与末帧定格画面）、生成提示词、时长、是否含原声对白、输出文件路径与当前状态。输入参考图预先裁切为目标画幅；场景参考图一律使用不含人物的纯背景空镜（避免与人物立绘叠加生成双胞胎重影），带透明通道的立绘先垫中性纯色背景以防边缘发黑。

生成提示词按镜头顺序写清人物、衣着、核心器物（写明具体形制与材质，防模型偷换）、动作、视线与神情变化（用具体眉眼与肢体动作描写，禁用“脸红、脸白”等字面颜色词以防整张脸变色），注明画风、主角是否出镜及禁生内嵌字幕/水印；若角色开口说话，将台词写入对应镜头提示词并跨片段复用同一句角色音色描述词。成片生成后均匀抽帧核验相貌衣着、动作、器物与末帧定格，不合格的直接修正提示词重生成（严禁靠塞旁白替穿帮画面圆场；一旦试出解决共性问题的有效提示词写法，立即同步更新到其余所有片段）；字幕时间点先按分镜秒数初排，再对照成片张口时刻精校（相邻两句字幕之间必须留足阅读时间），排在视频后的余下台词停在末帧定格图上由玩家点击推进。

## 运行时与体积

- 剧本用成对起止指令包裹过场，区间内台词作为滚动字幕且不得穿插选项或跳转；静态检查脚本自动核验起止闭合且台词句数与字幕时间点数组长度一致。
- 过场视频按需懒加载、单次播放，播完停在末帧画面（已看过的记入全局存档供标题页「鉴赏」重温）；播放期间立绘退场、对话框切为底部窄字幕条、背景音乐压低，支持到点自动换句与点击提前跳句，打开菜单或切后台标签页时视频与字幕计时同步暂停。
- 读档、快进、关闭动态影像、开启“减弱动态效果”或视频加载失败时，直接展示末帧定格图并切为点击推进；浏览器拦截有声自动播放时自动降级为静音播放加字幕。批量转码前先截帧对比选出无可见画质折损的最低码率（原始母片留仓外），并按单次通关下载总量核验托管平台的单文件与带宽限制。
