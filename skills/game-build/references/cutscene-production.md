# 剧情过场的生产与接入

游戏要在选择之后播剧情过场时读这份说明。过场演什么、配在哪些选择上，由 GAME_DESIGN 和 ART_DIRECTION 决定；
这里只讲怎样把分镜做成片、接进游戏。

## 台账与提示词

每段过场在台账里记一条：跟在哪个选项后面、在剧本哪里，以及参考图、分镜、提示词、时长、是否带声、输出文件和状态。
分镜按镜头写起止秒数、动作和配哪句字幕，并写明末帧。参考图先裁成影像画幅，透明底的立绘先铺一层中性底色。

提示词按镜头写谁、做什么、看向哪里、表情怎么变；逐一说明每张参考图是谁、穿什么、拿什么，并写明画风、玩家是否出镜、
不要字幕和水印。要人物开口时，把台词写进它所在的镜头。每个角色固定用同一句声线描述，所有片段照抄，同一人物的声音才会接近。

画面出错时，先回到提示词里找原因，多半是给了模型含糊或自相矛盾的信息：

- 场景参考里已经有人，又另给了人物参考，模型会画出重复的人。场景参考改用不带人物的背景。
- 用颜色写情绪（脸红、脸白），模型会照字面把整张脸涂上颜色。改写成神情和动作。
- 剧情靠它成立的道具，要写出外形，只写名字的话，外形相近的器物会被换成更常见的那一件。

## 审片与字幕

每段成片均匀抽帧拼成一张图来看：人对不对、动作演没演到、道具对不对、末帧稳不稳。不合格就改提示词重新生成，
不要在剧本里补一句旁白去解释画面没演出来的事。某个改法对其他段落也适用时，把它写进所有段落的提示词。

字幕时间点先按分镜里各镜头的起点定，成片出来后再按对白实际开口的时间校准，相邻两句之间留够读完的时间。
排到片尾之后的句子，等影片播完、停在末帧上时由玩家点击推进。

## 运行时

- 剧本用一对指令包住一段过场，中间的台词就是它的字幕，这一段里不放选择或跳转。剧本检查要核对指令成对、句数与时间点个数一致。
- 过场有声，只播一次，播完停在末帧。播放时立绘退场，文本框改成字幕条，配乐压低。
- 字幕到时间点自动换句，玩家点击可以先走一步；打开菜单或切走标签页时影像暂停。
- 读档、快进、关闭影像、系统要求减弱动态或文件读不出时，直接显示末帧，字幕改为点击推进。浏览器拦下有声自动播放时，改成静音播放。
- 看过的过场在跨周目解锁里记下，鉴赏里可以重看。

## 体积

过场只在播放时加载。压缩前先拿一段片子截图比较几档压缩率，选肉眼看不出差别的最低码率再批量处理，原始成片留在项目外。
按一次完整游玩实际下载的量估算流量，再对照托管平台的上传上限和流量额度。
