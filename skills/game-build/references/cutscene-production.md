# 剧情过场的生产与接入

当游戏需要在玩家做出选择后播放一段剧情过场短片时，按本说明执行。过场具体演什么、配在哪些选择点上，由 `GAME_DESIGN.md` 和 `ART_DIRECTION.md` 决定；本文专门讲如何把分镜做成视频成片并接入游戏运行时。

## 台账与提示词

每段过场在资产台账里登记一条记录：紧跟在哪个选项之后、位于剧本哪个节点，以及所用参考图、分镜表、生成提示词、时长、是否含原声对白、输出文件路径与当前状态。分镜表按镜头列出起止秒数、人物动作、对应哪句字幕，并明确标注末帧定格画面。喂给模型的参考图需预先裁切为目标视频画幅；带透明通道的人物立绘需先垫一层中性纯色背景，避免透明边缘在生成视频时发黑或产生噪点。

生成提示词按镜头顺序写清：谁在画面里、做什么动作、视线看向何处、神情如何变化；同时逐一指明每张参考图对应哪个角色、穿什么衣裳、手执何物，并注明整体画风、玩家主角是否出镜，以及严禁生成内嵌字幕和台标水印。若需要角色在画面中开口说话，把那句台词直接写进对应镜头的提示词里；每个角色固定使用同一句音色描述词并在所有片段中原样复用，保证同一人物跨片段的声音听感连贯。

当生成出来的画面出现穿帮时，先回头排查提示词是否给了模型含糊或前后打架的指令：

- **画面里多出双胞胎重影**：如果场景参考图里本来就已经画了人物，又额外上传了人物立绘参考图，模型往往会在画面里画出两个重复的人；场景参考图一律改用不含人物的纯背景空镜。
- **整张脸被涂成大红或惨白**：提示词里如果直接用颜色词描写情绪（如“羞得脸红”“吓得脸白”），视频模型很容易按字面把整张脸涂满油彩；一律改用具体的眉眼神情和肢体动作来描写情绪。
- **关键道具被偷梁换柱**：关系到剧情因果的核心器物必须写出具体形制与材质特征；如果只写一个笼统的名字，模型往往会拿更常见的近似器物顶替。

## 审片与字幕

每段成片生成后，按时间轴均匀抽帧拼成一张九宫格或长条预览图逐项审片：人物相貌衣着对不对、关键动作演没演到位、核心道具准不准、末帧定格稳不稳。凡是不合格的片段，直接修正提示词重新生成，绝不能靠在剧本里硬塞一句旁白去替穿帮的画面打圆场。一旦试出某条提示词写法能有效解决共性问题，立即同步更新到其余所有片段的提示词中。

字幕切句时间点先按分镜表里各镜头的起止秒数初排，等成片出来后再对照人物实际张口说话的时刻精校；相邻两句字幕之间必须留足阅读时间。排在视频结束之后的余下台词，等影片播完、画面稳稳停在末帧定格图上时，再交由玩家点击逐句推进。

## 运行时

- 剧本中使用成对的起止指令包裹一段过场，夹在起止指令之间的台词即作为该段过场的滚动字幕，且过场区间内部不得穿插分支选项或章节跳转。剧本静态检查脚本需自动核验：起止指令成对闭合、内部台词句数与字幕时间点数组长度完全一致。
- 过场视频带音轨且只单次播放，播完即停在末帧画面上。播放期间人物立绘退场、常规对话框切换为底部窄字幕条、背景音乐自动压低音量。
- 字幕到时间点自动换句，玩家点击画面也可提前跳到下一句；打开系统菜单或切到浏览器后台标签页时，视频与字幕计时同步暂停。
- 在读档恢复、开启快进、关闭动态影像、系统开启“减弱动态效果”或视频文件加载失败时，直接展示末帧定格图并将字幕切换为点击推进；当浏览器拦截有声自动播放时，自动降级为静音播放并正常显示字幕，确保玩家在任何环境下都不会漏掉剧情。
- 玩家已经看过的过场自动记入跨周目全局存档，随时可在标题页的「鉴赏」界面重温。

## 体积

过场视频采用按需懒加载，只在即将播放前请求文件。批量压制前，先挑一段代表性成片截帧对比几档码率，选出肉眼看不出画质折损的最低码率参数再批量转码，未压缩的原始母片留在仓库目录之外。最后按单次完整通关实际会触发下载的视频总量估算带宽消耗，确保符合目标托管平台的单文件大小上限与月度流量额度。
