# 语音资产生产规范

仅在 `ART_DIRECTION.md` 明确启用角色配音时使用；配音只演绎已定稿台词（不得加戏改词），且必须同步提供字幕。默认在构建期预先合成音频并落盘为工作区静态资产；若需运行时联网实时合成，须先由 `PRODUCT_BRIEF.md` 批准联网、成本、隐私与断网降级方案。音色库须具商用授权（克隆真人声线须持当事人明确授权），调用接口时只传单句台词与必要的生僻字注音。

## 台账与验证

优先复用工程现有的对白表或资产清单，按缺项补齐：台词 ID、说话角色、触发条件、定稿文本、语种与生僻字注音、声口要求、绑定字幕、音色来源与授权状态、音频文件路径、缺音降级方式与生成状态（无现成对白表时再新建最小配音台账）。字幕与配音必须源自同一条定稿文本（台词一旦改字，旧音频立即作废重录）；构建期生成的音频文件保存在项目工作区内，无论是预生成音频还是已批准的实时合成语音，均须在真实触发点实机核验说话人归属、专有名词读音、字幕同步、跳过、静音开关、缺音回落与重开表现，确保关闭声音或音频加载失败时玩家依然能顺畅读懂并打通游戏。
