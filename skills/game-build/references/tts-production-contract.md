# 语音资产生产规范

仅在 `ART_DIRECTION.md` 明确选用角色配音时启用；配音只用于演绎已定稿的台词，不得擅自加戏改词，也不能成为传达关键玩法信息的唯一渠道（必须同步提供字幕）。

## 授权与数据边界

默认在构建阶段预先合成音频并保存为本地静态资产。若需在玩家游玩时实时联网合成语音，必须先由 `PRODUCT_BRIEF.md` 明确批准联网请求、外部文本传输、单价成本、隐私合规与断网降级方案；API 密钥严禁打入前端代码包、代码仓库、运行日志或测试证据中。调用语音合成接口时只发送待配音的单句台词与必要的生僻字注音，严禁上传原著全文、设计文档或无关个人信息。

所选音色库必须具备合法商用授权，克隆真人声线必须持有当事人的明确授权证明。宣传片旁白不能充当游戏内角色配音，单条试音成功也不代表自动获批全量台词配音。具体合成工具按当前环境的可用能力与许可协议选用，不绑定特定供应商或单一模型。

## 台账与验证

优先复用构建或运行时实际读取的对白表或资产清单，为每条配音台词补齐：台词 ID、说话角色、触发条件、定稿台词文本、语种与生僻字注音、角色声口要求、绑定字幕、音色来源与授权状态、音频文件路径、缺音降级方式与当前生成状态；工程尚无现成对白表时再新建最小配音台账。

字幕与配音必须源自同一条定稿台词文本，一旦台词改字，旧音频立即作废重录；各角色的音色需贴合已批准的性格声口、文化身份并保持角色间清晰可辨。构建期生成的音频文件必须保存在项目工作区内；无论是预生成音频还是实时合成语音，都必须在游戏的真实触发位置实机核验说话人归属、专有名词读音、字幕同步、手动跳过、静音开关、音频缺失回落及重开表现，确保关闭声音或音频加载失败时玩家依然能顺畅读懂并打通游戏。无需在仓库里归档冗长的接口请求原始报文或重复的测试报告。
