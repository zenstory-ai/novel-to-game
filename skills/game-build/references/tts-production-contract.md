# 语音资产生产合同

只在 `ART_DIRECTION.md` 已选择角色语音、旁白或朗读时启用。语音表现已批准的台词和角色方向，
不创造新剧情，也不成为规则、目标、选择或结果的唯一载体。

## 产品边界

- 默认在构建期生成或录制成本地资产，游戏运行不依赖网络、供应商或密钥。
- 运行时动态语音只有在 PRODUCT_BRIEF 已批准联网、外部文本处理、成本、隐私和服务失效行为时采用；
  客户端不持有服务密钥。
- 只发送逐句台词与必要读音，不上传小说、SOURCE_BIBLE、设计文档、未公开手稿或无关个人信息。
- 营销旁白与游戏内语音分别记账；一次成功不自动扩大到全量配音。

## 唯一台账

每条采用语音只记录一行：

`line_id | speaker | trigger | exact_text | language/pronunciation | voice_direction | subtitle_key | provenance/rights | output | fallback | status`

- 字幕和语音输入由同一 `exact_text` 派生；台词变化时旧音频失效。
- `speaker` 继承美术方向的年龄感、节奏、文化依据和可听辨差异，不按语言给所有角色共用一个声线。
- 音色只使用自录、获授权真人、获授权公共音色或合成设计音色；真实人物克隆需要明确许可。
- `fallback` 至少保证静音、缺文件和自动播放受限时仍能读懂并完成游戏。

## 生产与检查

1. 使用当前环境中合适的工具，按官方文档核实许可、输入处理和输出格式；仓库不固定供应商或模型。
2. 密钥只从受信环境读取，不进入仓库、客户端、日志正文或证据文件；失败重试有明确上限。
3. 把最终音频保存到工作区稳定路径；临时 URL、供应商任务页和缓存不是游戏资产。
4. 确认文件非空、可被目标运行时解码，时长/声道/响度合理，并在实际触发位置播放一次。
5. 检查字幕同步、说话者标识、专名读音、重复频率、跳过、静音、损坏文件和重开路径。

自然度、魅力和音色偏好不写成机器 PASS，也不新增强制真人听审。可降级语音失败时保留字幕或普通
音效并记 limitation；brief 明确列为必需的语音失败时，对应玩家效果 FAIL。

构建完成后只回写上述台账的本地输出、来源/权利、基本媒体信息和结果，不归档完整 API 往返、供应商
页面截图或重复报告。
