# TTS 生产契约

本契约只在 `ART_DIRECTION.md` 选择角色语音、旁白或 TTS 时启用。它把已批准的逐字台词变成
可复现、可替换、可静音降级的游戏资产，不负责创造新剧情，也不把供应商写回核心设计。

## 零、采用范围交接

构建前逐条读取 ART_DIRECTION 的语音候选表，只生产 决定=采用 的最小集合。某条缺触发窗口、
增量价值、台词稳定性、频率/权利判断或字幕与缺音 fallback 时，退回美术方向补齐，不由构建
“顺手多配几句”。营销片与游戏内资产分开记账；一次生成成功不扩大批准范围。全量预录与运行时
动态各须附 ART_DIRECTION 写明的适用理由，不能把可调用 API 当理由。

## 一、默认边界

1. **构建期优先**：默认在构建时合成、验证并把音频打进游戏包；运行时不需要网络或密钥。
2. **运行时动态须显式批准**：只有 `PRODUCT_BRIEF.md` 已批准联网、外部文本处理、成本与服务
   失效行为时才可启用。浏览器、移动端和桌面客户端不得持有供应商密钥，调用必须经过受信服务端。
3. **最小发送**：只发送逐句台词与必要读音控制，不上传完整小说、`SOURCE_BIBLE.md`、设计文档、
   未公开手稿或无关个人信息。未公开内容须有用户对该外部处理的明确授权。
4. **不靠语音救设计**：语音缺失、静音或自动播放受限时，核心规则、目标、结果和操作仍可理解。

## 二、逐句清单与权利

生成前建立唯一真值：

`line_id | 角色/旁白 | casting_id | 性别呈现/年龄感 | 触发状态 | 逐字台词 | 语言 | 字幕键 | 声口/情绪 | 专名读音 | 音色来源 | 权利证据 | 资产级别 | fallback`

- 字幕与 TTS 输入由同一条 `line_id` 派生；修台词必须使旧音频指纹失效，不能只改字幕。
- 每个角色从 ART_DIRECTION 的角色级选角表取得独立 `casting_id` 和音色引用；不得只按语言选一个
  通用音色。原著 / 设计已锁定男声、女声或其他性别呈现时，构建须逐句保持；未锁定时不得猜测。
  旁白与角色不得静默共用音色，一人分饰多角必须有方向层批准及可听辨差异。
- 音色来源只用自录、授权真人、授权公共音色或合成设计音色。真人克隆须有书面许可；公共音色也要
  记录商业使用范围。权利证据不足的资产不得进入交付包。
- 供应商条款、隐私、内容留存 / 训练用途、目标市场与商业发行许可在实际调用前复核；免费额度
  只说明价格，不自动证明商业授权或生产可用性。

## 三、调用与恢复

- 密钥只从环境变量或密钥管理器读取，不进命令参数、仓库、客户端包、source map、请求证据、
  错误正文或追踪字段。生成源文件和含供应商标识的私有 sidecar 默认不进版本库。
- 不为一次 HTTP 调用新增 SDK 依赖；当前运行时已有可靠 HTTP 客户端时直接使用。若确有产品需要
  新依赖，先回用户确认。
- 为每次调用设置有限超时；网络错误、`429` 与可恢复的 `5xx` 使用有上限的指数退避并尊重
  `Retry-After`，认证、余额、参数与权利错误立即失败。并发不超过账户当前限制。
- 请求指纹至少覆盖供应商、端点、模型、音色引用、逐字台词、语言 / 读音控制、情绪、语速、
  格式、采样率和编码参数。只有指纹、源文件哈希都相同时才可无调用复用；只改本地混音时可复用
  原始响应。
- 每条失败独立记录，可降级项落字幕 / 非语音反馈继续构建；必需项失败则停止交付，不让整条
  自动化无限等待。

## 四、响应与音频门禁

HTTP 成功不等于音频可用。每个生成场景至少验证：

1. 响应媒体类型与文件签名合理，文件非空且能被目标解码器完整解码；错误 JSON 不得误存成音频。
2. `ffprobe`、引擎导入器或目标平台等价工具记录格式、时长、采样率、声道和码率；再实际播放一次。
3. 检查全静音、异常头尾静音、截断、爆音 / 削波、响度超界、速度失真与背景噪声；本地响度标准
   与音乐 ducking 由项目锁定，不把“能听见”当混音通过。
4. 按实际采用用途覆盖短反馈、长段、情绪切换、停顿、专名、多音字、数字和目标语言；核对控制标记
   未进入输出文本且字幕与语音使用同一逐字来源。自然度与音色是否合适不写成机器确定结论。
5. 在静音、缺文件、损坏文件、网络断开、限流与服务错误下复跑；fallback 不丢规则、目标与结果。

## 五、构建证据

`BUILD_BRIEF.md` 的语音资产台账在生成后逐条回写：

`line_id | casting_id/speaker | provider/model | voice provenance | request_sha256 | source path/sha256 | final path/sha256 | duration | codec/rate/channels | loudness | subtitle key | rights | generation result`

去密钥请求摘要、重试记录、解码 / 音频测量报告存入工作区内持久证据路径；临时 URL、供应商页面
截图或口头说明都不算证据。生成音频能否进入 Git 由其授权与仓库体量政策决定，但最终
游戏包使用的本地资产及哈希必须可追溯。
