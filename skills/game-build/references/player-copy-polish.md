# 上屏文字审校

正式版交付前，通查代码与数据里所有玩家看得见的文字：标题、提示、界面与弹窗、任务追踪、招式与道具说明、旁白、对白、选项、阻断提示、结算总结卡、分享转发语与结局页。润色只改表达，不改 `GAME_DESIGN.md` 已定的胜负条件、数值门槛、代价、证据来源与揭露顺序。

- **不外露元说明**：删掉向玩家解释「为什么这样设计、接下来考什么、改编自哪一回」的作者旁白（「本段旨在…」「以下选项代表不同路线」「此处为不可逆节点」）。紧迫感与后果的分量由在场人物、环境变化或世界内的规矩传达；确需防误触的说明只用简短的界面短语。
- **不外露策划术语、内部字段与场外批注**：招式不写「物理单体高伤」，院门不弹「好感度不足」，选项不挂「【善良】」「（推荐）」「【看广告稳过】」。反馈、门槛与说明换成符合作品时代语体的世界内事物与具体效果，数值与回合数照实保留；设计要求隐藏的量，用场景事实交代原因（「门闩已落，今夜未留灯」）；激励提示或解锁入口用贴合世界观的求助措辞单独呈现，不混进人物对话选项。
- **去掉套路腔与大模型烂梗**：删净十来字一断的电报体碎句、把刚演完的画面再总结一遍的尾巴、同一意思换词车轱辘复述、给普通词乱加的引号、先立假靶子再否定的二元套句，以及公文腔与高频套话（「嘴角勾起一抹冷笑」「命运的齿轮开始转动」「空气仿佛凝固」「更大的风暴即将来临」）。台词贴合角色的出身、名分与当下意图；古风或时代题材不混入现代网络热梗与心理咨询腔。选项写当场说出口的话或做出的动作，不写道德评判或提纲式概括；结果毫无差别的寒暄直接合并为顺畅对白，不拆成假选项充数。
- **零背景也读得懂**：多人多物同场时点名具体对象；新人物、器物或规矩第一次影响判断时，借场内的一句话交代它的身份与用途。
- **不剧透、不串台**：背包物品名与描述、头衔、路标、战斗日志与队友闲聊不得点破尚未揭晓的伪装或秘密，也不让不在场的角色插话。
- **图文对得上**：复用的场景、人物与影像资产，逐处核对当处文字交代的时辰、天气、场所与人物手里的东西；对不上就为该状态另出资产或改用不带状态的中性资产，不拿别的状态顶替。原著或设计有意让图文矛盾（例如作为线索）的除外。
