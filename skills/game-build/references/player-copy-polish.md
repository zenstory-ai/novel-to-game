# 上屏文字审校

正式版交付前，通查代码与配置里所有玩家看得见的文字：标题、操作提示、界面与弹窗、任务追踪、招式与道具说明、旁白、对白、选项、阻断提示、结算卡、分享语与结局页。审校只润色表达，不改动 `GAME_DESIGN.md` 已锁定的胜负条件、数值门槛、代价、证据来源与揭露顺序。

- **不外露作者元说明**：删净向玩家解释「为什么这样设计、接下来考什么、出自原著哪一回」的场外旁白（如「本段旨在…」「以下选项代表不同路线」「此处为不可逆节点」）。紧迫感与抉择分量靠在场人物、环境异动或世界内规矩自然带出；确需防误触的系统确认只用简短界面短语。
- **不外露策划术语、内部字段与场外批注**：招式说明不写「物理单体高伤」，院门阻拦不弹「好感度不足」，对话选项不挂「【善良】」「（推荐）」「【看广告稳过】」。反馈、门槛与说明一律写成贴合作品时代语体的世界内事物与具体效果，数值与回合数如实保留；设计要求隐藏的变量，用场景事实交代原因（如「门闩已落，今夜未留灯」）；激励广告提示或解锁入口用贴合世界观的求助措辞单独放置，不混进人物对话选项。
- **清掉套路腔与现代热梗**：删净十来字一断的电报体碎句、把刚演完的场面再总结一遍的收尾句、同一意思换词连说两遍、给普通词乱加引号、先立假靶子再否定的套路句，以及公文腔与网文烂俗套话（「嘴角勾起一抹冷笑」「命运的齿轮开始转动」「空气仿佛凝固」「眼中闪过一丝不易察觉的情绪」「更大的风暴即将来临」）。台词须符合角色的出身、名分与当下盘算；古风或年代题材严禁混入现代网络热梗与心理咨询腔。选项直接写角色当场说出口的话或做出的举动，不写道德贴签或提纲概括；结果毫无差别的寒暄直接并入顺畅对白，不拆成假选项凑数。
- **没读过原著也能看懂**：多人多物同场时点名具体对象；新人物、新器物或新规矩首次影响玩家判断时，顺手借场内一句话带出它的来历与用处。
- **不剧透、不串台**：背包物品名与说明、人物头衔、路牌、常驻短目标条、战斗日志与队友闲聊一律严守主角当下知情边界，不得提前点破尚未亲见或揭晓的转折、伪装与隐情，也不让不在场的角色凭空插话。
- **图文严丝合缝**：复用的场景、立绘与视频资产，逐处核对当屏文字写明的时辰、天色、地点与在手器物；对不上就为该状态补做资产，或改用不带特定状态的中性资产，不张冠李戴。原著或设计有意拿图文出入作破案线索的除外。
- **去说明书化、控字密度与防剪过头**：把写给实现核对的精确公式、倍率推导与策略攻略留在设计文档和代码里，不直接印在按钮、选项注脚、状态卡、底栏注或败北长篇提示中。按位置控短文字：按钮与状态签用清晰 2–6 字短词，严禁不可读的单字怪缩写，风险计量条旁留 4–6 字后果短签；常驻目标、提示与预警保持单行一眼可读（约 20 字内）；选项直写角色当场言行，不附大段数值解读或括号补丁说明；非剧情弹窗不堆百字以上纯文字说明。操控图例与继续提示须按当前输入形态双态适配（触屏与窄屏不误显键盘字样），桌面端必要快捷键保留极简内联键帽；同时清掉跨控件复述：同一目标、状态或规矩已在画面标记、图标或前一控件交代清楚的，删去其余位置的重复句。
