# 动态媒体生产规范

仅在 `ART_DIRECTION.md` 选用动态媒体（视频短片、生成式音乐或音效）时启用。调用前先核实宿主环境的工具可用性、商用授权（使用真人肖像或声线参考须持明确授权）与单价成本；仓库内只保存与具体供应商解耦的资产台账、提示词和落盘成品文件。

## 最小台账与连续性验证

优先复用工程现有的资产清单表，按资产 ID 补齐触发条件、参考图、不可走样的锁定事实（角色五官、衣着纹样、场景陈设、道具状态与画风）、允许变化的动作范围、起止衔接边界、输出文件路径、版权来源、降级回落方案与当前状态。

抽帧核查代表性画面中的人物相貌、场景方位和关键道具是否走样，状态变化是否准确落在指定镜头内，以及画面是否提前剧透了玩家尚未获知的秘密；已有目标图或立绘参考时必须拿参考图约束生成，不得仅靠改写文字提示词去赌画面一致。在真实触发点验证正常播放、手动跳过与异常降级：玩家跳过或开启减弱动态模式后，必须落入同一个合法的规则状态并完整保留后续决策信息与操作入口。

## 成本闸门与生成音画

生成视频和长曲目的单价远高于静态图片：务必先用静帧回落画面把全流程跑通，等分支交互、台词文案、热区坐标与剧情路线全部锁定后再对照台账生成动态影像（批量提交前先试做一段样片核验相貌保持、多镜头衔接、口型音色匹配与实际消耗额度）。

生成背景音乐时写明场景情绪、主奏乐器、曲速、是否循环及「纯器乐无人声」；生成音效时写明发声物体、具体动作、时长及「无背景配乐」。结合起音密度与高频谱亮度筛选起伏平缓、温润不刺耳的候选版，后期统一裁掉首尾空白静音、标准化响度（背景音乐压在阅读舒适音量下，音效峰值留出防爆音余量）、长曲目加淡入淡出、环境底噪用交叉淡化做无缝循环；运行时长曲目流式加载、短音效解码进内存缓冲，加载失败时自动回落到合成音效或静音模式。
