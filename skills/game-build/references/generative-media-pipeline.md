# 动态媒体生产合同

仅在 ART_DIRECTION 选择动态媒体时使用。工具和模型由环境决定，使用前核实当前能力、许可与费用。
需要改变视角、位置或空间关系的交互不能用视频伪装。

## 最小台账

复用构建或运行时实际消费的资产登记表，按资产标识补齐触发条件、参考、锁定事实、允许运动、
起止边界、输出、来源与权利、降级方式和状态；没有现成记录时再建最小台账。

- 参考声明允许控制的事实；锁定身份、服装、地理、道具状态与已批准风格。
- 本镜只改变允许的动作与状态；开始/结束边界需能衔接相邻镜头。
- 来源与权利可追溯，真实人物参考须有明确授权；不上传与本资产无关的原文或私人信息。

## 连续性与运行验证

检查代表帧中的身份、地理和道具是否漂移，状态变化是否发生在正确镜头，
是否泄露未获知事实；已有参考时用其约束变体，不用提示词临时补设计空白。

在实际触发位置验证播放、跳过与降级。跳过或低动效版本仍进入同一合法状态，
保留必要信息、输入机会和结果。最终运行文件保存在工作区，供应商任务页不是资产。

## 成本闸门与顺序

视频和长音乐的单价远高于静帧。先用回落画面把游戏做完并打磨：交互、文案、热区与路线都定下来以后，
再按台账生成影像；改剧本或改画面会让已生成的片段作废。开工前先生成一段代表片验证身份保持、多镜头连续、
口型与声音、成本，再成批提交。

## 剧情过场台账

每段一条：对应的选择与剧本标签、参考图（场景与在场人物）、分镜（每个镜头的起止秒数、动作、配哪句字幕、末帧）、
提示词、时长、画幅、分辨率、是否带声、输出路径与状态。提示词按镜头写「谁、做什么、看向哪里、表情怎么变」，
并写明画风、人物与参考图的对应关系、玩家是否出镜、不要字幕与水印。
参考图先处理成影像画幅；透明底的立绘铺一层中性底色再上传，否则模型会自行补背景。
生成后统一转码为目标分辨率、可边下边播的格式，抽代表帧检查身份、服装与场景是否漂移、动作是否演到，
再抽出末帧作为定格回落图；字幕时间点按实际成片校准后写进运行时注册表。
不合格的段落改提示词重生成，不要用文字去解释画面里没演出来的动作。

静帧上的循环微动（以那张静帧为首尾帧）只作待机氛围层，单独登记，不与过场混用一个台账。

## 生成音乐与音效

曲目按场景情绪写乐器、速度、是否循环与「无人声」；音效写声源、动作、时长与「无背景音乐」。
后期统一处理：去首尾静音，按响度归一（曲目压在读字底下，音效峰值留余量），曲目首尾淡入淡出，
环境声用首尾交叉淡化做成无缝循环。运行时长曲目用流式播放、短音效解码进缓冲，读不出时回落到原有的合成音。

## 供应商边界

生成能力由运行环境提供。项目里只保存与供应商无关的台账、提示词和成品文件；调用方式、账号与密钥留在项目外的
adapter 配置与环境变量里，不写进仓库、台账或运行时代码。
