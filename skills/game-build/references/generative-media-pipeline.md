# 动态媒体生产合同

仅在 ART_DIRECTION 选择动态媒体时使用。工具和模型由环境决定，使用前核实当前能力、许可与费用。
需要改变视角、位置或空间关系的交互不能用视频伪装。

## 最小台账

复用构建或运行时实际消费的资产登记表，按资产标识补齐触发条件、参考、锁定事实、允许运动、
起止边界、输出、来源与权利、降级方式和状态；没有现成记录时再建最小台账。

- 参考声明允许控制的事实；锁定身份、服装、地理、道具状态与已批准风格。
- 本镜只改变允许的动作与状态；开始/结束边界需能衔接相邻镜头。
- 来源与权利可追溯，真实人物参考须有明确授权；不上传与本资产无关的原文或私人信息。

## 连续性与运行验证

检查代表帧中的身份、地理和道具是否漂移，状态变化是否发生在正确镜头，
是否泄露未获知事实；已有参考时用其约束变体，不用提示词临时补设计空白。

在实际触发位置验证播放、跳过与降级。跳过或低动效版本仍进入同一合法状态，
保留必要信息、输入机会和结果。最终运行文件保存在工作区，供应商任务页不是资产。
