# 生成式媒体的生产与接入

仅在 `ART_DIRECTION.md` 选用视频过场、生成音乐音效或角色配音时使用。调用前核实工具可用性、商用授权与单价（真人肖像或声线须有当事人明确授权）；仓库只存与供应商无关的资产台账、提示词与成品文件。

## 先锁内容，再生成

视频与长曲目远比静帧贵：先用替代静帧把全流程跑通，等分支、台词、热区与路线全部定稿，再按台账生成；批量之前先做一段样片，核对相貌保持、镜头衔接、口型音色与实际消耗。台账逐项记录触发条件、参考图、不可走样的事实（五官、衣纹、陈设、道具状态、画风）、输出路径、来源与授权、降级方案与状态。

## 视频过场

- **参考图**：先裁成目标画幅；场景参考一律用不含人物的空镜，否则会与立绘叠出重影；透明底立绘先垫中性纯色底。已有目标图或立绘时必须拿它约束生成，不只靠改提示词去赌一致性。
- **提示词**：按镜头顺序写人物、衣着、动作、视线与神情；器物写明形制与材质，防止被偷换；神情用眉眼与肢体动作描写，不用「脸红」「脸白」这类字面颜色词，否则整张脸会被染色；注明画风与不生成字幕水印。人物开口时把台词写进对应镜头，并跨片段复用同一句音色描述。没有参考立绘的配角同样写明是否成年与外观年龄段；用带幼小意味的称谓（如「小丫头」）指代成年人时要改写，否则常被画成孩童。
- **审片**：均匀抽帧核对相貌、外观年龄、衣着、器物与末帧定格，并检查画面有没有提前剧透玩家还不知道的事。不合格就改提示词重生成，不靠旁白替穿帮画面圆场；试出解决共性问题的写法后，同步到其余片段。
- **字幕**：时间点先按分镜初排，再对照成片的张口时刻精校，相邻两句之间留足阅读时间。已与口型或配音绑定的台词，不重生成媒体就不能改句数与文字。
- **运行时**：过场按需加载，播完停在末帧；播放时立绘退场、对话框收成字幕条、配乐压低，打开菜单或切到后台时视频与字幕计时一起暂停。读档、快进、关闭动态影像、减弱动效或加载失败时，直接显示末帧并改为点击推进——跳过或降级后必须落在同一个规则状态，分支、台词与结局一样不少。有声自动播放被拦截时降级为静音加字幕。按单次通关的下载总量核对托管平台的单文件与带宽限制。

## 音乐、音效与配音

- 音乐提示写明情绪、主奏乐器、曲速、是否循环与「纯器乐无人声」；音效写发声物、动作、时长与「无背景配乐」。加载失败时改用合成音或静音。
- 配音只演绎定稿台词，并同步提供字幕；字幕与配音出自同一条文本，台词改字则旧音频作废。默认在构建期合成并保存到本地；运行时联网合成须先由 `PRODUCT_BRIEF.md` 批准联网、成本、隐私与断网替代方案。调用时只传单句台词与必要的注音。
- 关闭声音或音频缺失时，游戏仍须能完整读懂并打通。
