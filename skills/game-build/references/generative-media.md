# 生成式媒体的生产与接入

仅在 `ART_DIRECTION.md` 选用视频过场、生成音乐音效或角色配音时使用。动工前先核实工具可用性、商用授权与单价（使用真人肖像或声线须有本人明确授权）；仓库内只存与特定供应商解耦的资产台账、提示词与成品文件。

## 先锁内容，再生成

视频与长曲目远比静帧昂贵：先用替代静帧跑通全流程，等分支、台词、热区与路线全部定稿，再按台账出片；批量生成前先做一段样片，核对人物不走样、镜头衔接、口型音色与实际开销。台账逐条记清触发条件、参考图、不可走样的特征（五官、衣纹、陈设、道具状态、画风）、输出路径、来源与授权、降级方案及当前状态。

## 视频过场

- **参考图**：先裁成目标画幅；场景参考图一律用不带人物的空镜，免得与立绘叠出重影；透明底立绘先垫一层中性纯色背景。已有目标样张或角色立绘时必须拿它垫图约束，不能光靠改提示词去碰运气。
- **提示词**：按镜头顺序写明人物、衣着、动作、视线与神情；器物写清形制与材质，防模型乱换道具；神情用眉眼与肢体动作描写，不用「脸红」「脸白」这类颜色词，免得整张脸被染色；注明画风及「无字幕、无水印」。人物开口说话时把台词写进对应镜头，并跨片段复用同一句音色描述。无参考立绘的配角同样写明是否成年与外观年龄段；含幼小意味的成年人称呼（如「小丫头」）先改写成明确成年描述，防止被画成幼童。
- **审片**：均匀抽帧核对五官相貌、外观年龄、衣着、器物与末帧定格，并检查画面有没有提前漏出玩家尚不知晓的隐情。穿帮就直接改提示词重出，不靠旁白硬圆；试出能解决共性毛病的写法后，同步到同批其余片段。
- **字幕**：时间轴先按分镜初排，再对着成片张口时刻逐句校准，前后两句留足阅读间隔。已与口型或配音绑死的台词，不重出媒体就不得增删句数或改字。
- **运行时**：过场按需加载，播完定格在末帧；播放期间收起立绘、对话框缩为底部字幕条、压低配乐，打开菜单或切到后台时视频与字幕计时同步暂停。读档、快进、关闭动态影像、减弱动效或加载失败时，直接展示末帧并改为点击翻页——跳过或降级后必须落在同一规则状态，分支、台词与结局一句不丢。有声自动播放被浏览器拦截时降级为静音配字幕。按单次通关下载总量核对托管平台的单文件与带宽上限；小游戏严禁把视频与长音频打进 4 MB 主包，一律走分包或远程按需加载。

## 音乐、音效与配音

- 音乐提示词写明情绪、主奏乐器、速度、是否循环及「纯器乐无人声」；音效写清发声物、动作、时长及「无背景配乐」。加载失败时回退为合成音或静音。
- 配音只录定稿台词并同步配齐字幕；字幕与配音同源，台词改字则旧音频作废。默认在构建期离线合成并存入本地；若需运行时联网合成，必须先由 `PRODUCT_BRIEF.md` 批准联网、成本、隐私与断网降级方案。调用接口时只传单句台词与必要注音。
- 关掉声音或音频缺失时，游戏仍须能完整读懂并通关。
