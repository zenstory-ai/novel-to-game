# 美术方向的改编判断

## 审美与成色

古装或年代题材把历史朝代、绘画媒介与人物美化程度拆开锁定：「古风」不等于整屏泛黄做旧，「现代审美」也不等于改穿现代衣裳；调整画风时只改用户点出的那一项，不动原著的时代风貌与人物身份特征。同一人物、器物与地标在不同状态和机位下保持统一的识别特征。

除 `targetFinish: graybox` 外，画面完成度向同品类主流商业作品的实机截图看齐——随手截一帧都该像成熟游戏，不像临时拼凑的技术演示；标题页、年龄确认页等门面画面及商店宣传图须与实机画面保持同一水准，不拿纯文字页凑数，也不搞精修封面配简陋实机。界面底纹、边框与字体取材自作品时代的器物（如宣纸账册、木牌漆器、旧报刊档案），古风、民俗与写实题材禁用深蓝黑底配紫青霓虹渐变、毛玻璃圆角悬浮卡及整屏泛黄滤镜。同屏人物、立绘与场景物件统一线稿粗细、上色手法与色温；角色与地面共用镜头俯角、透视比例与主光方向——跑图小人、战斗单位与对话立绘共享人物设定但按各自机位分别出图，俯视地图上不拿平视立绘缩小顶替。可行走地图把道路、建筑与地貌画成连贯绘景，不把零散物件硬贴在纯色底板上。

## 可读与主视野保护

色光、材质、动效与声音只反映规则已结算的状态，不暗示未实现的机制，也不向玩家或剧中人提前泄密。

- **视觉先于文字，但不剪过头**：状态、风险、目标与克制关系优先用场景物件、姿态、轮廓图标、色光动效与数字变化表达；必须上字时用清晰短词（2–6 字），严禁不可读的单字怪缩写，风险计量条旁留 4–6 字极短后果签，整句说明下沉到按需检视层。区分「说明墙」与「内联键帽」：桌面端新机制或非通用快捷键不可全藏进暂停菜单，优先在对应资源图标旁挂极小内联键帽，或在战斗等情境期于底栏贴单行紧凑键帽条；操控图例与继续提示按当前输入形态双态适配（触屏与窄屏不误显键盘字样）。功能图标用图形或人物小像配短名，不拿单字或 Emoji 充当图标。
- **主视野保护、层级与面板预算**：画面中央及主角行动、对阵、演出的主视野区保持开阔完整，不被面板、卡片或大字气泡切碎。常驻界面只放当下决策依据：`system-led` 与 `hybrid` 主屏常驻区一般不超过四块，单条目标或提示约 20 字内；`narrative-led` 守住阅读排版质感，外围功能栏同样收束，精简不等于砍剧情和核心规则。战中预警与提示优先吸附在顶栏或底栏边界内，不以独立浮层飘进对阵区赌避让；对白、抉择浮层展开时隐藏场景功能坞，瞬态横幅（如蓄力、转阶段播报）层级高于单位名牌与立绘；跨回合预警保持醒目直至处理完毕。
- **禁画清单与去重瘦身**：严禁顶、侧、底三面同时铺满按钮条或信息卡；严禁同一目标或预警多处重复写；严禁标题页挂纯文字「帮助/须知」说明书，也不把原著百科、调试信息或章节看板铺满主屏。界面不靠滚动条塞内容（隐藏滚动条仍能滚也不行）；超出一屏先删冗余说明与重复字段，确需保留的多项列表再分页、改为格子配侧栏详情或退入按需检视层。
- **竖屏、画布与小游戏安全区**：竖屏（如 `390×844`）标题主按钮沉入底部拇指区、不压主视觉人物面部；连续画布按视口比例适配，画布内气泡钳位在安全边距内，防露灰边与裁切。目标含微信或抖音小游戏时，右上角避让系统胶囊按钮，结合刘海与底栏安全区排布顶栏（暂停、返回、跳过、任务与资源栏不压胶囊下方），竖屏高频点按收在下半屏拇指区并兼顾桌面等比缩放；包体受限项目拆清首包极轻资源与分包或远程资源。

## 视觉目标包与媒体

仅在画风取向分歧大或 `targetFinish` 要求高完成度时，才先做视觉目标包——每张都必须是带真实 UI 的实机样张，不画无界面的概念海报。核心角色、关键场面与主界面各出约三张不同取向的样张，`director` 请用户挑定，`quick` 按标准自选并归档落选稿；后续量产资产在人物特征、色光、透视与 UI 留白上向选定样张看齐。没有生图工具时保留文字描述并如实记入风险，不谎称已出图。

动态媒体动工前先锁死不可走样的角色、场景与道具状态、起止衔接帧及跳过后的落点；需要自由视角或走位的交互，不用固定机位视频冒充。主角不出镜时镜头即主角视线。长文阅读的配乐以舒缓长音为主，易串味的曲风明确写入排除项。
