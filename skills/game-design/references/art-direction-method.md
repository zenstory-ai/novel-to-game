# 美术方向的改编判断

## 审美与成色

古装或时代题材分别锁定历史年代、绘制媒介与人物美化程度：「古风」不等于泛黄做旧，「现代审美」不等于换穿现代服装；调整画风时只改被点出的那个维度，不动原著的时代风貌与人物身份特征。同一人物、器物与地标在不同状态和机位下识别特征一致。

除 `targetFinish: graybox` 外，成色以同品类主流商业作品的实机截图为标尺：随手截一张图，应当一眼像该品类的成熟游戏，而不是技术演示；标题、年龄确认这类门面页同样要有完整画面，不拿纯文字页充数。场景里的角色与地面共用镜头俯角、透视比例与主光方向——跑图小人、战斗单位与对话立绘共享人物设定，但按各自机位分别出图，俯视地图不拿平视立绘缩小顶替。可行走地图把道路、建筑与地貌画进连续的绘景，不把独立物件贴在单色底板上。

## 可读

色光、材质、动效与声音只反映规则已裁决的状态，不暗示没实现的机制，也不向玩家或剧中人提前泄露尚未获知的秘密。常驻界面只留当前操作、决策依据与即时结果，细则按需展开；图标用轮廓清楚的图形或人物小像配短名，不拿单个文字字符（汉字、字母、假名）或 Emoji 顶替；界面不靠滚动查看内容（藏起滚动条照样能滚也不算），超出一屏就分页或改成格子加侧栏说明；要求下一回合应对的预警持续醒目，直到玩家应对完；以阅读为主的作品守住文学质感，精简界面不等于砍掉剧情与核心规则。

## 视觉目标包与媒体

仅在视觉方向存在高风险分歧或 `targetFinish` 要求高完成度时制作视觉目标包：它是带真实 UI 的游戏画面，不是概念海报。核心角色、关键时刻与主界面各出约三张不同取向的候选，`director` 请用户挑定，`quick` 按标准自选并隔离落选稿；后续资产在人物特征、色光、透视与 UI 留白上与目标图对齐。没有生图工具时保留文字方向并如实记录风险，不谎称已生成。

动态媒体要预先锁定不可走样的角色、场景与道具状态、起止衔接帧与跳过后的落点；需要自由视角或走位的交互，不用固定机位视频冒充。主角不出镜时镜头即主角视线。长文阅读的配乐以舒缓长音为主，容易混淆的曲风写明排除项。
