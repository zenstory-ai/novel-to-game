# 互动影游的交互设计

适用于「读剧情 → 做抉择 → 播放短片演绎当场后果 → 定格在末帧继续对话」的互动影游；人物塑造、知情边界与分支规则同见 [narrative-design-method.md](narrative-design-method.md)。

## 过场跟着选择走

- **每段过场都是一场小戏**：演玩家刚做的选择激起的当场反应——第一反应 → 一个承转动作（起身离席、递交信物、摔碗、合扇）→ 定格在人物神情或关键器物上，稳稳接住随后几句台词。背景落花、立绘眨眼、纱帘微晃属于待机氛围，不算过场，也不占影像预算。
- **按关键选择点核算，不按场次均摊**：先挑出后文会重提或追认的关键选择（留下回响、改变路线或决定结局），这些节点的每个选项各配一段过场，每个结局也各配一段；后文不再提起的家常寒暄用文字加立绘差分即可。影像预算 ≈（配过场的选择点数 × 各点选项数 + 结局数）× 单段时长（6～12 秒、2～4 个镜头）。预算吃紧时减少配过场的选择点数量，不在同一个选择点里只给部分选项配短片，也不砍故事分支。
- **先定稿再生成**：台词必须在批量生成视频前锁死。片中人物张不张口，看所用模型能否对准口型并稳住同一角色的音色：对得准，就把简短台词放在镜头开头；对不准，画面只靠神情和动作演戏，台词全走字幕。
- **降级不丢剧情**：读档、快进、关闭动态影像或视频加载失败时，自动切为末帧静画配点击翻页，分支、台词与结局一句不少。

## 五种互动手法

| 手法 | 适合放在 | 不适合 | 设计与无障碍要点 |
|---|---|---|---|
| 限时抉择 | 当众对峙、旁人逼你当场表态的紧迫场面 | 私下交心、重大路线分岔，以及任何涉及个人意愿或亲密边界的选择（绝不设倒计时，也不默认代选） | 超时进入专门写好的「不作声」分支并配专属过场，后果按在场各人的盘算分别记账，不全员一刀切扣好感；开菜单、藏对话框或切后台时暂停计时，快进与自动播放在限时处停下；设置中可关闭限时，将「不作声」并入常规选项 |
| 察言观色（画面热区） | 屋里某件物证决定接下来能拿什么话开口的场面 | 为凑点击硬塞进画面的无关摆设 | 可点细节多于允许查看的次数；热区只白描器物外观或人物小动作，不替玩家下判断；点中关键物证解锁带专属过场与后文回响的新选项；支持键盘切焦点，热区随底图坐标换算，不按屏幕像素写死 |
| 身体动作（按住、连点、划动） | 紧扣作品母题、值得玩家亲手做一次的标志性动作 | 靠手速判死刑，或拿机械 QTE 顶替人物抉择 | 成与败都能往下走，各有专属过场与后文回响；从首次按下起算计时，设置里提供一键辅助 |
| 人物记挂提示（如「她记下了」） | 后文会重提并引发连锁反应的关键选择 | 逢选必弹、毫无后文的普通对话 | 与后文实际回调的记录严格一致；只点明谁记在心里、是领情还是心冷，不露数字；待过场播完再浮现 |
| 剧情树回溯 | 多结局、鼓励多周目探索的作品 | 单线到底的短篇 | 每章开头落一个回溯节点，可随时跳回重选；鉴赏室收录已解锁的过场 |

`GAME_DESIGN.md` 须写明：哪些选择点配过场、各选项与结局的过场内容及分镜（对应选项、镜头起止秒数、对应字幕、末帧落点）、五种手法各用在哪场戏及理由、每个沉默分支与热区解锁选项的后续走向、身体动作成败两端的后果，以及明确禁设倒计时的场面。
