# 互动影游的交互设计

核心体验是「读一段剧情 → 做出抉择 → 看一段演出该抉择后果的短片 → 在末帧上接着读」时使用；人物、知情边界与分支遵循 [narrative-design-method.md](narrative-design-method.md)。

## 过场跟着选择走

- **每段过场是一场小戏**：演玩家刚做的那个选择引发的当场反应——第一反应 → 一个承转动作（起身离席、递交信物、摔碗、合扇）→ 定格在人物神情或关键器物上，托住随后几句台词。背景飘花、立绘眨眼、纱帘微晃只是待机氛围，不算过场，也不占影像预算。
- **按选择点核算，不按场次均摊**：先列出后文会重提或追认的关键选择（留下回响、改变路线或决定结局），这些选择点的每个选项各配一段过场，每个结局也各配一段；后文不再提起的家常寒暄用文字和立绘差分呈现。影像预算 ≈（配过场的选择点数 × 各点选项数 + 结局数）× 单段时长（6～12 秒、2～4 个镜头）。预算吃紧时减少配过场的选择点，不在同一个选择点里只给部分选项配过场，也不砍故事分支。
- **先定稿再生成**：台词在批量生成视频前定稿。人物是否在片中开口，取决于生成模型能否对准口型并保持同一角色音色：能，则台词短促并放在镜头起首；不能，则画面只靠神情与动作演戏，台词走字幕。
- **降级不丢内容**：读档、快进、关闭动态影像或加载失败时，改用末帧定格配点击翻页，任何分支、台词与结局都不因此丢失。

## 五种互动手法

| 手法 | 适合放在 | 不适合 | 设计与无障碍要点 |
|---|---|---|---|
| 限时抉择 | 当众对峙、有人逼你立刻表态的场面 | 私下交心、路线重大抉择，以及任何涉及个人意愿或亲密边界的选择（永远不设倒计时，也不默认代选） | 归零触发专门写好的「不作声」分支并配专属过场，后果按在场各人的盘算分别落账，不粗暴全员扣好感；打开菜单、隐藏对话框或切后台时暂停，快进与自动播放遇限时停下；设置里可关闭限时，把「不作声」列为常规选项 |
| 察言观色（画面热区） | 屋里某件物证决定玩家接下来能拿什么话开口的场面 | 为凑点击塞进画面的无关摆设 | 可点细节多于允许查看的次数；热区只白描器物形态或人物小动作，不替玩家下结论；点中关键物证解锁带专属过场与后文回响的选项；支持键盘切换焦点，热区随底图坐标换算，不按屏幕像素写死 |
| 身体动作（按住、连点、划动） | 紧扣作品母题、值得亲手做一次的标志性动作 | 靠手速判死刑，或拿机械 QTE 代替人物抉择 | 成功与失手都能继续，各有过场与后续回响；计时从首次按下起算，设置里提供一键辅助 |
| 人物记挂提示（如「她记下了」） | 后文会重提并引发连锁反应的关键选择 | 逢选必弹、没有后续影响的普通对话 | 必须与后文真正重提的记录一致；只点明谁记下了、领情还是心冷，不显示分值；在过场播完后浮现 |
| 剧情树回溯 | 多结局、鼓励多周目的作品 | 单线到底的短篇 | 每章开篇记录回溯节点，可随时跳回重选；鉴赏室收录看过的过场 |

`GAME_DESIGN.md` 写明：哪些选择点配过场、每个选项与结局的过场内容及其分镜（对应选项、镜头起止秒数、配哪句字幕、末帧落点）、各手法用在哪一场及理由、每个沉默分支与热区解锁选项的后续走向、身体动作成败的两种结果，以及明确不设倒计时的场面。
