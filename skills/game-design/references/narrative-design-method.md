# 互动叙事的改编边界

场景调度、人物对白、信息差或关键抉择作为核心体验时使用。行文沿用原著的语体、称谓、人物声口与文化概念，不把本地化写成异文化套路。

## 场景与人物

只记会影响玩法与实现的场景因果：在场人物的盘算与筹码、玩家可介入的节点、知情边界、离场时的状态变化与对后续场次的回响；不给每场戏硬套统一字段模板、固定节拍或台词字数。对白和选项是当前角色按身份、处境与已知信息真正会说、会做的事，不把作者的事后评判或结局剧透写进选项。可以合并或压缩场次，但不能为赶剧情让人物做出违背自身动机与筹码的决定。

## 知情与证据

秘密、证词和误判按「客观真相、人物已知或误信、玩家已获知」三层记。每件证据区分具体证物或字据、它直接证实的最小结论，以及仍待查明的推论。新线索可以推翻对旧证据的解读，但不能改写已经发生的事实；任何角色只按自己实际知道的信息行事。保密边界同样管住物品名称与描述、章节标题、头衔标牌与同场站位，不能只管对白。

原著里的重生、预知、系统面板或神通，严格沿用已确立的触发规则、知情范围与代价，不在角色遇困时临时扩权。

## 选择后果与分支汇流

关键选择记录玩家的实际言行、当场人物反应、留下的既成事实及后文呼应处，不用一个隐藏好感总分代替具体的恩怨。个人线的关键抉择紧扣该角色自己的心结与盘算，不写成对谁都管用的讨好话；亲疏变化优先用神态、称呼改口、允许出入的场所与愿意托付的私事体现，少靠数值加减交代。

分支可以在公共场景汇流，但汇流后的台词、持有器物、人物关系与可选动作必须匹配玩家走过的路径，不把未选分支的事当成既成事实；汇流处逐一核对关键物件在谁手里、各人何时到场离场。只保留后文真正会用到的状态标记；承诺、证词、器物去向和公开表态都要在当事人或后续决策里得到回应。交付前沿代表性路径正反走读：无人未卜先知，无未选分支串线，结局能追溯到玩家先前的具体选择。
