# 需求确认：先给推荐，再处理高风险分歧

## 默认动作

1. 速读原著，摸清作品语言、题材、情绪基调、时代设定和内容尺度，结合用户意图直接给出完整推荐方案，不连抛空泛问题。
2. 仅当目标平台、核心玩法、核心代入感、成人内容、真实人物、版权归属、资产授权、付费服务或高成本制作投入存在重大分岔时，才停下来请用户拍板。
3. 其余未定事项写入 `PRODUCT_BRIEF.md` 的「未确认假设」（注明推荐依据与影响范围，后续若需调整须先回改 `PRODUCT_BRIEF.md`）；待用户裁决的阻断项全部清零后，再进入原著拆解。

## 产品框架

| 维度 | 最小锁定内容 |
|---|---|
| 平台与运行时 | 交付物、生产引擎、目标运行环境与当前可用测试环境、目标与最低显示模式、输入方式、性能预算 |
| 市场、语言与受众 | 目标发行市场、首发界面语言、核心/轻度受众定位、主要游玩动机与信息密度 |
| 类型与先例 | 已锁定玩法或待比较方向、玩法对标先例（写明借用的核心动作与循环）、候选玩家动作、空间形态 |
| 体验重心 | `experienceProfile`：`system-led` / `narrative-led` / `hybrid` |
| 美术与完成度 | 画风、`targetFinish`、视觉参考维度（构图/色光/材质，禁搬用他作角色、界面或未授权资产） |
| 内容尺度 | 年龄分级、成人内容范围与平台审核约束（严禁涉及真实人物或对未成年角色作性化处理） |
| 核心代入感 | 玩家扮演谁、追求什么、在什么时刻获得什么情绪体验 |
| 时长与预算 | 首个可玩版本时长、章节/单局结构、单人/多人当前版本实现范围、影响玩法的发行定位（买断/免费或 `N/A`），以及本次可用的模型额度、工时或费用上限（未指定时按当前可用资源估算并记入未确认假设） |

`PRODUCT_BRIEF.md` 简明锁定上述维度、明确非目标、未确认假设与待决阻断项；不适用的维度填 `N/A` 表示明确不做，后续阶段不得自行补回默认值。
