# 对标基准参考：市场 × 题材 × 平台 × 画风

> 用途：需求 intake 阶段，给用户提**有信息量的推荐默认值**（对标名作 / 平台 / 画风 / 单局结构）。所有条目都是**挑选时的参考**，最终由用户确定。
>
> **这张表凭通用知识整理，不是已核实的定论。** 真要把某几款拿去当默认或写进交接，先用 WebSearch 联网核实其机制、平台与现况（较新或小众作品尤其容易记错或过时）；联网不可用时标注「凭记忆·未核实」。

> **先决定走哪条路，再看表。** 下面第 1 节按题材簇给的多是放置、抽卡、SLG、换装这类
> **系统主导**打法。原著最值得保留的是人物、关系、悬念、证词或道德困境时，**直接跳到
> 第 1.5 节**的互动叙事路线，不必先读完系统主导那几张表——两条路标准相同，只是先例名单
> 和判据说法不同。

## 0. 硬规则：小说语言 → 对标市场

**先按原著语言锁定对标市场，再在该市场里找玩家真正熟悉的爆款。**

| 原著语言 | 对标市场 | 找谁 |
|---|---|---|
| 中文 | 中国大陆 | 国内爆款（原神/一念逍遥/率土/羊了个羊…） |
| 英文 | 西方（欧美） | Steam/主机叙事向（BG3/Disco Elysium/Hades…） |
| 日文 | 日本二次元 | galgame/收集 gacha/JRPG（Fate/蔚蓝档案/P5…） |
| 韩文 | 韩国 | webtoon 改编/即时通讯乙女/工业化放置 RPG（Mystic Messenger/第七史诗…） |

- **对标分两层，别混用。** 核心玩法循环必须与**至少 2 款**对标**同玩法**——核心动词与循环结构就是它们那一套，不是「借了它一条」；画风、商业模式、UI 惯例这类才可以只借一条原则。每款标注「借用层级」（同玩法 / 仅原则）并写清借的是什么，名字只是索引。
- **目标市场 ≠ 研发地**：不少「最像日系」的爆款其实是韩厂做的（蔚蓝档案=Nexon，NIKKE=Shift Up）。做日韩题材时，题材面向谁（日本宅）与工业打法借谁（韩系）要分开看。

## 1.5 互动叙事 / 文字冒险：跨题材的第二条路

上面的主表按题材簇给出的多是放置、抽卡、SLG、换装这类**系统主导**打法。它们不是唯一
合法解：**互动叙事是有几十年发行史、动词集明确、先例充足的成熟品类**，对以人物、关系、
悬念和道德困境见长的原著往往是更贴的落点。

选它不等于放松标准——它同样要满足 ≥2 款同玩法先例、可验证的"玩过的人很多"凭据、三段弧
和能动性合同。**唯一变的是判据的说法，不是强度。**

共有核心动词：**读局面 → 追问 / 调查 → 比对证词与证据 → 表态或行动 → 承受回响**。
循环结构：连续场景推进，少数关键节点不可兼得，隐藏状态在后续场景被回读。

> **未能核实、不要拿来当凭据**：80 Days 的销量／下载量（inkle 未公开）、Fallen London 的
> 注册或活跃用户数、《文字游戏》与《飞越13号房》的销量。这几款可以作「仅原则」引用，
> 不能充当同玩法先例的"玩过的人很多"凭据。Disco Elysium、Pentiment、Obra Dinn、
> Zero Escape、The Wolf Among Us 目前只查得到第三方估算站数字，非官方口径，引用时标注
> 「第三方估算」。

配套的结构与平台提示：

- **结构语法先选再写**，概念阶段会要求说明理由：**主干加瓶颈**（分支定期在共同事件汇流，
  需要状态记忆，内容量可控）、**任务簇**（按地点组织的小节点簇，簇内多解，适合调查探索）、
  **长廊**（一条主干，岔路很快死亡或汇回）、**分院帽**（前段分支后分配到一条基本线性的后半段）、
  **树洞**（大量分支不汇流，多数玩家看不到多数内容）。小说改编默认从「主干加瓶颈」起步，
  以调查、取证、推理为主体时优先考虑「任务簇」。
- **平台**：Steam 与移动买断是叙事向主场；小程序**不适合**长文本互动小说（碎片时长装不下
  阅读），这条在主表第 2 节已写明，选叙事主导时尤其要认。
- **画风**：立绘＋背景（galgame 式）成本最低且辨识度靠角色设计；实拍影像（隐形守护者式）
  与单色低保真（Obra Dinn 式）都是已被验证的低成本高辨识路线。
- **中文市场的结构性机会**：国产 Galgame／文字冒险的公认短板是剧本，工作室多靠美术和玩法
  差异化。**一部有完整剧情和人物的原著正好补在这条短板上**，这是选叙事主导时真实存在的
  市场理由，写进市场区隔那一栏。
- **中文玩家的满足点**排序是代入感 → 剧情反转 → 主题内核，排在制作精度之前；这决定了
  资源投入该先给场景连续性和人物，而不是先给面板与数值。

| 画风 | 一句话 | 代表作 |
|---|---|---|
| **像素** | 成本低–中（高质量像素动画其实不便宜），辨识度中（易同质，靠色彩/题材突围），全平台尤网页/小程序/独立PC | Dead Cells、星露谷 |

| **2.5D**(2D伪3D/正交/横版景深) | 成本中，辨识度中–高，网页/App/PC/主机通吃 | 极乐迪斯科、奥日、明日方舟 |
| **卡通渲染3D**(二次元PBR) | 成本高，辨识度高（二次元标配），App/PC/主机，小程序吃力 | 原神、崩坏3 |
| **写实3D** | 成本很高（建模/动捕/光照），辨识度靠制作规格，PC/主机/高端App，**仅史诗/准3A体量才用** | 黑神话悟空、艾尔登法环 |

## 4. intake 收尾提醒

- 先按语言定市场 → 按目标平台锁画风与单局结构 → 在题材簇里取 2–4 个对标。
- **主表不是唯一解**：原著价值主要在人物、关系、悬念、证词或道德困境时，第 1.5 节的
  互动叙事路线往往比放置／抽卡更贴，且先例同样充足。给推荐时把两条路都摆出来，说明
  各自取什么、弃什么，让用户在有信息的情况下选，**不要默认只报系统主导的那一条**。
- **对标必须标注借用层级**：同玩法项要说得出共有的核心动词与循环结构，仅原则项说清借的是哪条画风 / 商业 / UI 原则。给默认值时把关系说出来（例：「一念逍遥式=小程序放置+长线数值买量，同玩法」而非只报「一念逍遥」）。**至少 2 款同玩法**，凑不满就换一个有先例的打法。
- 缺强标杆的题材（系统流、无限流、webtoon复仇/回归、异世界轻改）：**缺的是题材标杆，不是自创玩法的许可**。玩法一律落到有同玩法先例的打法——给「放置买量 / roguelite / 养成逆袭 / 章节 AVG」等可落地路径**二选一与用户确认**，题材只做 IP 皮；不得以「暂无公认标杆」为由把自创循环推进概念阶段。
