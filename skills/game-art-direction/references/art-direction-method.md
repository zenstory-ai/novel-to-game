# 美术方向的改编判断

## 审美校准与品类成色

古装或时代题材需分别锁定历史年代、绘制媒介与人物美化程度：「古风」不等于泛黄做旧，「现代审美」也不等于换穿现代服装；调整画风时只改动被点出的维度，不得篡改原著的时代风貌与人物身份特征。同一人物、器物与地标在不同状态和机位下的标志性特征必须一致。

场景中的角色与地面须采用统一的镜头俯角、透视比例和主光方向（跑图小人、战斗单位与对话立绘共享人物设定但按各自机位分别出图），通过脚底站立点、接触阴影与前后遮挡校验角色稳踩地面，俯视地图绝不直接拿平视立绘缩小顶替。除 `targetFinish: graybox` 外，画面成色一律以同品类主流商业作品的实机截图为标尺：随手截一张图，应当一眼像该品类的成熟游戏，而不像粗糙的技术演示；3D 画面优先打磨光照层次（主光、天光、环境光遮蔽、雾效）与材质地表分层，而非单纯堆砌模型面数。可行走地图应将道路、桥梁、建筑与地貌融进连续绘景（避免把独立物件生硬贴在单色底板上；若单独生成的物件贴地像剪纸，先生成完整场景目标图校准街巷肌理与物件穿插关系），保持合理的人体与建筑门窗比例并对齐底层碰撞边界；地图清晰度取决于底图源文件像素分辨率与屏幕实际显示尺寸之比（计入设备像素比 DPR，底图模糊时单拉高 Canvas 分辨率无济于事）。扩充画幅时重新规划分区与疏密节奏，分块生成大图时先锁死全图总布局、跨块道路衔接点、比例与受光方向并预留融合重叠区。

## 功能与可读边界

色光、材质、动效和声音必须如实反映规则引擎已裁决的状态，不暗示未实现的机制，也不向玩家或剧中人物提前泄露尚未获知的秘密。在目标视口、暗色场景、减弱动态和静音状态下，当前可执行操作、判断依据、局势压力与结算结果均须清晰可辨，不得靠缩小字号或隐藏按钮掩盖排版缺陷。

功能入口、物品与状态图标须绘制轮廓鲜明的实心图形并配简短名称，不拿单字、Emoji 或通用花纹顶替，也不把图标内已有的文字在相邻标签里重复抄写。包含多个功能面板时，统一弹窗外壳（标题栏、关闭按钮、滚动区、卡片与高亮样式）并覆盖小图标、空槽位与二级弹窗，密集的角色养成数据按队伍成员与操作层级分块排布；手机窄屏重排时完整保留全部导航入口。常驻主界面只保留当前操作、决策依据与即时结果，详细规则按需展开（以文字阅读为主的作品则要守住文学质感，精简界面废话不等于把精彩剧情和核心规则一刀切掉）；同一次动作的跳字、状态标记与战报分清主次、不重复刷屏，克制关系等关键提示用目标身上的局部图标加两三字短签直白标出；要求下一回合应对的蓄力或危机预警须持续醒目保持到玩家完成应对为止；对话框的角色名、正文与继续按钮留出独立空间以防滚动误触。

## 视觉目标包与媒体交接

仅在视觉方向存在高风险分歧或 `targetFinish` 要求高完成度时制作「视觉目标包」（展现带 UI 的真实游戏画面，附可见标准与反例，不拿概念海报充当实机参考）：每个核心角色、关键时刻和主界面先出约三张不同取向的候选图，`director` 模式请用户挑定、`quick` 模式按标准自动选定并立即隔离落选废稿；后续批量资产须在人物特征、色光、透视与 UI 留白上与目标图严格对齐（缺少生图工具时保留文字方向并如实记录风险，不谎称已生成）。

资产清单逐项记录用途、角色/场景识别特征、触发状态、版权边界与可降级资产的替代方案。动态媒体还需锁定不可走样的角色/场景/道具状态、起止衔接帧与跳过后的落点状态（需要自由改变视角或走位的交互严禁用固定机位视频伪装）。互动影游过场规定：直接拿已批准的角色立绘与纯背景空镜作为生成参考图锁死五官衣纹与陈设；主角不出镜时镜头即代表主角视线；先用代表片测试模型能否对准口型并保持同一角色音色，达标则让人物在片中开口念词，否则只保留环境声与动作音效、台词统一由底部字幕呈现；末帧停在人物神情或关键器物上承接后续定格台词（开启“减弱动态效果”时完全静止）；播放期间立绘退场、对话框收为底部窄字幕条，倒计时、热区与关系回响提示均采用不遮挡脸部与手部的轻量样式。音乐与音效同样登记用途、乐器、循环与缺音回落（长文阅读配乐以舒缓长音为主，易混淆曲风写明排除项）；语音方向只规定声口与语速，逐句合成交由构建阶段执行。
