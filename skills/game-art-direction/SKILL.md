# 游戏美术与创意方向

定义玩家在游戏里看见、听见和读懂的视听体验；至于资产用什么工具生产、采用哪个渲染库或调用哪家模型，留给构建阶段决定。

读取 [art-direction-method.md](references/art-direction-method.md)。输入必须包含 `GAME_DESIGN.md` 与 `PRODUCT_BRIEF.md`；视觉表现服务于玩法决策，不得为了迁就好看的参考图而改写玩法规则。

产物语言由 `PRODUCT_BRIEF.md` 锁定；未锁定时跟随对话语言，不默认产出中文。

直接继承目标平台、视口与屏幕朝向、画风、`targetFinish`、内容尺度与 `experienceProfile`。视觉参考只借鉴已声明的构图、材质、色光或信息层级，不得照搬其他作品的角色、地图、界面与美术资产。原著文化背景与目标发行市场分开考证，不用泛化的流行刻板符号替代原著自身的时代与文化气质。

## 设计

1. 确立能明确区分“符合本作”与“偏离本作”的核心视觉原则（校准方法见参考文档「身份与审美校准」）；
2. 为主角、目标点、威胁、奖励和场景地标建立清晰的镜头机位、视觉焦点、剪影轮廓、体型比例与画面疏密规则；
3. 让色彩、光影、材质和动效准确传达真实游戏状态，同时提供不依赖颜色辨识的图形提示、低动效替代方案与充足的明暗对比度；
4. 明确首屏视觉重心、HUD 信息层级、操作即时反馈、结果强弱分级、失败提示与结算画面；
5. 为场景环境、角色造型、可交互物和关键道具制定统一的视觉语言与各自的标志性识别特征；
6. 规定目标语言的字体覆盖、阅读视线顺序、单屏字数上限与文化符号使用边界；
7. 针对核心玩法循环或视觉风险最高的环节定义「关键游戏时刻」，写清当下玩家操作、局势压力、画面焦点及操作前后的画面变化；
8. 设定声音风格、功能音效层级和配乐边界；仅在确有独特体验价值时启用角色配音，且全程保证纯字幕与静音模式下可正常游玩。

`narrative-led` 或 `hybrid` 项目的叙事层还需说明：人物站位距离、朝向、前景遮挡与肢体姿态如何外化人物关系变化，以及对话框区域如何兼顾顺畅阅读、历史回看、跳过与快进。

不要在美术方向文档里写着色器代码、模型拓扑、贴图分辨率参数、API 接口、文件格式教程或供应商调用配置。

## 输出

生成 `design/ART_DIRECTION.md`，包含：

- `targetFinish` 与核心视觉原则；
- 镜头构图、世界/角色/道具视觉语言、服务玩法的色光与材质规则；
- HUD 布局、操作反馈、动效与转场、语言文化规范及声音方向；
- 关键游戏时刻；
- 必需资产与可降级资产清单、原创与授权边界，以及尚待验证的视觉风险。

是否额外产出 `design/VISUAL_TARGETS.md` 及少量目标样张，按参考文档「关键游戏时刻与目标图」的条件决定。

交付前在目标视口尺寸下核查：玩家操作、局势压力与状态反馈是否一眼可辨；关键游戏时刻是否在真实的带 UI 游戏画面中成立（不能拿概念宣传海报顶替）；美术规范是否完整覆盖核心循环、失败与结局，让构建阶段无需自行揣测画风或反馈形式，同时保有所需的工程实现自由。
