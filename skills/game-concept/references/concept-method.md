# 概念选择方法

## 先定义类型，再谈创意

“动作”“角色扮演”这类大标签不够。PRODUCT_BRIEF 已锁的维度（主类型、输入方式、单次时长、受众、市场与语言）直接继承，不在本阶段重定；
本阶段只定死它留空的：子类型、玩家视角与明确非类型。类型决定玩家用什么能力解决大多数问题；支持类型只能增强主循环，不能平分产品重心。

同一玩家幻想能用多种类型表达时，按**先例厚度**选类型——优先选玩家玩过最多、认得最快
的那一类，而不是规则最少的那一类。“少”只是切片的尺度手段，不是选型标准：可缩的是
体量、资产量、内容量、周期数与关卡数，**不可缩的是核心动词集与循环结构**——把一个
成熟品类削到只剩一条判断，得到的不是精简版，是没人认得的东西。

原作有大量战斗不等于必须做实时动作；市场上有大型对标也不等于把它整体缩成网页版——
缩的是范围，不是玩法骨架。维度同理：**该用三维就用三维**，判据是玩法要不要玩家操纵
空间与视角（走位、绕后、地形、镜头），不是“二维更省”。零构建不是二维的同义词，
Three.js 可以随库入仓照零构建纪律交付（见 game-build 的生产技法）；真正的取舍是
资产量与时间，不是维度本身。

## 对标拆解

对标按设计问题选择，不按题材相似选择：

| 问题 | 应寻找的证据 |
|---|---|
| 核心动作 | 哪款作品已让相似动作产生持续的选择和熟练度差异？ |
| 世界响应 | 哪款作品让工具或能力清楚改变环境、角色或路线？ |
| 关卡结构 | 哪款作品用相近时长教会、组合并检验核心机制？ |
| 市场区隔 | 玩家最可能拿它与什么比较，本作凭什么不是低配复刻？ |
| 文化理解 | 原作文化怎样表达题材，目标语言市场怎样理解同类题材和符号？ |

**先联网核实，再落笔**：动手拆对标前，对每款先做一轮 WebSearch，用商店页、开发者/发行商
说明、开发者演讲、可靠评测或玩法百科核实它到底怎么运作、在哪个平台、卖给谁、现在活得
如何；不要凭宣传标签推断具体机制，也不要用训练记忆代替查证。把「查证到的事实」和
「据此做出的推断」分开记，并在对标矩阵「核实状态」列标注（已核实·来源类型 / 凭记忆·
未核实）；联网不可用时如实标注「凭记忆·未核实」，不把记忆当结论。这条对较新、较小众
或近年数值/版本变动大的作品尤其重要。

## 硬否决

出现任一情况就重做，而不是靠评分补偿。**这些判据针对的是缺陷，不是承载媒介**——叙事主导
不因为"玩家在读字"被判死，系统主导也不因为"有数值"被豁免。只有**下面明确写出两种说法的
那几条**随 `experienceProfile` 换判据；其余各条对所有品类逐字同样成立，**不存在"叙事主导版
的换皮否决"这种东西，也不要现场发明一个**：

- **玩家读完一段只是让它继续**：判据是**这个方向能不能当场点出切片里两个具体场景，
  在那里换一个玩家选择会导致后面发生不同的事**——点不出两个（包括根本没有分歧点的
  "一直点下一页"），本条触发。写不出具体场景而只写"选择会有后果"这类断言，按点不出计。
  **注意：文本量大、以对白为主、没有实时操作，都不是本条的判据。**
- 没有可重复参与、压力、取舍或状态变化。**「参与手段」就是本作那 3–5 个核心动词**，
  不是另一套词：系统主导取走位、出招、分配、经营这类；叙事主导取追问、质证、表态、
  护住、交出这类。两者都要能反复使用并产生熟练度差异；
- 原著中心的情感 / 伦理张力只能靠过场或旁白传达，核心循环与它无关；
- 换皮：删去小说专有名词后，不存在任何由原作规则或张力驱动的机制差异（如假扇越扇
  火旺、相克在 Boss 战反转）。沿用 `PRODUCT_BRIEF` 锁定的类型语法不算换皮，判定依据
  是概念卡「本作独有规则转换点」是否成立；
- 可玩原型依赖开放世界、多人服务或生产级资产量；
- 依赖复制其他游戏受保护的角色、地图、UI 或素材；
- **无先例**：核心动词与循环结构找不到 ≥2 款已发行且被大量玩家玩过的作品与它同构，
  或矩阵里列出的共有动词经核实并不成立。子类型窄到没有已发行作品占据它，与“动作”
  “角色扮演”这类大到不指向任何具体玩法的标签一样判不成立。题材缺公认标杆不是自创
  玩法的许可，文学契合度不构成豁免——换一个有先例的打法，题材照做 IP 皮。
  **互动叙事同样受这条约束、也同样满足得了这条**：它是有几十年发行史和明确动词集的
  成熟品类，先例见下节的名单，不得以“我们做的是纯剧情”为由跳过先例核实；
- **无弧线**：整个切片的可用参与手段与可达空间从头到尾不变，玩家在最后一拍能做的事
  与第一拍相同。计数器、等级与熟练度读数变大不算变化。叙事主导按同样强度判，只是
  差集换成：新的可问对象与可问话题、新的质证或施压手段、因先前行为而改变的人物态度、
  只有知情者才走得到的场景与结局。**纯粹多出一段文本、多一个不改变后续的对白选项，
  与“数字变大”同样不算差集**；
- **能动性造假**：玩家的介入被兑现成一个花资源的界面——他在分诊已经写好的结果，
  而不是让事情因他而不同（判据见下节两项权利）。

## 玩家能动性合同：两项权利

"玩家有没有能动性"不能靠有没有交互控件判断。用两项权利判，两项都要成立：

- **因果权**：玩家的选择决定后续事件**为什么**发生、朝哪个方向转。事件只是被玩家的
  操作放行，或选什么都汇入同一条因果，即不成立。
- **结算权**：结果**看得出是他的**——世界点名他做过的事，代价落在他在乎的东西上。
  结算只出现在一个总分或一段旁白总结里，即不成立。

这道门专治一个具体滑坡：**"给玩家能动性"被廉价兑现成"给玩家一个花资源的界面"。**
资源面板是最容易做出、也最容易被验收为"可交互"的东西，所以概念阶段会默认滑向它。
卡牌、回合、资源条本身不是缺陷；缺陷是它们**替代**了这两项权利。每个方向都要用一句话
回答：玩家做了什么，使这件事只能这样发展，而且看得出是他做的。

## 三档 experienceProfile 怎么判

按**玩家大部分时间在做什么**判，不按屏幕上有没有数字判：

- **`system-led`**：玩家主要在操作规则——走位、出招、分配资源、经营、建造。剧情通过
  场景、过场和文本承载，但玩家的熟练度长在规则上。
- **`narrative-led`**：玩家主要在读局面、追问、比对证词、表态和承担回响。可以有量表，
  但它们**不构成玩家的主要判断对象**——拿掉面板，玩家仍然知道自己在干什么、下一步该
  争取什么。
- **`hybrid`**：两层**各自都能通过自己那套完成检查**——系统层拿得出数值预算表与决策
  深度示例，叙事层拿得出场景脊柱、知识表与延迟回响，且两层之间有已声明的双向影响
  （系统状态改变可用的说法，剧情事实改变可用的规则）。

`hybrid` 是**更高要求，不是折中挡**。判不清时的两条测试：

1. **拿掉测试**：删掉资源层，剩下的还是不是一个完整体验？删掉场景与对白层呢？两边都
   塌，才是 `hybrid`；只有一边塌，就按没塌的那边记档。
2. **能动性测试**：如果资源层拿不出因果权与结算权——玩家花资源只是放行已经写好的剧情——
   那它不是"系统层"，是伪装成玩法的面板。这时不记 `hybrid`，记 `narrative-led` 并按
   「能动性造假」把那层资源界面删掉或补成真的系统。多数把小说做成卡牌的失败案例正是
   在这里被记错档：有面板不等于有系统层。

记档只影响判据说法与读哪几份方法文件，**不影响标准强度**。

## 互动叙事这条线

互动叙事的共有核心动词是**读局面 → 追问 / 调查 → 比对证词与证据 → 表态或行动 → 承受回响**，
循环结构是连续场景推进、少数关键节点不可兼得、隐藏状态在后续场景被回读。可用作同玩法先例
的已核实条目（**引用前仍须自己联网复核一遍**，本表只是起点，不替代上一节的核实义务）：

| 先例 | 「玩过的人很多」凭据（来源与日期） |
|---|---|
| 《隐形守护者》 | 2019 年约 140 万份，当年国产单机销量第一（国游销量吧 2019 年度榜，2020-01） |
| 《山河旅探》 | 2024 年约 55 万份 / 约 ¥2800 万，国产年度第四（2024 年度国产销量榜，2025-01） |
| 逆转裁判系列 | 截至 2023-03-31 全球累计 1000 万份（Capcom 官方 Platinum Titles） |
| Her Story | 上市约一个月 10 万份（作者 Sam Barlow 公开说明，2015-07） |
| Sunless Sea | 上市 31 天 54,210 份（Failbetter 官方销售复盘） |
| Slay the Princess | 全平台超 100 万份（开发方公布，2026-02） |
| Doki Doki Literature Club | 原作 1350 万次下载；Plus 付费版超 100 万份（发行方公布） |

**不可用作凭据**：80 Days（inkle 未公开销量）、Fallen London（未公开用户数）、《文字游戏》、
《飞越13号房》。Disco Elysium、Pentiment、Obra Dinn、Zero Escape、The Wolf Among Us 只有第三方
估算，引用时标「第三方估算」，不算已核实凭据。

叙事主导方向和其他方向受同一套约束，只是判据换成对应说法：

| 判据 | 系统主导 | 叙事主导 |
|---|---|---|
| 核心动词 | 走位、出招、经营、建造 | 追问、质证、比对证词、表态、护住、交出、隐瞒 |
| 熟练度差异 | 操作与资源判断 | 知道谁在说谎、知道该拿哪份证词压谁、知道什么该瞒 |
| 三段弧差集 | 新动词 / 新可达空间 | 新可问对象与话题、新质证手段、因先前行为改变的人物态度、只有知情者走得到的场景与结局 |
| 压力来源 | 资源稀缺、对手行动 | 时间窗口、知情者会先开口、说错话不可撤回、关系互斥 |
| 失败 | 战败、破产 | 信错人、被反将、关系不可逆破裂、错过唯一窗口 |

**结构选型先于文案。** 互动叙事有成熟的分支结构语法，选一个并说明为什么：

- **主干加瓶颈**（branch and bottleneck）：分支定期在共同事件处汇流；需要状态记忆，
  内容量可控——多数小说改编的默认解；
- **任务簇**（quest）：按地点而非时间组织的小节点簇，簇内多解、簇间少连；适合调查与探索；
- **长廊**（gauntlet）：一条主干，岔路很快死亡或汇回；状态负担最小，保证人人看到主线；
- **分院帽**（sorting hat）：前段密集分支后把玩家分配到一条基本线性的后半段；等于要写
  好几个后半程，按内容预算决定；
- **树洞**（time cave）：大量分支不汇流；不需要状态记忆，但多数玩家看不到多数内容。

**怎么选**：先看玩家主要在做什么，再看内容预算，不要直接取默认值。玩家主要在**调查、
取证、比对**（谁在说谎、证据指向谁）→ 任务簇；主要在**站队、维系或牺牲关系** → 主干
加瓶颈；只有一条命定主线、要保证人人看到 → 长廊；要做多周目、每周目换一个立场 →
分院帽；短小、以再玩一次为卖点 → 树洞。**主干加瓶颈是拿不准时的起步值，不是免于比较
的默认值**；选了它也要写清为什么不是任务簇。

组合爆炸是真的：三选一连做四层就是 81 个终点。**不设瓶颈时分支不要超过 2–3 层。**
按"节点数 × 变体数 × 关键人物数"估算内容量，并接受"写的大部分内容多数玩家看不到"。

**切片很短时三段弧怎么放**：10–15 分钟的切片同样要三段弧，但每期的结束标记应落在
**场景**上而不是章节上（例如"第一次有人对你说谎"→"你第一次拿证词压人"→"你用早先那份
证词逼出结局"）。放不下三期就缩窄切片范围——取更少的原著段落、更少的人物，而不是把
三期摊薄成同形的三段；**同形三段比两段更糟**，它谎称有弧线。

## 比较维度

1. **原作规则适配**：在先例的动词集之内，原作独特规则是否改变了这些动词的对象、代价
   或世界回应，而非只使用名词。换掉动词集不是适配，是另做一个没人认得的游戏。
2. **原作情感 enact**：核心循环（不是过场）是否让玩家亲身做出或回应原著招牌的情感 / 伦理
   张力，而不是把情绪 orphan 到旁白与 cutscene。
3. **玩家能动性**：玩家是否反复做有后果的决定并逐步掌握它。
4. **视觉传播**：一张实际游戏画面能否同时说明身份、动作和独特世界。
5. **文化适用**：核心幻想和表达在原作语境中是否准确，在目标市场是否无需错误类比就能读懂。
6. **完成风险**：最小原型能否用现有模型与资产证明最危险的承诺。

优先选择最小但能证明核心幻想的原型。相近方案不需要伪精确排序，直接说明关键
取舍和最大不确定性。推荐方案必须能回答：首个验证动作是什么、玩家如何失败、哪条
观察结果会让我们放弃这个方向。

若某方案卖点含多结局 / 多策略，命名"第二遍与第一遍可观察不同"的那一个内容并指向已有
证据（一个最小重玩钩子）；纯一次通关叙事不强求——这道钩子是逼出自觉声明，不是要求做成
必须复玩。
