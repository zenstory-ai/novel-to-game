# 概念选择方法

## 类型与先例

类型由玩家大部分时间用什么能力解决问题决定，不由原作表面上有多少战斗、恋爱或对白决定。范围可以
缩小，核心循环不能削到只剩一次判断或一个放行按钮。

先例按设计问题选择，不按题材相似选择。一个主要玩法先例应能说明核心动词、循环、压力与熟练度；
辅助先例只补主要先例回答不了的独立问题。记录借什么、明确不借什么和事实来源，不收集与当前决定
无关的销量或排名。

需要玩家操纵空间、视角或地形时使用实时空间；固定镜头和连续场景不必为了“更像游戏”强做三维。
平台与技术只是实现约束，不替代玩法判断。

## 硬否决

出现任一情况就重做，不靠评分补偿：

- 玩家读完或点完一段只让既定剧情继续，换选择不会改变后续原因、关系、路线或结果；
- 没有 3–5 个可重复参与手段，或这些动作不产生压力、取舍、状态变化与熟练度差异；
- 原作中心规则、情感或伦理张力只存在于过场和名词，核心循环与它无关；
- 删除专有名词后，本作与通用模板没有动作对象、代价或世界回应上的差异；
- 最小切片依赖开放世界、多人服务、生产级内容量或不可获得资产；
- 依赖复制其他游戏受保护的角色、地图、UI、文本或素材；
- 玩法无法用一个主要先例或清楚的循环说明，玩家也无法预判自己反复在做什么；
- 切片从头到尾只有数值或文本增加，没有新的参与手段、可达空间、可问对象或局面；
- 玩家介入被兑现成花资源放行既定结果，缺少因果权或结算权。

## 玩家能动性

- **因果权**：玩家的选择决定事情为什么发生、朝哪里转；选什么都汇入同一原因即不成立。
- **结算权**：世界会点名玩家做过的事，代价落在他在乎的对象上；只给总分或旁白总结不成立。

每个方向用一句话回答：“玩家做了什么，使这件事只能这样发展，而且结果怎样看得出是他造成的？”

## 身份专属命令

自然语言不是默认输入方式。只有当玩家需要以角色身份组织对象、执行人、条件、期限或知情范围，且措辞
差异本身值得保留时，才选择一项 `signature_command`；实时瞄准、移动、节奏操作或已有按钮已经完整表达
核心动词时写 `N/A`。不开放通用“你想做什么”，也不把每个 NPC 都变成聊天入口。

五项字段组成一条因果链：`player_job → recurring_job_loop → signature_command → resistance_chain →
advancement_ladder`。`signature_command` 选中时只先锁 `id`、玩家可见 `label` 和候选 `intents`；具体
槽位、验证器与提交项由世界设计裁决。意图数量服从最小切片，不设跨项目固定数；玩家表达先编译成
有限候选动作，世界仍可拒绝、部分执行、走样、泄露或延期追责。若自由表达最后只等价于按一个现成
按钮，且没有增加身份感、组合空间或可读后果，就不采用。

## 体验承载类型

- `system-led`：玩家主要操作规则，熟练度来自走位、出招、分配、经营或建造。
- `narrative-led`：玩家主要读局面、追问、比对信息、表态并承担回响；拿掉数值面板仍知道该争取什么。
- `hybrid`：两层各自成立且双向影响；一层只是为另一层放行时，按真正承载体验的那层记录。

用“拿掉测试”判断：删掉系统层或场景/对白层，哪一边会让体验失去主要决策？两边都塌且彼此读写，
才是 `hybrid`。

## 互动叙事结构

互动叙事的可重复循环可以是：读局面 → 追问/调查 → 比对证词与证据 → 表态或行动 → 承受回响。
熟练度来自知道谁掌握什么、何时施压、什么必须隐瞒，以及先前行为怎样改变当前局面。

按内容预算选择结构：

| 结构 | 适用情况 | 主要成本 |
|---|---|---|
| 主干加瓶颈 | 关系与立场变化需要记忆，但关键事件可汇流 | 状态变体 |
| 任务簇 | 调查、取证、地点顺序可交换 | 节点组合 |
| 长廊 | 命定主线必须被所有玩家看到 | 分支较浅 |
| 分院帽 | 前段选择分配到不同后半程 | 多套后半程 |
| 树洞 | 短小、多周目、分支很少汇流 | 大量内容不可见 |

不设汇流时分支不要连续膨胀；用“节点数 × 状态变体 × 关键人物数”估算内容，而不是画一棵无限树。

## 三段弧

三段弧要求玩家能力或局面发生质变：

- 探索期：认识可用动作、对象和第一层风险；
- 成长期：组合动作、读取先前状态，获得新手没有的选择；
- 成熟期：在较少提示下利用早先积累，完成代表性结果。

系统主导看新动词与新可达空间；叙事主导看新可问对象、质证手段、人物态度和只有知情者可达的场景。
数字变大、多一段文本或无后果选项都不算弧线。

## 比较维度

1. 原作规则是否改变动作对象、顺序、代价或世界回应；
2. 玩家是否亲手 enact 原作的情感或伦理张力；
3. 玩家能动性是否在切片内被世界回读；
4. 一张实际画面能否说明身份、动作和独特世界；
5. 表达是否尊重原作文化，并适合目标界面语言与受众；
6. 最小原型能否用现有时间、工具与资产证明最大风险。

相近方案不做伪精确排序。选择能以最小切片证明核心幻想、且失败条件最清楚的方向。
