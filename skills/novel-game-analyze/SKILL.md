# 小说游戏化拆解

把整本小说讲了什么故事、哪几场戏最抓人、人物怎么较劲、世界按什么规矩运转拆清楚，并附可核查的原文出处，供下游选切片、定玩法、做美术。只记原著事实：不写文学读后感，不提前敲定游戏品类，不混入下游才发明的数值、界面或代码结构。

行文用平实白描讲清因果、算盘与张力；不用「运行模型」「状态向量」之类的系统黑话，不写「气氛紧张」式的空评语，也不把结局倒推成人物早有预谋。

产物语言由 `PRODUCT_BRIEF.md` 锁定；未锁定时跟随对话语言，不默认产出中文。引用保留原文；文档或界面语言与原文不同时，只翻译影响决策的内容，并维护一张人名、地名、器物与规则的统一术语表。礼制、称谓、宗教与叙事传统保留原有文化内涵，不替换成异域奇幻或现代类型标签。

## 输入

- 工作区已有覆盖**全书**的拆文成果或写作工程时，直接沿用其中的事实与出处，只对缺口定点回查原文；只覆盖开头或局部的资料不能当作读完全书（用户明确限定只改编某一卷或某几章时除外）。
- 从原始文本拆解时，先确认编码可读、剔除与正文重复的目录、核对章回连续无漏。长篇按连续章回分批精读，同一批只读一次，进度记入 `analysis/_coverage.md` 以便续跑与查漏；互不重叠的批次可以小规模并行，每轮收齐后先核对统一人物称呼与未完事件再开下一轮；每批除本段事实外，顺手记下跨批才接得上的线索：同人异名、未收尾的目标、待揭晓的伏笔、秘密借什么信物、字据或口信传开以及谁在场。全书读完再收束成文。
- 已有 `PRODUCT_BRIEF.md` 时，按它的内容尺度与已锁定方向排取证重点；锁定方向需要而原著没有成体系描写的部分，标「原著无现成设定，属下游设计新增」。情爱、暴力、权谋等冲突按文本事实提取因果，并对照分级标出下游需谨慎改编的尺度。

## 输出：`analysis/SOURCE_BIBLE.md`

原文直陈的附章回位置与短定位词，由多处细节合推的写「据第 X、Y 章细节推断」，查无出处的标「原文未明确」。优先用表格，共六节：

1. **来源与全书覆盖**：底本版本、授权或洁本说明、总章数与覆盖情况。先用几句话点明全书的驱动力与根本矛盾，再按作品自身的结构（原书卷部、境界、对手、案件或关系演进）切出覆盖全书连续章回的主线阶段，每段写清谁想做什么 → 卡在哪 → 靠什么破局 → 得失与对后续的约束。
2. **高光桥段**：冲突最集中、反转最妙、读者追读期待最强的大戏，每场 `章回 | 起因与赌注 | 博弈与反转 | 结果代价 | 改编价值`。包含多步试探、博弈或取舍的标为可玩切片候选；纯命运揭晓或只成立一次的爆发标为单次演出，提醒下游不要拆成重复刷取的循环。
3. **人物与关系**：核心人物的身份名分、由言行归纳的性格、想要什么、软肋、筹码、翻脸或让步的条件与结局；涉及名分、座次或固定队伍的作品附名册表 `姓名 | 身份/次序 | 结局 | 证据位置`；关系按方向与变化记录（甲 → 乙：表面态度与真实算盘，第 X 章因何事改变）。只合并有原文同指依据的称呼，拿不准是否同一人就分开记。玩家身份未锁定时，记下不同切入视角各自够得着的行动空间。
4. **秘密与信息差**（原著靠悬念、隐瞒、冒充或证词推进时必填，直白推进的作品从略）：同一真相只建一条记录，对照客观发生时间与正文披露路径，写清读者和关键角色各自何时知情或误信。
5. **世界规矩与场景风物**：力量、器物或礼法的触发条件、代价、克制与反例，标出首次确立、关键反例与最终回收的章回——只在开篇成立的现象、人物的吹嘘与谎言都不算全书铁律；人物遇阻时反复使用的破局手段；主要场景的出入口、门槛与动线；原著写明的形制、材质、服饰、天气与声响。
6. **改编红线与留白**：`条目 | 边界类型 | 证据位置`，边界类型取 `immutable`（原著铁律）、`adaptable`（可压缩调适）、`open`（原著留白，允许原创）或 `conflicted`（原文前后矛盾或版本异文）；单独列出影视、戏曲、同人里常见而本书未载的设定误区；跨语言或含古语行话时附术语表。

下游选定方向后，只在所依赖的事实缺出处或前后出入时，按章回定点回查并增补，不重扫全书。
