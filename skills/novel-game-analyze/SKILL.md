# 小说游戏化拆解

通读原著，拆清全书讲了什么故事、哪几场戏最抓人、人物之间怎么较劲、世界按什么规矩运转，并附上可核查的原文出处，供下游选切片、定玩法、做美术。只记原著事实：不写文学读后感，不提前锁死游戏品类，也不塞入下游才设计的数值、界面或代码结构。

行文用平实白描交代前因后果、人物盘算与冲突张力；不套「运行模型」「状态向量」这类工程黑话，不写「气氛紧张」式的空泛评语，也不把最终结局倒推成角色早有预谋。

产物语言由 `PRODUCT_BRIEF.md` 锁定；未锁定时跟随对话语言，不默认产出中文。引用保留原文；文档或界面语言与原文不同时，只翻译影响改编决策的内容，并维护一张人名、地名、器物与规则的统一术语表。礼制、称谓、宗教与叙事传统保留原书文化语境，不硬套异域套路或现代类型标签。

## 输入

- 工作区已有覆盖**全书**的拆文库或写作工程时，直接沿用其中的事实与出处，只对缺漏处回查原文；仅覆盖开篇或局部的资料不能当成已读完全书（用户明确限定只改某一卷或某几章时除外）。
- 从原始文本拆书时，先确认编码正常可读、剔除与正文重复的目录、核对章回连续无缺漏。长篇按连续章回分批精读，同一批只读一遍，进度记入 `analysis/_coverage.md` 便于续跑与查漏；互不重叠的批次可小规模并行，每轮收齐后先统一人物称呼、核对未完事件再开下一轮。每批除记录本段事实外，顺手记下跨批才能接上的线索：同人异名、尚未收尾的目标、待揭晓的伏笔，以及秘密借哪件信物、字据或口信传开、当时谁在场。全书读完再收束成文。
- 已有 `PRODUCT_BRIEF.md` 时，按其中锁定的方向与内容分级有所侧重地摘录证据；选定方向要用、但原著并未展开的部分，标明「原著无现成设定，属下游设计新增」。情爱、暴力、权谋等桥段如实梳理因果，并对照目标分级标出下游改编须留意的尺度边界。

## 输出：`analysis/SOURCE_BIBLE.md`

原文写明的附章回与简短定位词；由多处细节推知的注「据第 X、Y 章细节推断」；书里没交代的标「原文未明确」。优先用表格，共六节：

1. **来源与全书覆盖**：底本版本、授权或洁本说明、总章数与覆盖范围。先用几句话点明全书核心驱动力与根本矛盾，再顺着作品自身结构（卷部、境界、对手、案件或关系转折）切出覆盖全书连续章回的主线阶段，每段写清「谁想做什么 → 卡在哪 → 靠什么破局 → 得失及对后文的约束」。
2. **高光桥段**：冲突最集中、反转最精彩、读者追读期待最高的大戏，按 `章回 | 起因与赌注 | 博弈与反转 | 结果代价 | 改编价值` 列表。含多步试探、拉锯或取舍的标为「可玩切片候选」；纯身世揭晓或只成立一次的情感爆发标为「单次演出」，提醒下游别硬拆成重复刷取的循环。
3. **人物与关系**：核心人物的身份名分、由言行体现的性格、诉求、软肋、筹码、翻脸或让步的条件与最终结局；涉及名分、座次或固定队伍的作品附名册表 `姓名 | 身份/次序 | 结局 | 证据位置`；关系按方向与转折记录（甲 → 乙：表面态度与真实盘算，第 X 章因何事生变）。只合并有原文依据的同人异称，拿不准是否同一人就分开记。玩家身份未锁定时，记下不同切入角色各自够得着的行动空间。
4. **秘密与信息差**（原著靠悬念、隐瞒、冒充或证词推进时必填，直白推进的作品从略）：同一真相只建一条记录，对照客观发生顺序与正文披露节点，写清读者和关键人物各自何时知情、何时误信。
5. **世界规矩与场景风物**：力量、器物或礼法的触发条件、代价、克制与反例，标出首次立规、关键反例与最终回收的章回——仅在开篇有效的情况、角色自吹或谎话都不算全书铁律；人物遇阻时惯用的破局手段；核心场景的出入口、准入门槛与动线；原著写明的器物形制、材质、服饰、天色、声响，以及人物神态举止、场景异象等可直接「以画代字」的视觉线索。
6. **改编红线与留白**：按 `条目 | 边界类型 | 证据位置` 列表，边界类型取 `immutable`（原著铁律）、`adaptable`（可压缩调适）、`open`（原著留白，允许原创）或 `conflicted`（原文前后出入或版本异文）；单独列出影视、戏曲、同人里流传甚广但本书未载的常见误区；跨语种或含古语行话时附术语表。

`SOURCE_BIBLE.md` 是供下游筛选与取舍的原著事实底稿，不是直接搬进开场旁白或游戏内设定百科面板的文本库。下游选定方向后，仅在所依赖的细节缺出处或前后矛盾时按章回定点回查补证，不重扫全书。
