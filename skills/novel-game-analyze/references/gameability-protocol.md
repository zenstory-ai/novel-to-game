# 游戏化全书拆解方法

长篇小说拆解按「划分章节边界 → 逐章提取 → 分层汇总 → 原文回查」四步推进。互不重叠的章节批次可并行提取，跨章汇总与原文回查须串行完成。

## 一、分批覆盖与逐章取证

长篇小说可将章节边界表写入 `analysis/_coverage.md` 用于分批处理、断点续跑和漏章检查（已有拆文资料仅在逐章覆盖范围与原著完全一致时才可直接复用；分批临时工作卡在汇总后清理）。每个章节单元记录覆盖状态与原文位置（审阅后无相关发现的同样计入已覆盖，未审或读取失败的单独标记），只提取有原文依据、影响游戏改编的可观察事实及其玩法转化价值，不复述剧情梗概或硬凑空表：

| 字段 | 只记录什么 |
|---|---|
| 客观变化 | 谁做了什么，导致哪项状态、人物关系、资源、位置或认知发生变化 |
| 动作候选 | 玩家可反复执行、且随选择或熟练度产生不同反馈的动作 |
| 规则证据 | 规则的触发条件、代价、例外情况、反制手段与可见后果 |
| 行动者 | 核心角色的目标、默认行事方式、手头筹码、底线与立场变化 |
| 空间 | 场景的出入口、准入门槛、地标、潜在风险与可改变的区域 |
| 物件与能力 | 关键器物或能力的发动条件、效果、限制、归属，以及是否仅出场一次 |
| 知识与信息差 | 谁知情、谁误信、谁在隐瞒或撒谎，以及秘密靠什么载体传递 |
| 节奏与感受 | 危机与压迫感如何蓄积、释放或反转，玩家通过什么行动体会这种起伏 |
| 视听锚点 | 原著有明确描写、可用于识别或状态反馈的轮廓、材质、声响与名场面 |
| 证据与边界 | 原文位置、推演结论、前后冲突点、原著未定义处及影视/同人二创混入风险 |

## 二、提炼系统与分层汇总

针对原著里反复出现的动作、世界规则、人物关系、场景空间和信息差，逐一追问：玩家能在此做什么决定？世界如何回应？什么状态会延续到下一步？重复尝试后能否走出不同结果？仅出现一次的高潮桥段留作标志性演出，不当成核心玩法循环。玩家身份未锁定时，对比主角、原创角色、势力首领或旁观者各自可触达的操作与决策空间；身份已锁定时只验证该身份。

将单章提取的事实按**阶段层**（剧情目标、场景转移、能力跃迁或规则群的压力变化、关键转折与可重复玩法结构）和**全书层**（贯穿全书的因果律、角色行事逻辑、空间动线与独有视听特征，标出首次确立、典型发作、关键反例与最终回收的章节位置）逐级收束并回查原文，避免把仅在开篇成立的局部现象写成全局硬规则。当原著由秘密、谎言、证词或立场交锋推动时，专门梳理人物知情范围与伏笔回收；无此类结构则不硬凑表格。书中人物的主观台词不自动等于客观世界规则，不同角色或器物的属性也不得张冠李戴；交付前确认全书章节无遗漏、核心规则均可追溯原文，并能清楚回答「玩家扮演谁、能做什么、在哪里做、世界如何回应」。
