# 小说拆解与取证方法

长篇原著按「**核对章界 → 分段精读（同趟记单段事实与跨章延续线索）→ 全书收束 → 疑点定点回查**」四步推进；已有覆盖全书的拆文成果时直接跳入「全书收束」。

## 一、分段精读与断点续跑

长篇小说可将章节边界与进度记入 `analysis/_coverage.md`，用于分批处理、断点续跑和漏章检查（审阅后无新增改编要点的章回同样标为已覆盖，读取失败或缺失的章回单独标记；汇总核验无误后清理分批临时草稿）。

每段原文按连续数章或自然卷段切分，**同一章节块只精读一次**。互不重叠的批次可小规模并行（如每轮 3 批），每轮收齐后先对齐人物称呼与未完事件再开下一轮；单批过长或中断时拆小重试。除对应 `SOURCE_BIBLE.md` 六节的本段事实与章回定位词外，同趟顺手记下容易跨章断线的过程信息（有据才记，不硬凑空表）：

- **节奏与情绪蓄势**：危机与压迫感如何蓄积、延迟、爆发或反转，作者在哪些场面重墨展开、哪些一笔带过，读者追读的期待点落在何处；
- **秘密传递载体**：隐情靠哪件信物、书信、耳目、口供或失言流转，谁在场听见、谁被蒙在鼓里；
- **跨批延续状态**：本批新确认的同人异名、尚未收尾的剧情目标（标 `open`）、待揭晓的悬念伏笔、下一批需承接的关系状态与待核疑点。

## 二、合拢故事骨架、筛选高光桥段与对齐隐情顺序

1. **按作品结构切分主线阶段**：收束前先结合开篇与结局看清故事全貌，按作品自身脉络切分阶段——升级试炼按境界或地图切，复仇破局按对手或阶段目标切，单元闯关按每难/每案切，群像世情按关系演进与家运兴衰切，多线交织按线索切并标出交汇点（原书已有卷部划分时优先沿用）。
2. **把握阶段粒度**：每个阶段都应有完整起承转合与核心在场人物；一两章内的偶发小事并入所属阶段，横贯全书的大口号（如“主角的成长之路”）拆成具体阶段，相邻批次若围绕同一目标与同一批人物自然延续则合并为一段。
3. **筛选高光桥段并区分改编用法**：逐场还原完整的戏剧链条（例如初次按常理出手为何碰壁或闯出大祸 → 查明哪条隐情、器物克制或人事软肋 → 靠什么计策、代价或同伴接力翻盘 → 留下什么不可逆结果）。包含多步试探、策略博弈或艰难取舍的场次标为**可玩切片 / 核心关卡候选**；纯命运揭晓或仅能成立一次的终局爆发标为**单次标志性剧情演出**，提醒下游勿硬拆成重复日常刷取循环。
4. **对齐事件发生与正文揭晓顺序**：涉及往事隐情、身份掉包、冤案追查或宅门耳目时，同一事件只建一条主记录，串起散见各章的披露节点，防止下游把后文才揭穿的真相提前塞进早期对白或界面说明。

## 三、人物合并立档与硬规矩核实

- **一人一档与有向关系**：无名路人与群体泛称（如“众街坊”“掌柜”，除非原文固定指代特定人物）不单独立档。仅合并有明确原文同指依据的本名、字号、排行与固定称号，拿不准是否同一人时分开记录，严防把相邻人物的等级、器物、台词或结局串到一起。“甲倚重乙”与“乙算计甲”按各自方向分开记录；无直接交集、仅凭第三方转述的关系须注明转述者与依据。
- **区分局部现象与全局铁律**：汇总世界规则与器物能力时，标出**首次确立、典型生效、关键反例与最终回收**的章回位置，避免把仅在开篇新手阶段成立的现象当成全书硬规则；书中人物的主观猜测、吹嘘或谎言不自动等于客观世界规则。
