# 游戏化全书拆解方法

长篇小说拆解按「划分章节边界 → 逐章提取 → 分层汇总 → 原文回查」四步推进。

## 一、来源与覆盖

记录底本版本、改编章节范围、章节切分方式、缺失部分和版权边界。除非用户明确限定只改局部，否则拆解范围必须覆盖全部原著章节；无法读取的章节须如实标为缺失，不能拿局部抽样冒充全书拆解。

长篇小说可将章节边界表写入 `analysis/_coverage.md`，用于分批处理、断点续跑和漏章检查。已有的拆文资料只有在逐章覆盖范围与原著完全一致时才能直接复用；分批提取用的临时工作卡在完成汇总后即可清理。

## 二、逐章取证

每个章节单元记录覆盖状态与原文位置（审阅后无相关发现的章节同样计入已覆盖，未审或读取失败的单独标记）。以下维度用于指导审阅取证，只记录有原文依据且影响游戏改编的发现，不必每章硬凑空表：

| 字段 | 只记录什么 |
|---|---|
| 客观变化 | 谁做了什么，导致哪项状态、人物关系、资源、位置或认知发生变化 |
| 动作候选 | 玩家可反复执行、且随选择或熟练度产生不同反馈的动作（含原著中有依据的发号施令、委托与代办） |
| 规则证据 | 规则的触发条件、代价、例外情况、反制手段与可见后果 |
| 行动者 | 核心角色的目标、默认行事方式、手头筹码、底线，以及可下达或承接的事务与立场变化 |
| 空间 | 场景的出入口、准入门槛、地标、潜在风险与可改变的区域 |
| 物件与能力 | 关键器物或能力的发动条件、效果、限制、归属，以及是否仅出场一次 |
| 知识与信息差 | 谁知情、谁误信、谁在隐瞒或撒谎，以及秘密靠什么载体传递 |
| 节奏与感受 | 危机与压迫感如何蓄积、释放或反转，玩家通过什么行动体会这种起伏 |
| 视听锚点 | 原著有明确描写、可用于识别或状态反馈的轮廓、材质、声响与名场面 |
| 证据与边界 | 原文位置、推演结论、前后冲突点、原著未定义处及影视/同人二创混入风险 |

提取结果只记可观察事实及其玩法转化价值，不复述整章剧情梗概。

## 三、从原著事实提炼系统候选

不要看到叙事元素就直接套游戏类型。针对原著里反复出现的动作、世界规则、人物关系、场景空间、信息差和情绪高潮，逐一追问：玩家能在此做什么决定？世界如何回应？什么状态会延续到下一步？玩家重复尝试后能否摸清规律或走出不同结果？仅出现一次的高潮桥段可留作标志性演出，不能当成核心玩法循环。

涉及发号施令或托人办事时，需拆清：发令者想办什么、执行人实际能做到什么、中间经过哪些人物或空间权限、会留下什么物证与目击者、日后在什么条件下翻旧账。原著中反复出现的「下令不等于办成」可提炼为玩法机制候选；偶发的一次传话则不能夸大成通用自由输入或完整委派系统。

原著事实统一使用四种改编边界标签：`immutable`（不可改）、`adaptable`（可调适）、`open`（原著留白）、`conflicted`（原文前后矛盾）。玩家身份未锁定时，对比主角、原创角色、势力首领或旁观者各自可触达的操作与决策空间；身份已锁定时只验证该身份。

## 四、分层汇总

按三层由细到粗收束：

1. **章节层**：保留单章内的具体事实、状态变化和原文出处；
2. **阶段层**：按剧情目标、场景转移、能力跃迁或规则群整理压力变化、关键转折和可重复的玩法结构；
3. **全书层**：提炼贯穿全书的因果律、角色行事逻辑、空间动线规律、情绪主线与独有视听特征。

全书层需主动排查反例与结局回收，避免把仅在开篇成立的局部现象写成全局硬规则。当原著由秘密、谎言、证词或立场交锋推动时，再专门梳理人物知情范围与伏笔回收；原著无此类结构则不必硬凑表格。

## 五、事实保真与交付

关键数值、能力上限、人物关系、角色生死和最终结局必须回查原文核实。汇总结论需同时标出首次确立、典型发作、关键反例和最终回收的章节位置；前后矛盾处保留双方证据并标为 `conflicted`，原著未交代处归入开放设计空间。书中人物的主观台词不自动等于客观世界规则，不同角色或器物的属性也不得张冠李戴。

`SOURCE_BIBLE.md` 只保留会影响概念选型与玩法设计的原著事实、改编边界和关键出处。交付前确认底本范围明确、全书章节无遗漏、核心规则均可追溯原文，并能清楚回答「玩家扮演谁、能做什么、在哪里做、世界如何回应」。
